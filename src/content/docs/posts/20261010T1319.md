## 問題の概要

長さ $N$ の十進数 $S$ が与えられます。$S$ からいくつかの文字を消し、残った文字をそのままの順で並べた数を $6$ の倍数か $7$ の倍数にしたい問題です。残す文字は $1$ 個以上で、先頭が $0$ になってもかまいません($0$ も $6$ と $7$ の倍数です)。消す文字の個数の最小値を求め、できなければ $-1$ を出力します。

テストケースは $T \le 2 \times 10^5$ 個あり、$N$ の総和は $2 \times 10^5$ 以下です。

## 解法

### 42 で割った余りを見る

$42 = 6 \times 7$ は $6$ でも $7$ でも割り切れるので、ある数が $6$ の倍数か $7$ の倍数かは、その数を $42$ で割った余り $m$ だけで決まります。$m$ が $6$ の倍数か $7$ の倍数であれば条件を満たします。

### DP

$S$ を先頭から 1 文字ずつ見ていき、

$$
\mathrm{dp}[m] = \text{残した文字が表す数を } 42 \text{ で割った余りが } m \text{ になるときの、消した文字数の最小値}
$$

を更新します。最初は何も残していないので、$\mathrm{dp}[0] = 0$、それ以外は $\infty$ です。

次の文字が数字 $x$ のとき、各 $m$ について 2 通りの遷移があります。

- **消す**:余りは $m$ のままで、消した文字数が $1$ 増えます。
- **残す**:余りは $(10m + x) \bmod 42$ になり、消した文字数は変わりません。

### 1 文字以上残す条件

最後に、$m$ が $6$ の倍数か $7$ の倍数であるものについて $\mathrm{dp}[m]$ の最小値をとります。

ただし、全部消した場合も「余り $0$、消した文字数 $N$」として $\mathrm{dp}[0]$ に含まれています。残す文字は $1$ 個以上という条件があるので、$\mathrm{dp}[m] < N$ のものだけを答えの候補にします。候補がなければ $-1$ です。

計算量は $O(42 \sum N)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    S = input()
    dp = [float("inf")] * 42
    dp[0] = 0
    for c in S:
        x = int(c)
        ndp = [float("inf")] * 42
        for i in range(42):
            ndp[i] = dp[i] + 1
        for i in range(42):
            j = (i * 10 + x) % 42
            ndp[j] = min(ndp[j], dp[i])
        dp = ndp
    ans = float("inf")
    for i in range(42):
        if i % 6 == 0 or i % 7 == 0:
            if dp[i] < N:
                ans = min(ans, dp[i])
    if ans == float("inf"):
        ans = -1
    print(ans)
```
