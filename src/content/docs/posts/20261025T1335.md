## 問題の概要

$N$ 日分の竹簡があり、$i$ 日目の竹簡は $A_i$ 枚です。これを 1 日目から順に、容量 $K$ の本に綴じていきます。1 日分の竹簡は分けられません。今の本にその日の竹簡を加えて $K$ 枚以下なら今の本に綴じ、$K$ 枚を超えるなら次の本にその日の竹簡をすべて綴じます。本の冊数が $M$ 冊以下になる最小の $K$ を求める問題です($1 \le M \le N \le 1000$、$1 \le A_i \le 100$、$\sum A_i \le 10000$)。

## 解法

1 日分の竹簡が 1 冊に収まらないといけないので、$K \ge \max A$ です。また $K = \sum A$ なら全部が 1 冊に収まるので、条件を満たします。

そこで $K$ を $\max A$ から $\sum A$ まで小さい順に試し、それぞれについて問題文の規則どおりに本を綴じて冊数を数えます。冊数が初めて $M$ 以下になった $K$ が答えです。

試す $K$ は $\sum A \le 10000$ 通り以下で、1 回のシミュレーションは $O(N)$ なので、全体で $O(N \sum A)$、最大 $10^7$ 回程度です。

なお、$K$ を大きくしても冊数は増えないので、$K$ を[二分探索](/blog/posts/20261024T1231/)すれば $O(N \log \sum A)$ でも求まります。

## 解答コード

<details>
<summary>Python</summary>

```python
N, M = map(int, input().split())
A = list(map(int, input().split()))
for k in range(max(A), sum(A) + 1):
    t = 0
    f = 1
    for a in A:
        if t + a > k:
            f += 1
            t = a
        else:
            t += a
    if f <= M:
        print(k)
        break
```

`t` が今の本に綴じた竹簡の枚数、`f` が冊数です。
