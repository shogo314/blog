## 問題の概要

$N$ 頂点 $M$ 辺の有向グラフが与えられます。辺 $a \to b$ は「囚人 $a$ は囚人 $b$ に殺意を持っている」ことを表します。「生存している $a, b$ で辺 $a \to b$ があるものを選び、$b$ を殺す」という操作を好きな回数行ったあと、生存している囚人の集合としてありうるものの個数を $998244353$ で割った余りを求める問題です。

テストケースは $T$ 個あり、$N$ の総和と $M$ の総和はそれぞれ $2 \times 10^5$ 以下です。

## 解法

### 生存者の集合の条件

グラフを強連結成分分解します。外から入ってくる辺がない強連結成分(入次数 $0$ の成分)を、ここでは**始点成分**と呼びます。

生存者の集合 $S$ がありうるのは、**すべての始点成分に $S$ の頂点が 1 つ以上あるとき**で、そのときに限ります。

**必要性.** 始点成分 $C$ の頂点を殺せるのは、$C$ の頂点だけです。$C$ の頂点が全員殺されたとすると、$C$ の中で最後に殺された頂点を殺した頂点は $C$ の中にいて、そのあとに殺されています。これは最後であることに反します。よって、$C$ には生存者が残ります。

**十分性.** どの頂点も、どこかの始点成分から到達できます。強連結成分の中では互いに到達できるので、すべての始点成分に $S$ の頂点があれば、すべての頂点が $S$ のどれかの頂点から到達できます。そこで、$S$ からの距離 $d(v)$ を考え、$S$ にない頂点を $d(v)$ が大きい順に殺します。$d(v) = t \ge 1$ の頂点 $v$ には、$d(u) = t - 1$ で辺 $u \to v$ がある頂点 $u$ があります。$u$ は $S$ の頂点か、$v$ よりあとに殺す頂点なので、$v$ を殺すときにはまだ生きています。したがって、$v$ を殺せます。

### 数える

条件は成分ごとに独立です。

- 始点成分 $C$ では、空でない部分集合ならどれでもよいので $2^{|C|} - 1$ 通りです。
- それ以外の成分 $C$ では、制限がないので $2^{|C|}$ 通りです。

これらの積が答えです。

## 解答コード

<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/graph/graph.hpp"
#include "shogo-library/graph/graph_util.hpp"
#include "shogo-library/math/modint.hpp"

using mint = modint998244353;

void solve() {
    LL(N, M);
    Graph<> g(N);
    rep(M) {
        LL(a, b);
        a--, b--;
        g.add_directed_edge(a, b);
    }
    vl dp(N);
    auto tmp = strongly_connected_components(g);
    mint ans = 1;
    for (const auto &f : tmp) {
        ll x = 0;
        for (ll u : f) {
            x |= dp[u];
        }
        ans *= mint(2).pow(f.size()) - !x;
        for (ll u : f) {
            for (ll v : g[u])
                dp[v] = 1;
        }
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    LL(T);
    rep(T)
        solve();
}
```

`strongly_connected_components` は強連結成分をトポロジカル順に返します。`dp[v]` は「すでに処理した成分から $v$ に入る辺がある」ことを表すフラグです。成分 `f` を見る時点で、`f` に外から入る辺はすべて前の成分から来ているので、`x` が $0$ なら `f` は始点成分です。成分の中の辺で立つフラグは、`x` を求めたあとに立てています。
