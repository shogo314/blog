## 問題の概要

長さ $n$ の整数列 $a$ と正の整数 $x, y$ が与えられます。カウンタ $t$ は最初 $0$ です。$a$ を好きな順に並べ替えてから順に見ていき、値 $v$ について $t \le v$ なら $t$ を $x$ 増やし、そうでなければ $t$ を $y$ 減らします。最後の $t$ の最大値を求める問題です($1 \le n \le 2 \times 10^5$、$1 \le x, y \le 10^9$、$-10^9 \le a_i \le 10^9$)。

## 解法

$a$ を昇順に並べてシミュレーションした結果が答えです。

### カウンタが大きいほうが得

$k$ 個の値を見た時点の $t$ は、増やした回数を $p$ として $px - (k - p)y = p(x + y) - ky$ です。よって、同じ個数を見た時点の 2 つのカウンタの値 $t \le t'$ の差は $x + y$ の倍数です。

$t \le t'$ のとき、同じ値 $v$ を見たあとも大小は逆転しません。両方が増える場合と両方が減る場合は明らかです。$t \le v < t'$ で $t$ だけが増える場合は、$t' \ge t + (x + y)$ なので $t' - y \ge t + x$ です($t > v \ge t'$ となることはありません)。

したがって、途中のある時点でカウンタが大きいほうが、残りの並びが同じなら最後のカウンタも大きいか等しいです。

### 隣り合う 2 つの入れ替え

並びの中で $u > v$ が $u, v$ の順に隣り合っているとき、$v, u$ の順に入れ替えても、2 つを見たあとのカウンタは小さくならないことを示します。2 つを見る前のカウンタを $t$ とします。

- $t \le v$ のとき:どちらの順でも 1 つ目で増えて $t + x$ になります。2 つ目で増えるのは、元の順では $t + x \le v$ のとき、入れ替えると $t + x \le u$ のときで、後者のほうが条件が弱いです。
- $v < t \le u$ のとき:元の順では $u$ で増えて $v$ で減り、入れ替えると $v$ で減って $u$ で増えます($t - y < t \le u$ なので)。どちらも $t + x - y$ です。
- $u < t$ のとき:どちらの順でも 1 つ目で減って $t - y$ になります。2 つ目で増えるのは、元の順では $t - y \le v$ のとき、入れ替えると $t - y \le u$ のときで、後者のほうが条件が弱いです。

どの場合も、入れ替えたほうが増える回数が多いか等しいので、カウンタも大きいか等しいです。上で示したことから、最後のカウンタも小さくなりません。この入れ替えを繰り返すと昇順になるので、昇順が最適です。

計算量はソートの $O(n \log n)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
n, x, y = map(int, input().split())
a = list(map(int, input().split()))
a.sort()
t = 0
for v in a:
    if t > v:
        t -= y
    else:
        t += x
print(t)
```
