二分探索について、参考になる記事や資料をまとめました。

二分探索は、答えの候補が並んでいて、ある境目より手前では条件を満たさず、そこから先ではずっと満たす(単調性がある)ときに、その境目を $O(\log N)$ 回の判定で求める手法です。ソート済みの配列から値を探すのが基本の形で、C++ の `std::lower_bound` や Python の `bisect` がこれにあたります。

競プロでよく使うのは、その一般化です。「答えを $x$ 以下にできるか」のような判定問題が $x$ について単調なら、答えそのものを二分探索で求められます(答えで二分探索)。最小値の最大化・最大値の最小化や、平均値の最大化がこの形の典型です。実数の範囲でも同じように探せますが、打ち切り方に注意が必要です。

実装では、条件を満たす側の端を `ok`、満たさない側の端を `ng` として、`ok` と `ng` が隣り合うまで真ん中で区切る書き方(めぐる式二分探索)がよく使われます。範囲が大きいときは、真ん中を `(ok + ng) / 2` で計算すると和が型の範囲を超えることがあるので、`ok + (ng - ok) / 2` のように書くと安全です。

セグメント木の上を降りながら境目を求める「セグメント木上の二分探索」については、[セグメント木のリンク集](/blog/posts/20261010T0123/)も見てください。

- [めぐる式二分探索 コピペで使えるPython実装](https://aotamasaki.hatenablog.com/entry/meguru_bisect)(学習する天然ニューラルネット)

## C++

- [std::lower_bound](https://cpprefjp.github.io/reference/algorithm/lower_bound.html)・[std::upper_bound](https://cpprefjp.github.io/reference/algorithm/upper_bound.html)・[std::partition_point](https://cpprefjp.github.io/reference/algorithm/partition_point.html)(cpprefjp)
  - `lower_bound` は「指定した値以上の最初の位置」、`upper_bound` は「指定した値より大きい最初の位置」を返します。範囲がソートされていなくても、条件で区分化されていればよいこと、どちらも `partition_point` と同じ働きであることが書かれています。`partition_point` は判定関数を渡して境目を求める関数で、二分探索を一般化した形にあたります。
  - `std::set` や `std::multiset` に `std::lower_bound` を使うと、比較の回数は $O(\log N)$ でもイテレータを進めるのに $O(N)$ かかります。メンバ関数の `s.lower_bound(x)` を使ってください(cpprefjp の `lower_bound` のページにも、メンバ関数を使うようにと書いてあります)。
