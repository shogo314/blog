## 問題の概要

BCD に参加するには、DOJ のレーティングが $0$ 以上 $2200$ 以下でなければなりません。レーティングが $N$ のとき、BCD に参加できるかを判定する問題です。テストケースは $T$ 個あります($1 \le T \le 10000$、$0 \le N \le 4000$)。

## 解法

$0 \le N \le 2200$ なら `YES`、そうでなければ `NO` を出力します。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    if 0 <= int(input()) <= 2200:
        print("YES")
    else:
        print("NO")
```
