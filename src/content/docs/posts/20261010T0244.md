Cartesian Tree について、参考になる記事や資料をまとめました。

Cartesian Tree は、数列の最小値を根にし、その左側と右側の部分列から左右の部分木を再帰的に作った二分木です(最大値を根にする流儀もあります)。添字について見ると二分探索木、値について見るとヒープになっています。スタックを使えば $O(N)$ で構築できます。「区間を最小値で分割して再帰する」分割統治は、この木の上の再帰とみなせます。

同じ値があるときは、どちらを小さいとみなすかで木の形が変わります。下の資料の多くは左端の最小値を根にしていますが、右端を根にするものもあるので注意してください。

## まず読むもの

- [Cartesian Tree の実装 〜 stack を用いた O(N) 時間構築](https://drken1215.hatenablog.com/entry/2023/10/19/025800)(けんちょんの競プロ精進記録)
  - 定義から始めて、スタックで $O(N)$ で構築する手順を、具体例でのスタックの推移表と C++ 実装つきで解説しています。使える問題へのリンクもあります。
- [列を最小値で分割して再帰するパターンと Cartesian tree](https://kmyk.github.io/blog/blog/2020/07/27/recursion-on-cartesian-tree/)(うさぎ小屋)
  - 最小値で列を分割して再帰する分割統治が Cartesian Tree の上の再帰そのものだと整理し、例題 3 問で使い方を示しています。Treap との用語の違いにも触れています。

## RMQ・LCA との関係

区間最小値(RMQ)は、Cartesian Tree の上の 2 頂点の最小共通祖先(LCA)に対応します。

- [前処理O(n)クエリO(1)のLCAと静的RMQ](https://joisino.hatenablog.com/entry/2017/08/13/210000)(joisino)
  - RMQ を Cartesian Tree の上の LCA に帰着させ、前処理 $O(n)$・クエリ $O(1)$ を実現する記事です。スタックによる構築も図で説明しています。
- [Solve RMQ by finding LCA](https://cp-algorithms.com/graph/rmq_linear.html)(cp-algorithms、英語)
  - RMQ が LCA に帰着できることの説明と、スタックによる構築のコードがあります。このコードでは、同じ値があると右端の最小値が根になります。
- [LCA and RMQ ~簡潔もあるよ！~](https://www.slideshare.net/yumainoue965/lca-and-rmq)(井上祐馬、スライド)
  - RMQ から LCA への帰着から、簡潔データ構造まで扱う上級者向けの資料です。
