## 問題の概要

正整数 $N$ が、$1$ 桁の正整数だけの積で表せるかを判定する問題です。テストケースは $T$ 個あり、$1 \le T \le 100$、$1 \le N \le 10^{18}$ です。

## 解法

### 素因数で言い換える

$N$ が $1$ 桁の正整数だけの積で表せることは、$N$ の素因数が $2, 3, 5, 7$ だけであることと同じです。

- $1$ 桁の正整数 $1, 2, \dots, 9$ は、どれも素因数が $2, 3, 5, 7$ だけです。そのため、これらの積の素因数も $2, 3, 5, 7$ だけです。
- 逆に、素因数が $2, 3, 5, 7$ だけなら、$N$ を[素因数分解](/blog/posts/20261023T2138/)した式がそのまま $1$ 桁の正整数の積になっています。$N = 1$ のときも、$1$ 自体が $1$ 桁なので表せます。

### 割れるだけ割る

$N$ を $2, 3, 5, 7$ でそれぞれ割り切れなくなるまで割り、最後に $1$ が残れば `Yes`、そうでなければ `No` です。

1 回割るたびに $N$ は半分以下になるので、割る回数は $\log_2 10^{18} < 60$ 回ほどで済みます。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    for p in [2, 3, 5, 7]:
        while N % p == 0:
            N //= p
    if N == 1:
        print("Yes")
    else:
        print("No")
```
