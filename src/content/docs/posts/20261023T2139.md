最大部分配列問題について、参考になる記事や資料をまとめました。

最大部分配列問題は、数列の連続する部分列(部分配列)のうち、和が最大のものを求める問題です。全部の区間を調べると $O(N^2)$ ですが、Kadane のアルゴリズムを使うと $O(N)$ で解けます。左から順に「その位置で終わる部分列の和の最大値」$c$ を $c \gets \max(c + A_i, A_i)$ で更新していき、$c$ が取った値の最大値が答えです。累積和 $S$ で見ると、右端 $r$ を決めたときの最大値は「$S_r$ − それまでの $S$ の最小値」なので、累積和と累積 min でも $O(N)$ で求まります。Kadane のアルゴリズムで持っている値は、この差にあたります。最小の和を求めたいときは、符号を反転させれば同じです。

空の部分列(和は $0$)を許すかどうかで答えが変わるので、問題文をよく確認してください。許すなら答えは $0$ 以上で、許さないなら全要素が負のときの答えは最大の要素です。紹介する記事やコードでも扱いが分かれていて、初期値を $0$ にするか $A_1$ にするかで違いが出ます。また、和は 64 bit 整数で持つ必要があることが多いです。

区間の最大部分配列和を、要素の更新をはさみながら何度も求めたいときは、[セグメント木](/blog/posts/20261010T0123/)を使います。各ノードに「区間全体の和」「接頭辞の和の最大値」「接尾辞の和の最大値」「部分配列の和の最大値」の 4 つを持たせると、1 点の更新と区間のクエリがどちらも $O(\log N)$ でできます。累積和そのものについては [累積和・いもす法のリンク集](/blog/posts/20261012T0121/) も見てください。

## まず読むもの

- [Kadane's Algorithm | 最大部分配列 問題](https://ark4rk.hatenablog.com/entry/2018/01/08/002508)(Ark's Blog)
  - $O(n^3)$ と $O(n^2)$ の全探索、分割統治による $O(n \log n)$、Kadane のアルゴリズムによる $O(n)$ を順に紹介しています。Kadane のアルゴリズムは、全探索の式の $\max$ の順番を入れ替えて、右端 $j$ で終わる部分列の和の最大値 $s_j$ の漸化式を導く形で説明しています。D 言語のコードつきで、空の部分列は許さない設定です。分割統治の節は概要だけです。
  - 本文中の数式の一部は画像で埋め込まれていて、今は表示されません。
- [Kadane's Algorithm - Maximum subarray problem](https://zenn.dev/janos0207/articles/25f43ab27fe652)(Janos、Zenn)
  - 全探索と Kadane のアルゴリズムを Python で比べています。先頭からの和が初めて負になる位置 $k$ より前から始まる部分列は考えなくてよい、という形で $O(N)$ になる理由を説明しています(本人も厳密な証明ではないと書いています)。空の部分列は許さず、全要素が負なら最大の要素を返す実装です。
  - コードの `List` と `inf` は import されていないので、そのままでは動きません。

## Kadane のアルゴリズム

- [\[競プロ\]\[Max Subarray\] Kadane's Algorithm解説](https://qiita.com/awesam/items/37a0ceb1468feef3a403)(awesam、Qiita)
  - $\mathrm{DP}[i]$ を「$A_i$ で終わる部分配列の和の最大値」とする DP として説明し、答えは $\mathrm{DP}[n-1]$ ではなく $\mathrm{DP}$ 全体の最大値であることを強調しています。LeetCode の Maximum Subarray を解く C++ のコードつきです。
  - コードは和を `int` で持っています。

## 累積和による見方

  - コードは和を `int` で持っています。答えの初期値を `a[0]` にしているので空の部分列は許さない設定ですが、本文ではそのことに触れていません。また、Kadane のアルゴリズムを「1984 年に提案」としていますが、英語版 Wikipedia の歴史の節によると、考案されたのは 1977 年に問題が提案されてまもなくです。
- [More on Prefix Sums](https://usaco.guide/silver/more-prefix-sums)(USACO Guide、英語)
  - 最初の「Max Subarray Sum」の節で、固定した右端 $r$ について $p[r] - \min_{l < r} p[l]$ を取る方法を説明し、C++・Java・Python のコードを載せています。下の CSES - Maximum Subarray Sum が例題です。別解として Kadane のアルゴリズムのコードも折りたたんで載っています。
  - 別解の Python のコードは数値を 1 行に 1 つずつ読んでいますが、CSES の入力は 1 行に並んでいるので、そのままでは動きません。

## 分割統治

- [Maximum Subarray Sum using Divide and Conquer algorithm](https://www.geeksforgeeks.org/dsa/maximum-subarray-sum-using-divide-and-conquer-algorithm/)(GeeksforGeeks、英語)
  - 列を半分に分け、「左半分の答え」「右半分の答え」「中央をまたぐ部分列の最大値」の 3 つの最大値を取る $O(n \log n)$ の方法を、C++・Java・Python などのコードで示しています。中央をまたぐ部分は、中央から左に伸ばした和の最大値と右に伸ばした和の最大値の和です。最後に Kadane のアルゴリズムのほうが良いと書いています。
  - コードは和を `int` で持っています。また、空間計算量を $O(n)$ としていますが、追加で使うのは再帰の深さぶんの $O(\log n)$ です。

左右の答えと「またぐ部分」を組み合わせるこの考え方を、区間ごとに前計算して持っておくのが次のセグメント木による方法です。

## セグメント木に載せる方法

- [最大部分配列問題(連続部分列の総和の最大値)をセグ木に載せる](https://blog.hotman78.com/posts/5pyA5aSn6YOo5YiG6YWN5YiX5ZWP6aGMKOmAo-e2mumDqOWIhuWIl-OBrue3j-WSjOOBruacgOWkp-WApCnjgpLjgrvjgrDmnKjjgavovInjgZvjgosubWQ)(hotman's blog)

- [Finding subsegments with the maximal sum](https://cp-algorithms.com/data_structures/segment_tree.html#finding-subsegments-with-the-maximal-sum)(cp-algorithms、英語)
  - セグメント木の記事の一節で、同じ 4 つの値を持たせる方法を、`combine` 関数と再帰のセグメント木の C++ のコードで説明しています。こちらは空の部分列を許す設定で、葉では和以外の値を $\max(0, x)$ にしています。

下の AtCoder Algorithm Lectures の講座は、空の部分列を許さない設定で同じモノイドを説明しています。設定によって単位元や葉の値が変わるので、見比べると違いがわかります。

## 2 次元版

長方形の領域の和の最大値を求める 2 次元版は、使う行の範囲(上端と下端)を全通り試し、各列の和を並べた 1 次元の列で最大部分配列問題を解くと、$N \times M$ のグリッドで $O(N^2 M)$ です。

- [Two-dimensional case of the problem](https://cp-algorithms.com/others/maximum_average_segment.html#two-dimensional-case-of-the-problem-search-for-maximumminimum-submatrix)(cp-algorithms、英語)
  - 上の方法で $O(n^3)$ になることを説明しています。より速いアルゴリズムも知られているものの、複雑で実用的ではないことや、全点対最短路(min-plus の行列積)との関係にも触れています。

## AtCoder Algorithm Lectures

- [区間クエリのためのモノイド設計](https://info.atcoder.jp/entry/algorithm_lectures/range_query_monoid_design)
  - 「5.4 最大部分配列和」の節で、1 点更新と区間の最大部分配列和のクエリに答えるために、区間全体の和・接頭辞の和の最大値・接尾辞の和の最大値・答えの 4 つを持たせる設計を、結合の式と C++ のコードで説明しています。空でない部分列を対象にしていて、単位元は $(-\infty, -\infty, -\infty, 0)$ です。空の部分列を許す文献もあり、その場合は単位元が変わることにも触れています。
  - 「7.6 最大部分配列和(再考)」では、同じ問題を max-plus 半環上の $3 \times 3$ 行列の積として扱い、積の形が決まっているので 4 つの成分だけ持てばよいことを説明しています。「10.2」の関連問題には、下の CSES - Subarray Sum Queries が空の部分列の扱いの違いの注意つきで載っています。
  - $-\infty$ の具体的な値は書かれていません。$-\infty$ どうしを足すことがあるので、`long long` の最小値を使うとオーバーフローします。$-10^{18}$ 程度にしておくのが安全です。

- [segtree のドキュメント](https://atcoder.github.io/ac-library/production/document_ja/segtree.html)(AtCoder Library)
  - ACL のセグメント木に渡す型 `S`・演算 `op`・単位元 `e` の決め方が書かれています。セグメント木のライブラリ全般は [セグメント木のリンク集](/blog/posts/20261010T0123/) を見てください。
- [Maximum Subarray Sum - Kadane's Algorithm](https://www.geeksforgeeks.org/dsa/largest-sum-contiguous-subarray/)(GeeksforGeeks、英語)
  - $O(n^2)$ の全探索と Kadane のアルゴリズムを、C++・C・Java・Python・C#・JavaScript のコードで示しています。空でない部分列を対象にしていて、初期値を `arr[0]` にしています。
  - コードは和を `int` で持っています。C のコードは `int` を返す関数の結果を `%lld` で出力していて、書式が合っていません。

## 百科事典・英語の資料

最大部分配列問題の記事は日本語版 Wikipedia にはありません。

- [Maximum subarray problem](https://en.wikipedia.org/wiki/Maximum_subarray_problem)(英語版 Wikipedia)
  - 問題の定義と性質、歴史(Grenander が 2 次元版の簡略化として 1977 年に提案し、Shamos の $O(n \log n)$ の分割統治を経て Kadane が $O(n)$ の方法を考案したこと)、応用、Kadane のアルゴリズムを扱っています。Kadane のアルゴリズムは、空の部分列を許さない版と許す版の両方を Python のコードで示し、ループ不変条件で正しさを説明しています。2 次元版が $O(n^3)$ で解けることや、和の大きい順に $k$ 個の部分配列を求める一般化にも触れています。
  - 「Computing the best subarray's position」の節は、区間の位置も求められると書いているだけで、コードはありません。

- [CSES - Maximum Subarray Sum](https://cses.fi/problemset/task/1643):空でない部分配列の和の最大値を求めます。値が $10^9$ までなので、64 bit 整数が必要です。
- [CSES - Maximum Subarray Sum II](https://cses.fi/problemset/task/1644):長さが $a$ 以上 $b$ 以下の部分配列に限ります。累積和の最小値を取る範囲が窓になるので、[スライド最小値](/blog/posts/20261023T1323/)などで解けます。
- [ARC174 A - A Multiply](https://atcoder.jp/contests/arc174/tasks/arc174_a):区間を $C$ 倍したときの総和の増分は $(C - 1)A_i$ の区間和なので、この列の空を許す最大部分配列和を元の総和に足します。$C$ は負や $0$ のこともあります。

- [ABC466 E - Range Flip](https://atcoder.jp/contests/abc466/tasks/abc466_e):操作する区間は交わらないとしてよく、$B_i - A_i$ の列から高々 $K$ 個の交わらない区間を選んで和を最大化する問題になります。
- [AtCoder Weekday Contest 0097 Beta D - 最大長方形部分和](https://atcoder.jp/contests/awc0097/tasks/awc0097_d):2 次元版です。空の領域は選べず、$N, M \le 500$ なので $O(N^2 M)$ の方法が間に合います。
- [CSES - Subarray Sum Queries](https://cses.fi/problemset/task/1190):1 点の更新のたびに、配列全体の最大部分配列和を答えます。空の部分配列を許します。
- [CSES - Subarray Sum Queries II](https://cses.fi/problemset/task/3226):更新はなく、区間 $[a, b]$ の中の最大部分配列和を答えるクエリを処理します。空の部分配列を許します。
