## 問題の概要

長さ $2N$ の順列 $P$ が与えられます。1 回の操作では、相異なる位置をちょうど $N$ 個選び、そこにある値を好きな順に並べ替えます。$P$ を昇順に並べるのに必要な操作回数の最小値を求める問題です($2 \le N \le 3000$、全テストケースの $N$ の総和は $3000$ 以下)。

## 解法

$P$ を巡回置換に分解し、長さが $2$ 以上のサイクルの長さを $l_1, \dots, l_k$ とします。正しい位置にない値の個数は $s = l_1 + \dots + l_k$ です。答えは次のとおりです。

- $s = 0$ なら $0$ 回。
- $1 \le s \le N$ なら $1$ 回。
- $s > N$ で、「$s < 2N$」または「いくつかのサイクルの長さの和をちょうど $N$ にできる」なら $2$ 回。
- それ以外($s = 2N$ で、和を $N$ にできない)なら $3$ 回。

### 1 回でできる場合

1 回の操作で動かせるのは $N$ 個なので、1 回で済むのは $s \le N$ のときだけです。このときは、正しい位置にない位置をすべて選び、足りない分は正しい位置にある位置で埋めて、そのまま並べ直せば終わります。

### 2 回でできる場合

$s > N$ なら 2 回以上かかります。

いくつかのサイクルの長さの和がちょうど $N$ なら、1 回目にそれらのサイクルの位置を選んで正しく並べます。残りは $s - N \le N$ 個なので、2 回目で終わります。

$s < 2N$ のときも 2 回でできます。サイクルの一部を 1 回の操作で直す方法を考えます。サイクル $x \to P_x \to P_{P_x} \to \cdots$ から、つながった $r$ 個の位置を選びます。そこに並ぶ値のうち $r - 1$ 個は、正しい位置が選んだ位置の中にあります。よって、この操作で $r - 1$ 個を正しい位置に置けて、サイクルの長さは $r - 1$ だけ短くなります。1 回目では、サイクルを丸ごと選べるだけ選び、残りの $r$ 個の枠は次のサイクルの一部で埋めます。すると、正しい位置に置ける値は $N - 1$ 個以上になります。残りは $s - (N - 1) \le N$ 個なので、2 回目で終わります。

逆に $s = 2N$ のときに 2 回でできたとします。1 回目に選ばなかった $N$ 個の位置は、1 回目のあとも正しくないままです。2 回目で動かせるのは $N$ 個なので、1 回目に選んだ $N$ 個の位置は、1 回目ですべて正しくならなければいけません。そのためには、選んだ位置にある値の正しい位置が、すべて選んだ位置の中になければなりません。これは、選んだ位置がいくつかのサイクルの和集合であることを意味します。つまり、サイクルの長さの和をちょうど $N$ にできなければ、2 回ではできません。

### 3 回でできること

上の「サイクルの一部を直す」方法で 1 回操作すると、残りは $s - (N - 1) \le N + 1 < 2N$ 個になります($N \ge 2$ です)。ここから 2 回で終わるので、どの場合も 3 回あれば十分です。

### サイクルの長さの和を $N$ にできるか

部分和問題の DP で判定します。$\mathrm{dp}[j]$ を「いくつかのサイクルを選んで長さの和を $j$ にできるか」として、サイクルを 1 つずつ加えて更新します。サイクルは高々 $N$ 個なので、計算量は $O(N^2)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    P = list(map(lambda x: int(x) - 1, input().split()))
    visited = [False] * (2 * N)
    l = []
    for i in range(2 * N):
        if visited[i]:
            continue
        x = i
        visited[x] = True
        r = [x]
        while i != P[x]:
            x = P[x]
            visited[x] = True
            r.append(x)
        if len(r) > 1:
            l.append(len(r))
    s = sum(l)
    dp = [0] * (N + 1)
    dp[0] = 1
    for x in l:
        for i in reversed(range(x, N + 1)):
            dp[i] |= dp[i - x]
    if s == 0:
        print(0)
    elif s <= N:
        print(1)
    elif dp[N] or s < 2 * N:
        print(2)
    else:
        print(3)
```

前半では、まだ見ていない位置 `i` から `P` をたどってサイクルを取り出し、長さが $2$ 以上ならその長さを `l` に入れています。後半の `dp` は部分和問題の DP で、`i` を大きいほうから回すことで、同じサイクルを 2 回使わないようにしています。
