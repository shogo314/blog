## 問題の概要

レベル $0$ の絨毯は黒いマス 1 個です。レベル $n$ の絨毯は、レベル $n - 1$ の絨毯を $3 \times 3$ に 9 個並べ、真ん中の 1 個だけを同じ大きさの真っ白な正方形に置き換えたものです(シェルピンスキーのカーペット)。レベル $n$ の絨毯は $3^n \times 3^n$ になります。

レベル $n$ の絨毯の $r$ 行 $c$ 列のマスが黒か白かを答えるクエリが $q$ 個与えられます($1 \le q \le 10^5$、$0 \le n \le 30$、$1 \le r, c \le 3^n$)。黒なら `#`、白なら `.` を出力します。

## 解法

行と列を $0$ 始まりにして、$r, c$ を $3$ 進数で見ます。

レベル $n$ の絨毯を $3 \times 3$ のブロックに分けたとき、マス $(r, c)$ が入るブロックは、$r, c$ の $3$ 進数の一番上の桁(下から $n$ 桁目)で決まります。これが両方 $1$ なら真ん中のブロックなので白です。そうでなければレベル $n - 1$ の絨毯の中にいるので、残りの桁で同じことを繰り返します。最後まで真ん中のブロックに入らなければ黒です。

つまり、**$r, c$ の $3$ 進数の同じ桁がどちらも $1$ になるところが 1 つでもあれば白、なければ黒**です。どの桁から調べても結果は同じなので、下の桁から $3$ で割った余りを見ていけば、$1$ クエリあたり $O(n)$ で判定できます。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N, R, C = map(int, input().split())
    R -= 1
    C -= 1
    for _ in range(N):
        if R % 3 == C % 3 == 1:
            print(".")
            break
        R //= 3
        C //= 3
    else:
        print("#")
```

`for` の `else` は、`break` せずにループが終わったとき、つまり両方 $1$ の桁がなかったときに実行されます。
