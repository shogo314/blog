## 問題の概要

座面の高さが $a$ と $b$ の 2 脚の椅子と、厚さが $c$ と $d$ の 2 枚のクッションがあります。それぞれの椅子にクッションを 1 枚ずつ置いたとき、2 脚の高さを等しくできるか判定する問題です($1 \le a, b, c, d \le 100$)。

## 解法

置き方は 2 通りで、高さが等しくなる条件はそれぞれ $a + c = b + d$ と $a + d = b + c$ です。移項すると $a - b = d - c$ と $a - b = c - d$ になるので、まとめると $|a - b| = |c - d|$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
a, b, c, d = map(int, input().split())
if abs(a - b) == abs(c - d):
    print("Yes")
else:
    print("No")
```
