## 問題の概要

長さ $n$ の正整数列 $a_1, \ldots, a_n$ があります。次の操作を好きな回数行えます。

- 添字 $i$ を選ぶ。**操作を始める前の** $a_i$ の最上位ビットの位置を $k$ として、$a_i$ の下位 $k + 1$ ビットを左に 1 つ巡回シフトする

たとえば $4 = (100)_2$ は $(100)_2 \to (001)_2 \to (010)_2 \to (100)_2 \to \cdots$ と変化します。

数列を広義単調増加にするのに必要な操作回数の最小値を求め、不可能なら $-1$ を出力する問題です。

- $1 \le n \le 2 \cdot 10^5$、$1 \le a_i \le 2 \cdot 10^5$、テストケースの $n$ の総和は $2 \cdot 10^5$ 以下

正確な問題文は[元の問題ページ](https://eolymp.com/compete/br25/problems/4)を見てください。

:::caution[本番での勘違い]
本番では「最上位ビット」を「最下位ビット」と読み違えていました。最下位ビットより下はすべて $0$ なので、その読み方だと操作は「最下位の $1$ を 1 つ動かすだけ」になります。これが正しい操作と一致するのは、$a_i$ が 2 の累乗のときと $2^x - 1$ のとき(どちらの読み方でも値が変わらない)くらいです。そのためサンプルに加えて、$a_i = 2^x - 1$ の Subtask 2 と $a_i \le 3$ の Subtask 3 にも正解してしまい、勘違いに気づけないまま AC できませんでした。以下は upsolve での解法です。
:::

## 解法

$a_i$ のビット長を $w_i$ とすると、操作は $a_i$ を $w_i$ ビット幅で回転させるだけなので、$a_i$ がとりうる値は

$$
a_i \text{ を } r \text{ 回回転させた値} \quad (0 \le r < w_i)
$$

の $w_i$ 通りで、そのときの操作回数は $r$ です。途中で最上位ビットが $0$ になっても、回転の幅は操作前のビット長のまま変わらないことに注意します。

各要素の候補は高々 $w_i$ 個しかないので、前から順に

$$
\mathrm{dp}_i[v] = a_i \text{ を値 } v \text{ にしたときの、} a_1, \ldots, a_i \text{ を広義単調増加にする最小操作回数}
$$

を候補ごとに持つ DP ができます。遷移は

$$
\mathrm{dp}_i[v] = r + \min_{u \le v} \mathrm{dp}_{i-1}[u]
$$

です。前の要素の候補と今の要素の候補をそれぞれ値でソートしておけば、$\min_{u \le v}$ は尺取りで前から最小値を更新していくだけで求まります。

答えは $\min_v \mathrm{dp}_n[v]$ で、これが $\infty$ なら $-1$ です。

$L = \lfloor \log_2 \max a_i \rfloor + 1$ とすると、候補は各要素で高々 $L$ 個なので、計算量はソートを含めて $O(n L \log L)$ です。

## 解答コード

<details>
<summary>Python(upsolve)</summary>

```python
INF = float("inf")
for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    dp = [(0, 0)]
    for a in A:
        w = a.bit_length()
        cand = []
        x = a
        for r in range(w):
            cand.append((x, r))
            x = (x << 1 | x >> (w - 1)) & ((1 << w) - 1)
        cand.sort()
        ndp = []
        best = INF
        p = 0
        for q, r in cand:
            while p < len(dp) and dp[p][0] <= q:
                best = min(best, dp[p][1])
                p += 1
            ndp.append((q, best + r))
        dp = ndp
    ans = min(y for _, y in dp)
    if ans == INF:
        print(-1)
    else:
        print(ans)
```

</details>

`dp` は (値, 最小操作回数) の組を値の昇順に並べたもので、`best` が「値が `q` 以下の前の候補のうちの最小操作回数」です。
