## 問題の概要

半角スペースだけからなる文字列 $S$ が与えられるので、その長さを出力する問題です。$1 \le |S| \le 100$ です。

## 解法

入力の 1 行をそのまま読み、長さを数えます。

注意が要るのは読み込み方です。スペースを区切りとして読み飛ばす方法では、$S$ を読めません。たとえば C++ の `cin >> S` は空白を読み飛ばすので、$S$ は空になってしまいます。C++ なら `getline(cin, S)` のように、行全体を読む必要があります。

Python の `input()` は行末の改行だけを取り除き、スペースはそのまま残します。そのため、`len(input())` で答えが求まります。逆に `input().split()` や `input().strip()` を使うと、スペースが消えてしまいます。

## 解答コード

<details>
<summary>Python</summary>

```python
print(len(input()))
```

</details>
