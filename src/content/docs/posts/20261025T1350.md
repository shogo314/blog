## 問題の概要

$N$ 個の地域があり、軍隊が地域 $i$ を通るときは、まず兵士 $B_i$ 人を守備隊として残し(その直後に $1$ 人以上残っていなければなりません)、そのあと兵士 $A_i$ 人が合流します。次の 2 種類のクエリを $Q$ 個処理する問題です($1 \le N, Q \le 200000$、$0 \le A_i, B_i \le 10^9$)。

- `1 i a b`:$A_i$ を $a$ に、$B_i$ を $b$ に変える。
- `2 l r`:地域 $l, l+1, \dots, r$ を順に通るとき、地域 $l$ に入る時点で必要な兵士の最小人数を答える。

## 解法

区間を通る過程を「入るときに必要な最小人数 $x$」と「ちょうど $x$ 人で入ったときに出ていく人数 $y$」の組 $(x, y)$ で表します。$x$ 人より多く入れば、その分だけ出ていく人数も増えるので、この 2 つで区間の通り方が決まります。

地域 $i$ 1 つだけなら、$B_i$ 人を残したあとに $1$ 人以上必要なので $x = B_i + 1$ で、そのとき $y = A_i + 1$ です。

区間 $(x_1, y_1)$ を通ったあとに区間 $(x_2, y_2)$ を通るとき、つなげた区間の組は次のようになります。

- $y_1 \ge x_2$ のとき:$x_1$ 人で入れば 2 つ目の区間にも入れるので、$(x_1, \ y_1 - x_2 + y_2)$。
- $y_1 < x_2$ のとき:2 つ目の区間に入るのに $x_2 - y_1$ 人足りないので、最初にその分多く入る必要があり、$(x_1 + x_2 - y_1, \ y_2)$。

この演算は結合的です(区間をつなげる順によらず、実際に通ったときの結果を表しているため)。単位元は $(0, 0)$ です。よって[セグメント木](/blog/posts/20261010T0123/)に載せれば、クエリ 1 は 1 点の更新、クエリ 2 は区間の積の $x$ で、それぞれ $O(\log N)$ で処理できます。

値は最大で $(10^9 + 1) \times 200000 \approx 2 \times 10^{14}$ 程度なので、64 bit 整数で足ります。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

struct M {
    using S = pl;
    S op(const S &l, const S &r) const {
        if (l.second >= r.first) {
            return {l.first, l.second - r.first + r.second};
        } else {
            return {l.first + r.first - l.second, r.second};
        }
    }
    S e() const {
        return {0, 0};
    }
};

void solve() {
    LL(N, Q);
    vec<M::S> init;
    init.reserve(N);
    rep(i, N) {
        LL(a, b);
        init.push_back({b + 1, a + 1});
    }
    SegTree<M> seg(init);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(i, a, b);
            seg.set(i - 1, {b + 1, a + 1});
        } else {
            LL(l, r);
            print(seg.prod(l - 1, r).first);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`SegTree<M>` は、モノイド `M` の演算 `op` と単位元 `e` を使うセグメント木です。要素の `first` が $x$(必要な最小人数)、`second` が $y$(出ていく人数)です。
