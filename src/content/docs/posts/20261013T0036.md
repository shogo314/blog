## 問題の概要

はじめすべて $0$ の長さ $N$ の数列 $A$ があります。「$k$ と整数 $x$ を選び、$k$ の倍数番目の要素すべてに $x$ を足す」という操作を $N$ 回以下行って、$A = (X_1, \dots, X_N)$ にする操作列を 1 つ答える問題です。ただし $|x| \le 10^{18}$ でなければなりません。

テストケースは $T$ 個あり、$N$ の総和は $3 \times 10^5$ 以下、$|X_i| \le 10^9$ です。

## 解法

### 小さい番号から決める

$k$ を選ぶ操作で変わるのは $A_k, A_{2k}, \dots$ なので、$k$ より小さい番号の要素は変わりません。そこで、$i = 1, 2, \dots, N$ の順に $A_i$ を合わせていきます。

$i$ を見る時点で、$A_i$ を変える操作は $i$ の約数 $k < i$ を選んだものだけで、それらはすでに済んでいます。したがって、今の $A_i$ と $X_i$ の差 $x = X_i - A_i$ を求めて、$k = i$ で $x$ を足せば $A_i = X_i$ になります。このあとの操作では $A_i$ は変わりません。

各 $i$ について操作は高々 1 回なので、操作は $N$ 回以下です。

### $|x|$ の大きさ

$i$ のときに足す値を $x_i$ とすると、$X_i = \sum_{d \mid i} x_d$ が成り立ちます。これをメビウスの反転公式で解くと、$x_i = \sum_{d \mid i} \mu(i / d) X_d$ となります。$\mu$ の値は $-1, 0, 1$ のどれかなので、$|x_i|$ は ($i$ の約数の個数)$\times 10^9$ 以下です。$3 \times 10^5$ 以下の整数の約数は多くても $180$ 個なので、$|x_i| \le 10^{18}$ を十分に満たします。

### 計算量

$k = i$ で足すときに書き換える要素は $\lfloor N / i \rfloor$ 個です。合計は $\sum_{i=1}^{N} N / i = O(N \log N)$ になります。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    ans = []
    for i in range(1, N + 1):
        k = A[i - 1]
        if k == 0:
            continue
        ans.append((i, k))
        for j in range(1, N // i + 1):
            A[i * j - 1] -= k
    print(len(ans))
    for i, j in ans:
        print(i, j)
```

`A` を「あと足す必要がある量」として持ち、操作のたびにそこから引いています。`k` は足す値 $x$ で、$0$ のときは操作を省いています。
