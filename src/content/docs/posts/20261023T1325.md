LIS(最長増加部分列)について、参考になる記事や資料をまとめました。

LIS(Longest Increasing Subsequence)は、数列の部分列のうち増加しているもので最長のもの、またはその長さです。素直な DP は $O(N^2)$ ですが、「長さ $k$ の増加部分列の末尾として考えられる最小の値」を配列で持ち、各要素の置き場所を二分探索で求めると $O(N \log N)$ になります。また、「$A_i$ で終わる増加部分列の最長の長さ」を値の座標についてのセグメント木や BIT で区間最大値として求める方法も $O(N \log N)$ で、重みつきの LIS や個数の数え上げに拡張しやすいです。

二分探索の方法では、狭義の増加(同じ値を許さない)なら `lower_bound`(Python では `bisect_left`)、広義の増加(同じ値を許す)なら `upper_bound`(`bisect_right`)を使います。資料によって「増加」がどちらを指すかが違うので注意してください。また、二分探索の方法で最後に残る配列は LIS そのものではありません。LIS を復元するには、各要素について直前の要素や、その要素で終わる LIS の長さを記録しておく必要があります。

## まず読むもの

- [LIS でも大活躍！ DP の配列使いまわしテクニックを特集](https://qiita.com/drken/items/68b8503ad4ffb469624c)(けんちょん、Qiita)
  - ナップサック DP の配列の使いまわしから始めて、LIS の二分探索による方法とセグメント木による方法を、どちらも「DP の配列を使いまわしたもの」として説明しています。重みつきの LIS である EDPC Q - Flowers も扱っています。C++ です。
  - コードは `lower_bound` を使う狭義の LIS で、広義の場合の書き換えや復元には触れていません。
- [最長増加部分列・最長共通部分列](https://ikatakos.com/pot/programming_algorithm/dynamic_programming/longest_common_subsequence)(いかたこのたこつぼ)
  - 二分探索による方法、復元、セグメント木による方法、増加部分列への最小の分解(Dilworth の定理)を、表で具体例を追いながら説明しています。狭義なら `bisect_left`、広義なら `bisect_right` を使うこと、セグメント木による方法で同じ値をどの順に処理するかも書かれています。後半は最長共通部分列(LCS)です。
  - 二分探索の Python のコードは、関数名(`longest_increasing_subsequence`)と呼び出し(`lis(...)`)が食い違っているので、そのままでは動きません。また、コメントの「a以下の値が初めて出てくるindex」は「a以上」の誤りです。

## 二分探索による方法と復元

- [LIS - 最長増加部分列](https://yamate11.github.io/blog/posts/2024/09-01-lis-with-recovery/)(yamate11のブログ)
  - 長さだけを求める方法と、各要素の直前の要素の添字を記録して LIS を 1 つ復元する方法を、手順として短くまとめています。狭義なら `lower_bound`、広義なら `upper_bound` と明記されています。C++ です。
  - 添字の書き方に 0 始まりと 1 始まりが混ざっています。復元の最後の手順の「$c_j > 0$ なら」は「$c_j \ge 0$ なら」と読んでください(先頭の要素 $a_0$ も直前の項になりえます)。
- [ABC354 F - Useless for LIS の公式解説](https://atcoder.jp/contests/abc354/editorial/10037)(AtCoder)
  - 各要素で終わる LIS の長さと始まる LIS の長さを、値についてのセグメント木で求め、「両者の和から $1$ を引いたものが LIS の長さに等しいか」で、その要素が LIS に含まれうるかを判定しています。セグメント木による方法の使い方の例として読めます。

## 応用(2 次元 LIS、Dilworth の定理)

2 つの値の両方が大きくなる列(箱の入れ子など)は、一方でソートしてからもう一方の LIS を求めることで解けます。このとき、1 つ目の値が同じものどうしがつながらないように、同じ値の中では 2 つ目の値の降順に並べるのが定番です。また、Dilworth の定理から、数列を狭義増加部分列に分けるときの最小の個数は、最長の広義減少部分列の長さに等しくなります。

- [ABC038 D - プレゼント のユーザ解説](https://atcoder.jp/contests/abc038/editorial/25791)(seekworser、AtCoder)
  - 箱を $w$ の昇順、同じ $w$ では $h$ の降順に並べ、$h$ の LIS を求める、という 2 次元 LIS の定番の解き方を短く説明しています。
- [競技プログラミングにおける最長部分増加列問題まとめ](https://blog.hamayanhamayan.com/entry/2017/04/26/151849)(はまやんはまやんはまやん)

## Python

- [bisect --- 配列二分法アルゴリズム](https://docs.python.org/ja/3/library/bisect.html)(Python 公式ドキュメント)
  - `bisect_left` は等しい要素の左側、`bisect_right` は右側の位置を返します。狭義の LIS なら `bisect_left`、広義の LIS なら `bisect_right` です。`key` 引数は Python 3.10 で追加されました。LIS そのものには触れていません。
- [最長増加部分列(LIS)](https://kyoroid.github.io/algorithm/dynamic_programming/lis.html)(Competitive programming notebook)
  - `bisect_left` を使う長さの計算と、各要素で終わる LIS の長さを記録して後ろから復元する方法を、Python の短いコードで示しています。
  - 番兵の既定値が `INF=10**9` なので、$10^9$ を含む入力では長さを正しく数えられません。INF をもっと大きくしてください。

## 百科事典・英語の資料

- [Longest increasing subsequence](https://en.wikipedia.org/wiki/Longest_increasing_subsequence)(英語版 Wikipedia)
  - $O(n \log n)$ のアルゴリズムを、復元つきの擬似コードと具体例で説明しています。ほかに、LCS への帰着、Erdős–Szekeres の定理、ランダムな順列の LIS の長さが約 $2\sqrt{n}$ になることなども載っています。日本語版の記事はありません。
  - 擬似コードは狭義の LIS ですが、本文では狭義か広義かを明記していません。
- [Longest increasing subsequence](https://cp-algorithms.com/dynamic_programming/longest_increasing_subsequence.html)(cp-algorithms)
  - $O(n^2)$ の DP、二分探索による $O(n \log n)$ の方法、セグメント木などのデータ構造による方法を、それぞれ復元の方法とあわせて説明しています(データ構造による方法の復元は省略)。広義の LIS、LIS の個数、増加しない部分列への最小の分解なども扱い、練習問題の一覧があります。
  - 広義の場合は「二分探索を少し変える」とだけ書かれています。`upper_bound` に変えればよいです。
- [Longest Increasing Subsequence](https://usaco.guide/gold/lis)(USACO Guide)
  - $O(N^2)$ と $O(N \log N)$ の方法、セグメント木による方法を説明し、交差しない線分の最大個数や増加部分列への最小の分解(Dilworth の定理)などの応用と問題の一覧があります。コードは Python で、狭義の LIS です。
- [Patience sorting](https://en.wikipedia.org/wiki/Patience_sorting)(英語版 Wikipedia)
  - カードを山に積んでいくソートで、山の数が LIS の長さに等しくなります。二分探索による方法と同じ考え方で、山の間にポインタを張って LIS を復元する方法も書かれています。
  - 本文では「新しいカード以上の山に置く」、擬似コードでは「新しいカードより大きい山に置く」となっていて、狭義と広義が食い違っています。
- [Dilworth's theorem](https://en.wikipedia.org/wiki/Dilworth%27s_theorem)(英語版 Wikipedia)
  - 半順序集合の最小の鎖分解の個数が最大の反鎖の大きさに等しいという定理と、その双対(Mirsky の定理)を証明つきで説明しています。LIS との関係は、Erdős–Szekeres の定理がこの定理の応用とみなせる、と一言触れているだけです。
