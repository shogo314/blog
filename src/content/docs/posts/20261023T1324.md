転倒数について、参考になる記事や資料をまとめました。

数列 $A$ の転倒数は、$i < j$ かつ $A_i > A_j$ を満たす組 $(i, j)$ の個数です。左から順に「自分より前にあって自分より大きい要素の個数」を BIT で数えて足していくと $O(N \log N)$ で求まります。マージソートの途中で、左半分と右半分にまたがる組を数える方法でも $O(N \log N)$ です。転倒数は、隣どうしの入れ替えで数列を昇順にするときの最小の回数(バブルソートの交換回数)に一致します。値の異なる隣どうしを入れ替えると転倒数はちょうど $1$ 増えるか $1$ 減り、昇順の列の転倒数は $0$ だからです。

BIT を使う方法では値をそのまま添字にするので、値が大きいときや負の値があるときは座標圧縮が必要です。同じ値の組は転倒に数えないので、「自分以下の値の個数」を引くようにします。また、転倒数は最大で $N(N-1)/2$ になり、$N = 10^5$ でも 32 bit 整数に収まらないので、答えは 64 bit 整数で持ってください。BIT そのものについては [BIT のリンク集](/blog/posts/20261010T0220/) も見てください。

## まず読むもの

- [転倒数](https://scrapbox.io/pocala-kyopro/%E8%BB%A2%E5%80%92%E6%95%B0)(pocala-kyopro、Scrapbox)
  - 例の数列で BIT に 1 を足していく様子を表で追いながら、「これまでに見た個数 − 自分以下の個数」で自分より前にある大きい値の個数が求まることを説明しています。C++ の実装つきです。
  - 値が $1$ 以上 $N$ 以下(順列)であることを前提にしていて、座標圧縮には触れていません。
- [BITで転倒数を求める](https://qiita.com/wisteria0410ss/items/296e0daa9e967ca71ed6)(wisteria0410ss、Qiita)
  - BIT による方法を擬似コードで説明し、座標圧縮で BIT の長さを値の種類数に抑える方法も書いています。最後に、転倒数がバブルソートの交換回数に一致する理由を補足しています。
  - 擬似コードで、答えに $t_j$ を足すだけの行に「BITを使ってO(log N)」というコメントがあります。BIT を使うのは 1 つ上の $b$ に $1$ を足す行で、コメントの位置がずれています。
- [Binary Indexed Tree (BIT) 総まとめ！区間加算や二次元BITまで](https://algo-logic.info/binary-indexed-tree/)(アルゴリズムロジック)
  - BIT の記事の一節で、転倒数の手順を短くまとめています。値が $1$ 以上であることを前提にしているので、$0$ があるときは $1$ を足すか座標圧縮してから使ってください。

## マージソートによる方法

- [転倒数](https://scrapbox.io/taq225algo/%E8%BB%A2%E5%80%92%E6%95%B0)(taq225algo、Scrapbox)
  - 列を半分に分けて「左半分の転倒数 + 右半分の転倒数 + またがる組の数」で求める分割統治と、座標圧縮した BIT による方法の両方を、Python の実装つきで説明しています。
  - BIT の節の式 $t'_{k+1} = \sum_{v < a_{k+1}} B[v]$ は、$t'_j$ の定義($a_i \le a_j$ の個数)に合わせると $v \le a_{k+1}$ が正しいです。コードは正しく `bit.sum(x+1)` で、等しい値まで数えています。
- [Count Inversions of an Array](https://www.geeksforgeeks.org/dsa/inversion-count-in-array-using-merge-sort/)(GeeksforGeeks、英語)
  - 全組を調べる $O(n^2)$ の方法と、マージソートでまたがる組を数える $O(n \log n)$ の方法を、C++・Java・Python などのコードで示しています。
  - コードは転倒数を `int` で持っているので、そのまま使うと大きな $n$ であふれます。

## AtCoder Algorithm Lectures

転倒数そのものを扱う講座はまだありませんが、関連する講座があります。

- [区間クエリのためのモノイド設計](https://info.atcoder.jp/entry/algorithm_lectures/range_query_monoid_design)
  - 「8.1 転倒数」の節で、順列の転倒数を区間和のセグメント木で求める方法を 2 通り説明しています。添字の順に処理して値を添字にする方法と、値の順に処理して位置を添字にする方法です。一般の列のときの座標圧縮や、同じ値の扱いにも触れています。

## 実装

- [inversion-counting.hpp](https://nyaannyaan.github.io/library/dp/inversion-counting.hpp)(Nyaan's Library)
  - 座標圧縮つきで転倒数を `long long` で返す `inversion_counting` と、隣どうしの入れ替えで列 $v$ を列 $w$ にする最小回数を返す `swap_distance` があります。ドキュメントはなく、コード中のコメントだけです。
- [Static Range Inversion Query](https://hitonanode.github.io/cplib-cpp/data_structure/static_range_inversion.hpp)(hitonanode's library)
  - 数列の区間 $[l, r)$ の転倒数にオンラインで答える実装で、時間 $O((N + Q)\sqrt{N})$、空間 $O(N\sqrt{N})$ です。$N = 10^5$ で約 128 MB 使うと書かれています。
