## 問題の概要

$n$ 個の整数 $a_1, \ldots, a_n$ が与えられるので、最大値と最小値の平均を切り捨てて出力する問題です($2 \le n \le 10^5$、$-10^9 \le a_i \le 10^9$)。ただし、ソースコードのどこにも数字 `0`〜`9` を使ってはいけません。

## 解法

計算は $\left\lfloor \frac{\max A + \min A}{2} \right\rfloor$ です。問題は $2$ で割るところで、`// 2` と書くと数字を使ってしまいます。

そこで、$2$ で割って切り捨てる代わりに、右に $1$ ビットシフトします。シフト量の $1$ には `True` を使います。Python では `True` が整数の $1$ として扱われるからです。

右シフトは負の数でも切り捨て(負の無限大方向への丸め)になるので、和が負のときもそのまま正しい答えになります。たとえば $-4 \gg 1 = -2$、$-3 \gg 1 = -2$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
A = list(map(int, input().split()))
print((max(A) + min(A)) >> True)
```

`>> True` が $2$ で割って切り捨てる処理です。

</details>
