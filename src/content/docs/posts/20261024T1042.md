## 問題の概要

$n$ 人が博物館に 1 回ずつ入って出ました。$2n$ 回の入退場の時刻はすべて異なります。各人 $i$ について、

- $a_i$:$i$ が入る前に出ていた人数
- $b_i$:$i$ が出たあとに入ってきた人数

が記録されています。すべての記録が正しくなる入退場の順番があるか判定する問題です($1 \le n \le 2 \times 10^5$、$0 \le a_i, b_i < n$)。

## 解法

### 入る順番と出るタイミング

$a_i$ は、入るのが遅い人ほど大きいか等しいです。よって、入る順番は $a_i$ の昇順です。$a_i$ が等しい人どうしの間では誰も出ていないので、その人たちの入る順番を入れ替えても、ほかの人の $a, b$ は変わりません。

$k$ 人目が入ってから $k + 1$ 人目が入るまでの間を「すき間 $k$」と呼びます(すき間 $n$ は最後の人が入ったあと)。$b_i$ 人があとから入ってくるので、人 $i$ はすき間 $n - b_i$ で出ます。同じすき間で出る人どうしの順番は、記録に影響しません。

こうして入退場の順番は(記録に影響しない入れ替えを除いて)決まるので、次の 2 つを満たすか調べれば十分です。人 $i$ が $k_i$ 番目に入るとします。

1. 入ってから出る:$k_i \le n - b_i$。
2. $a_i$ が正しい:$a_i$ は、$n - b_j \le k_i - 1$ である人 $j$ の人数に等しい。

$a_i$ が等しい人どうしの順番は 2. に影響しないので、1. を満たしやすい順にします。それは $b_i$ の大きい人(早く出る人)を先にする順です。

### 実装

$a_i$ の昇順、同じなら $b_i$ の降順に並べます。0-indexed で $i$ 番目の人は $k = i + 1$ 番目に入るので、1. は $i + 1 \le n - b$ です。

また、2. の人数は、すき間ごとに出る人数を数えて累積和をとれば求まります。$c_k$ を「すき間 $k$ 以下で出る人数」とすると、2. は $a = c_i$ です。

全員がこの 2 つを満たせば `Yes`、そうでなければ `No` です。計算量はソートの $O(n \log n)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
n = int(input())
ab = [tuple(map(int, input().split())) for i in range(n)]
ab.sort(key=lambda x: (x[0], -x[1]))
c = [0] * (n + 1)
for a, b in ab:
    c[n - b] += 1
for i in range(n):
    c[i + 1] += c[i]
for i, (a, b) in enumerate(ab):
    if i + 1 > n - b or a != c[i]:
        print("No")
        exit(0)
print("Yes")
```
