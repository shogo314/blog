## 問題の概要

文書 $1, \dots, n$ と、最初は空のプリンターのメモリがあります。$i$ 番目の操作 $s_i$ は次のいずれかです。

- `1`:文書 $i$ をメモリの一番上に積む
- `2`:メモリが空でなければ、一番上の文書を印刷してメモリから取り除く。空なら文書 $i$ を印刷する
- `3`:文書 $i$ を印刷する

すべての操作のあとで、一度も印刷されなかった文書の番号を昇順に出力してください($n$ の総和 $\le 2 \cdot 10^5$)。

## 解法

メモリは「最後に積んだものから取り出す」ので、スタックそのものです。操作を順にシミュレーションして、印刷された文書を記録すれば、残りが答えです。

- `1`:スタックに $i$ を push する
- `2`:スタックが空でなければ pop した文書を、空なら $i$ を印刷済みにする
- `3`:$i$ を印刷済みにする

なお、`2` でスタックが空でないときは、文書 $i$ 自身は印刷されません。`2` の操作では文書 $i$ はメモリにも入らないので、その文書が印刷されることはもうありません。

各操作は $O(1)$ なので、全体で $O(n)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    S = input()
    t = []
    l = []
    for i, c in enumerate(S):
        if c == "1":
            l.append(i)
        elif c == "2":
            if l:
                t.append(l.pop())
            else:
                t.append(i)
        else:
            t.append(i)
    ans = set(range(N)) - set(t)
    print(len(ans))
    print(*[i + 1 for i in sorted(ans)])
```

`l` がメモリのスタック、`t` が印刷された文書のリストです。文書番号は 0 始まりで持っておき、出力するときに 1 を足しています。$k = 0$ のときは `print(*[])` が空行を出力するので、そのままで大丈夫です。
