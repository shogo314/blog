## 問題の概要

$n$ 人の生徒が 1 台のプリンターで書類を印刷します。生徒 $i$ の書類の印刷には $t_i$ 秒かかります。プリンターは一度に 1 つの書類しか印刷できず、時刻 $0$ から休みなく順に印刷します。各生徒の待ち時間を「時刻 $0$ から自分の書類が印刷し終わるまでの時間」とするとき、印刷する順番をうまく決めて、待ち時間の合計の最小値を求める問題です($1 \le n \le 2 \times 10^5$、$1 \le t_i \le 10^6$)。

## 解法

**印刷時間の短い順に印刷する**のが最適です。

$j$ 番目に印刷する書類の印刷時間を $s_j$ とすると、$j$ 番目の生徒の待ち時間は $s_1 + s_2 + \dots + s_j$ です。待ち時間の合計では、$s_j$ は $j$ 番目以降の $n - j + 1$ 人の待ち時間に含まれるので、

$$
\sum_{j=1}^{n} (n - j + 1) \, s_j
$$

になります。前に印刷するものほど大きな係数が掛かるので、短いものを前に置けばよいです。

実際、隣り合う $s_j > s_{j+1}$ があれば、2 つを入れ替えると合計は $s_j - s_{j+1} > 0$ だけ減ります。そのため、最適な順番では印刷時間が短い順に並んでいます。

あとは $t$ をソートして[累積和](/blog/posts/20261012T0121/)をとり、その合計を出力すれば答えです。$O(n \log n)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
from itertools import accumulate

input()
print(sum(accumulate(sorted(list(map(int, input().split()))))))
```

`accumulate` でソート後の累積和、つまり各生徒の待ち時間を求め、その合計を出力しています。
