## 問題の概要

$N$ 頂点の木があり、辺 $i$ は頂点 $A_i$ と $B_i$ を結びます($N$ は奇数)。各 $i = 1, \dots, N - 1$ について、辺 $i$ を取り除いてできる 2 つの連結成分のうち、頂点数が多い方のすべての頂点 $v$ の $x_v$ に $i$ を足します。最終的な $x_1, \dots, x_N$ を求める問題です($3 \le N \le 2 \times 10^5 - 1$)。

## 解法

頂点 $1$ を根とする根付き木で考えます。辺 $i$ が親 $u$ と子 $v$ を結ぶとき、辺 $i$ を取り除いてできる連結成分は「$v$ の部分木」と「それ以外」です。$v$ の部分木の頂点数 $\mathrm{sz}_v$ は、葉の側から足し合わせれば全頂点について $O(N)$ で求められます。

- $2 \, \mathrm{sz}_v > N$ なら、$v$ の部分木の全頂点に $i$ を足します。
- そうでなければ、$v$ の部分木以外の全頂点に $i$ を足します。これは「全頂点に $i$ を足し、$v$ の部分木の全頂点から $i$ を引く」と言い換えられます。

どちらも「ある頂点の部分木全体に値を足す」操作になります(全頂点は根の部分木です)。これは木の上の[いもす法](/blog/posts/20261012T0121/)で処理できます。頂点 $w$ の部分木全体に $c$ を足すときは、配列の $w$ の位置にだけ $c$ を足しておきます。すべて記録したら、根から葉に向かって親の値を子に足していきます。すると、各頂点の値は根からその頂点までの経路上の記録の合計になります。これは、その頂点を部分木に含む頂点への加算の合計なので、求める $x_v$ です。

計算量は $O(N)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
G = [[] for _ in range(N)]
for i in range(1, N):
    a, b = map(int, input().split())
    G[a - 1].append((b - 1, i))
    G[b - 1].append((a - 1, i))
par = [-1] * N
pid = [0] * N
order = [0]
for u in order:
    for v, i in G[u]:
        if v != par[u]:
            par[v] = u
            pid[v] = i
            order.append(v)
sz = [1] * N
for v in reversed(order[1:]):
    sz[par[v]] += sz[v]
x = [0] * N
for v in order[1:]:
    i = pid[v]
    if sz[v] * 2 > N:
        x[v] += i
    else:
        x[0] += i
        x[v] -= i
for v in order[1:]:
    x[v] += x[par[v]]
print(*x)
```

頂点 $1$(コード上は `0`)から BFS して、`order` に訪問順、`par[v]` に親、`pid[v]` に親と結ぶ辺の番号を記録しています。`order` を逆順に見ると子が親より先に来るので、部分木のサイズ `sz` が求まります。最後に `order` の順に親の値を子に足すことで、いもす法の記録を伝えています。

<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/graph/tree.hpp"

void solve() {
    LL(N);
    Tree<> tree(N);
    tree.read();
    RootedTree<> rooted(tree, 0);
    vl sz(N, 1);
    for (ll u : rooted.postorder) {
        for (ll v : rooted.child[u]) {
            sz[u] += sz[v];
        }
    }
    vl ans(N, 0);
    for (auto e : rooted.edges()) {
        ll u = e.src;
        ll v = e.dst;
        if (rooted.depth[u] > rooted.depth[v]) {
            std::swap(u, v);
        }
        if (sz[v] * 2 > N) {
            ans[v] += e.id + 1;
        } else {
            ans[0] += e.id + 1;
            ans[v] -= e.id + 1;
        }
    }
    for (ll u : rooted.preorder) {
        for (ll v : rooted.child[u]) {
            ans[v] += ans[u];
        }
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`RootedTree` は頂点 `0` を根とする根付き木で、`postorder`(帰りがけ順)、`preorder`(行きがけ順)、`child`、`depth` を持っています。各辺について深い方の端点を `v` とし、`v` が子になるようにしています。辺の番号 `e.id` は 0 始まりなので、$1$ を足しています。
