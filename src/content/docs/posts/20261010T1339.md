## 問題の概要

$N \times N$ のマスに、$1$ から $N^2$ までの整数を 1 つずつ書き込みます(マス $(i, j)$ の値を $H_{i,j}$ とします)。各列の最大値の和を $S_1$、各行の最大値の和を $S_2$ とします。

整数 $X$ が与えられるので、$S_1 - S_2 = X$ となる書き込み方を 1 つ出力する問題です。存在しなければ $-1$ を出力します。$N^2$ の総和は $10^5$ 以下です。

## 解法

$X \ge 0$ の場合を考えます。$X < 0$ の場合は、$-X$ の答えを転置すれば行と列が入れ替わり、$S_1$ と $S_2$ が入れ替わるので求まります。

### $S_1 - S_2$ の上限

$F = \dfrac{N (N - 1)^2}{2}$ とすると、$S_1 - S_2 \le F$ です。

- **$S_2$ の下限**:行の最大値を小さい順に $r_1 < r_2 < \dots < r_N$ とします。最大値が小さいほうから $k$ 行には、$r_k$ 以下の相異なる数が $kN$ 個あるので、$r_k \ge kN$ です。よって $S_2 \ge N(1 + 2 + \dots + N)$ です。
- **$S_1$ の上限**:列の最大値は相異なるので、$S_1$ は大きいほうから $N$ 個の数の和 $N^2 + (N^2 - 1) + \dots + (N^2 - N + 1)$ 以下です。

この 2 つの差を計算すると $F$ になります。したがって、$|X| > F$ なら $-1$ です。

### 構築

対角線のマスの値を $l_1 < l_2 < \dots < l_N = N^2$ とし、$l_i \ge iN$ を満たすように決めます。残りの数は、小さい順に、対角線以外のマスへ行ごとに左から書き込みます。最後に、最下行の対角線以外の $N - 1$ マスだけ、左右の順を逆にします。

このとき、次のことがいえます。

- **行の最大値は $l_i$**:$i$ 行目の対角線以外のマスには、残りの数のうち小さいほうから $(i - 1)(N - 1) + 1$ 番目から $i(N - 1)$ 番目が入ります。$l_i$ より小さい残りの数は $l_i - 1 - (i - 1) \ge i(N - 1)$ 個あるので、これらはすべて $l_i$ より小さいです。よって $S_2 = l_1 + \dots + l_N$ です。
- **列の最大値は大きいほうから $N$ 個の数**:最下行の対角線以外のマスには、残りの数のうち大きいほうから $N - 1$ 個が入ります。左右を逆にしたので、大きいものほど左の列に入ります。大きいほうから $N$ 個の数のうち、対角線にあるものは $l_N, l_{N-1}, \dots$ と右下からつながっていて、その列の最大値になります。残りは最下行の左側の列に入り、どれもその列の最大値になります。よって $S_1$ は常に上限の値になります。

したがって $S_1 - S_2 = (\text{大きいほうから } N \text{ 個の和}) - (l_1 + \dots + l_N)$ です。

$l_i = iN$ とすると、$S_2$ が下限になるので差は $F$ です。そこから $l_i$ を増やすと、増やした分だけ差が減ります。$l_{N-1}, l_{N-2}, \dots$ の順に、$l_{i+1} - 1$ を超えない範囲で必要な分だけ増やしていきます。全部を限界まで増やすと、対角線が大きいほうから $N$ 個の数になって差は $0$ になります。そのため、$0$ 以上 $F$ 以下のどの $X$ でも作れます。

```python
from itertools import product, combinations

for _ in range(int(input())):
    N, X = map(int, input().split())
    t = abs(X)
    f = N * (N - 1) // 2 * (N - 1)
    if t > f:
        print(-1)
        continue
    f -= t
    l = [i * N for i in range(1, N + 1)]
    for i in reversed(range(N - 1)):
        if f == 0:
            continue
        p = min(f, l[i + 1] - l[i] - 1)
        l[i] += p
        f -= p
    s = set(range(1, N * N + 1))
    ans = [[-1] * N for i in range(N)]
    for i in range(N):
        s.remove(l[i])
        ans[i][i] = l[i]
    s = sorted(s, reverse=True)
    for i, j in product(range(N), repeat=2):
        if ans[i][j] != -1:
            continue
        ans[i][j] = s.pop()
    ans[-1][:-1] = reversed(ans[-1][:-1])
    if X < 0:
        for i, j in combinations(range(N), r=2):
            ans[i][j], ans[j][i] = ans[j][i], ans[i][j]
    for a in ans:
        print(*a)
```

コードは 0-indexed です。`f` は、差を $F$ から $X$ に減らすために対角線の値を増やす量の残りです。`ans[-1][:-1] = reversed(ans[-1][:-1])` で最下行を左右逆にしています。
