## 問題の概要

$2 \times 2$ のグリッドの各マスに `A`, `B`, `C`, `D` が 1 つずつ書かれています。`A` のマスと `D` のマスが辺を共有しているかどうかを判定する問題です。

## 解法

`A` か `D` が書かれたマスに印をつけます。印のついた 2 マスが同じ行か同じ列にあれば辺を共有していて、対角の位置にあれば辺を共有していません。

$2 \times 2$ のグリッドで辺を共有するマスの組は、上の行、下の行、左の列、右の列の 4 通りです。このどれかで 2 マスとも印がついていれば `Yes` です。

## 解答コード

<details>
<summary>C++</summary>

```cpp
#include "shogo-library/base/all"

void solve() {
    STR(S, T);
    aal<2, 2> tmp;
    tmp[0][0] = S[0] == 'A' || S[0] == 'D';
    tmp[0][1] = S[1] == 'A' || S[1] == 'D';
    tmp[1][0] = T[0] == 'A' || T[0] == 'D';
    tmp[1][1] = T[1] == 'A' || T[1] == 'D';
    if (tmp[0][0] * tmp[0][1] + tmp[1][0] * tmp[1][1] + tmp[0][0] * tmp[1][0] + tmp[0][1] * tmp[1][1]) {
        print("Yes");
    } else {
        print("No");
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`tmp[i][j]` は、そのマスに `A` か `D` が書かれていれば $1$、そうでなければ $0$ です。`if` の中の 4 つの積は、順に上の行、下の行、左の列、右の列の 2 マスがどちらも印つきかどうかを表しています。どれかが $1$ なら和が正になり、`Yes` を出力します。
