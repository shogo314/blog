## 問題の概要

$N$ 人が数直線上に立っていて、人 $i$ ははじめ座標 $S_i$ にいます。1 回の操作では、1 人を選んで座標 $x$ から $x - 1$ か $x + 1$ に動かします。移動先に人がいれば、その人は同時に座標 $x$ に移ります(2 人が入れ替わります)。

すべての人 $i$ が座標 $T_i$ にいる状態にするための操作回数の最小値を求める問題です($1 \le N \le 2 \times 10^5$、$0 \le S_i, T_i \le 10^9$、$S_i$ はそれぞれ相異なり、$T_i$ もそれぞれ相異なる)。

## 解法

### 操作を 2 種類に分ける

1 回の操作は、次のどちらかです。

- **空いている座標への移動**:1 人の座標が $1$ 変わります。人の並び順は変わりません。
- **隣の人との入れ替え**:隣り合う 2 人の並び順が入れ替わります。2 人がいる座標の集合は変わりません。

人の並び順の変化は入れ替えでしか起こらないので、入れ替えの回数は、はじめと最後で前後関係が逆になっている 2 人の組の個数以上必要です。これは、人を $S_i$ の小さい順に並べ、それぞれの $T$ での順位を書いた列の[転倒数](/blog/posts/20261023T1324/)です。

### 詰めた座標

空いている座標への移動の回数を見積もるため、人 $i$ について

$$
u_i = (\text{人 } i \text{ の座標}) - (\text{人 } i \text{ より左にいる人数})
$$

を考えます。座標がすべて $0$ 以上なら、$u_i$ は座標 $0$ から人 $i$ の手前までにある空いている座標の個数です。

- 空いている座標へ移動すると、動いた人の $u_i$ がちょうど $1$ 変わり、ほかの人の $u$ は変わりません。
- 入れ替えでは、右に動いた人は座標が $1$ 増えて左にいる人数も $1$ 増え、左に動いた人はどちらも $1$ 減るので、2 人とも $u$ は変わりません。

$S$ の中で $S_i$ より小さいものの個数を $r_i$、$T$ の中で $T_i$ より小さいものの個数を $r'_i$ とすると、はじめの $u_i$ は $S_i - r_i$、最後の $u_i$ は $T_i - r'_i$ です。したがって、空いている座標への移動は少なくとも $\sum_i |\text{最後の } u_i - \text{はじめの } u_i|$ 回必要です。

### 答え

1 回の操作で減らせるのは、転倒数と $\sum_i |u_i \text{ の差}|$ のどちらか一方だけで、それも $1$ ずつです。したがって、答えは少なくとも

$$
(\text{転倒数}) + \sum_i |\text{最後の } u_i - \text{はじめの } u_i|
$$

です。実はこの回数で必ず達成でき、これが答えになります。現在の状態で、上の値を $1$ 減らす操作が必ずあることを示します。以下、目標の $u_i$ を $u'_i$ と書きます。左から並べたとき $u$ は広義単調増加で、2 人の $u$ が等しいのは座標が隣り合っているときです。$u'$ も目標の並び順で広義単調増加です。

- **$u_i < u'_i$ の人がいるとき**:そのような人のうち最も右にいる人を $i$ とします。$i$ の右隣の座標が空いていれば、$i$ を右に動かすと $u_i$ が $u'_i$ に $1$ 近づきます。右隣に人 $j$ がいるとき、$u_j = u_i$ です。$j$ は $i$ より右にいるので $u_j \ge u'_j$ で、$u'_j \le u_j = u_i < u'_i$ です。目標では $u'$ が並び順に広義単調増加なので、$j$ は $i$ より左に来るはずです。$i$ と $j$ を入れ替えると、転倒数が $1$ 減ります。
- **$u_i > u'_i$ の人だけがいるとき**:左右を逆にして同様です。
- **すべての人で $u_i = u'_i$ のとき**:転倒数が正なら、目標と前後が逆の隣り合う 2 人 $i$(左)、$j$(右)がいます。$u_i \le u_j$ かつ $u'_j \le u'_i$ なので $u_i = u_j$ となり、2 人は座標が隣り合っています。入れ替えれば転倒数が $1$ 減ります。

$S$ と $T$ をそれぞれソートして順位を求め、転倒数を BIT などで数えれば、計算量は $O(N \log N)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
S = list(map(int, input().split()))
T = list(map(int, input().split()))
os = sorted(range(N), key=S.__getitem__)
ot = sorted(range(N), key=T.__getitem__)
rs = [0] * N
rt = [0] * N
for k in range(N):
    rs[os[k]] = k
    rt[ot[k]] = k
ans = 0
bit = [0] * (N + 1)
for k, i in enumerate(os):
    x = rt[i] + 1
    c = 0
    while x > 0:
        c += bit[x]
        x -= x & -x
    ans += k - c
    x = rt[i] + 1
    while x <= N:
        bit[x] += 1
        x += x & -x
for i in range(N):
    ans += abs((T[i] - rt[i]) - (S[i] - rs[i]))
print(ans)
```

`os` は人を $S_i$ の小さい順に並べたもので、`rs[i]` は人 $i$ の $S$ での順位(0 始まり)、つまり $S_i$ より小さい $S$ の個数です。`rt` も同様に $T$ での順位です。

転倒数は、`os` の順に人を見ながら、それまでに見た人のうち $T$ での順位が人 $i$ より小さい人数 `c` を [BIT](/blog/posts/20261010T0220/) で数え、`k - c`(順位が大きい人数)を足して求めています。最後に $|u'_i - u_i|$ を足しています。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/others/inversion-number.hpp"
#include "shogo-library/utility/vector_func.hpp"

void solve() {
    LL(N);
    VL(S, N);
    VL(T, N);
    vl rs = rank(S), rt = rank(T);
    ll ans = inversion_number(select(rt, argsort(S)));
    rep(i, N) ans += abs((T[i] - rt[i]) - (S[i] - rs[i]));
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`rank(S)` は各要素の $S$ での順位(0 始まり)、`argsort(S)` は $S$ の小さい順に並べた添字の列です。`select(rt, argsort(S))` で、人を $S$ の小さい順に並べたときの $T$ での順位の列を作り、`inversion_number` でその転倒数を求めています。`inversion_number` はマージソートで転倒数を数えます。
