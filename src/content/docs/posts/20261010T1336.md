## 問題の概要

$N$ 個の餅があり、$i$ 番目の餅の大きさは $A_i$ です。まだ使っていない餅を 2 個選んで 1 組にできますが、上に置く餅は下に置く餅より真に大きくなければなりません。作れる組の最大数を求める問題です。

テストケースは $T \le 2 \times 10^5$ 個あり、$N$ の総和は $2 \times 10^5$ 以下です。

## 解法

$A$ を小さい順に並べ替えておきます。

### $k$ 組作れるかの判定

$k$ 組作れるなら、**小さいほうから $k$ 個を下に、大きいほうから $k$ 個を上に、それぞれ小さい順に組にしても作れます**。つまり、すべての $i$ ($1 \le i \le k$) で $A_i < A_{N - k + i}$ が成り立つかを調べれば判定できます。

理由を説明します。$k$ 組作れたとして、下の餅を小さい順に $b_1 \le \dots \le b_k$、上の餅を小さい順に $t_1 \le \dots \le t_k$ とします。

- 下の餅のうち大きいほうから $k - i + 1$ 個は、どれも $b_i$ 以上です。その上の餅は、それより真に大きいので $b_i$ より大きくなります。よって、$b_i$ より大きい上の餅は $k - i + 1$ 個以上あり、$t_i > b_i$ です。
- 小さいほうから $i$ 番目の $A_i$ は $b_i$ 以下、大きいほうから数えた $A_{N - k + i}$ は $t_i$ 以上です。

まとめると $A_i \le b_i < t_i \le A_{N - k + i}$ が成り立ちます。

### 二分探索

$k$ 組作れるなら、そこから 1 組外せば $k - 1$ 組も作れます。そのため、作れる最大の $k$ を二分探索で求められます。$k$ は $\lfloor N / 2 \rfloor$ 以下です。

計算量は、並べ替えと二分探索で $O(N \log N)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    A.sort()
    ok = 0
    ng = (N + 2) // 2
    while ok + 1 < ng:
        mid = (ok + ng) // 2
        if all(A[i] < A[N - mid + i] for i in range(mid)):
            ok = mid
        else:
            ng = mid
    print(ok)
```

二分探索では、`ok` 組は作れて、`ng` 組は作れない、という状態を保っています。`ng` の初期値 $\lfloor N / 2 \rfloor + 1$ は、どうやっても作れない組数です。
