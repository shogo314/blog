## 問題の概要

$N$ 棟の建物を建てます。建物 $i$ の高さは $1$ 以上 $A_i$ 以下の整数にでき、高さが $h$ の建物 1 棟につき、都市の完成度が $B_h$ 増えます。完成度の合計の最大値を求める問題です($1 \le A_i, B_h \le 10^5$、$M = \max A_i$ として、全テストケースの $N + M$ の総和は $2 \times 10^5$ 以下)。

## 解法

建物どうしは影響し合わないので、建物ごとに完成度の増え方が最大になる高さを選べばよいです。建物 $i$ で得られる最大値は $\max(B_1, \dots, B_{A_i})$ です。

$B$ の先頭からの最大値(累積 max)$C_h = \max(B_1, \dots, B_h)$ を前計算しておけば、答えは $C_{A_1} + \dots + C_{A_N}$ です。計算量は $O(N + M)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))
    for i in range(1, len(B)):
        B[i] = max(B[i], B[i - 1])
    print(sum(B[a - 1] for a in A))
```

`B` をその場で累積 max に書き換えています。リストは 0 始まりなので、$C_{A_i}$ は `B[a - 1]` です。
