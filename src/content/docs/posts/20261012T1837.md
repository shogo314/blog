## 問題の概要

長さ $N$ の非負整数列 $A$ に対して、次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。

- `1 i x`:$A_i$ を $x$ に変更する。
- `2 l r x`:$i = l, \dots, r$ の順に、$A_i = 0$ なら $x \leftarrow x \bmod 998244353$、$A_i > 0$ なら $x \leftarrow x + A_i$ とする。最終的な $x$ を出力する。

## 解法

$p = 998244353$ とします。区間 $[l, r]$ に $0$ が含まれないなら、答えは $x + \sum_{i=l}^{r} A_i$ です。

$0$ が含まれる場合、最後の $0$ の位置を $m$ とします。途中で $p$ で割った余りをとっても、その後の値を $p$ で割った余りは変わりません。位置 $m$ では余りをとるので、その時点の値は $\left(x + \sum_{i=l}^{m-1} A_i\right) \bmod p$ になります。その後は $\sum_{i=m+1}^{r} A_i$ を足すだけです。

そこで、[セグメント木](/blog/posts/20261010T0123/)の各ノードに担当区間について次の値を持たせます。

- $X$:$0$ を含むかどうかと、含む場合は最後の $0$ より前の要素の和を $p$ で割った余り
- $Y$:最後の $0$ より後の要素の和($0$ を含まなければ区間全体の和)

隣り合う区間 $L$(左)と $R$(右)をつなげるとき、$R$ が $0$ を含むなら、最後の $0$ は $R$ の中にあります。その前の要素は $L$ 全体と $R$ の最後の $0$ より前の部分なので、$X = (L \text{ の総和} + X^R) \bmod p$、$Y = Y^R$ です。$L$ の総和を $p$ で割った余りは、$L$ が $0$ を含むかどうかによらず $X^L + Y^L$ で求まります($0$ を含まないなら $X^L$ を $0$ とみなします)。$R$ が $0$ を含まないなら、$X = X^L$、$Y = Y^L + Y^R$ です。

答えは、区間が $0$ を含むなら $(x + X) \bmod p + Y$、含まなければ $x + Y$ です。$Y$ は最大で $2 \times 10^5 \times 10^9 = 2 \times 10^{14}$ 程度なので、64 ビット整数に収まります。全体の計算量は $O(N + Q \log N)$ です。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"
#include "shogo-library/math/modint.hpp"

using mint = modint998244353;

struct AALC0001H {
    struct S {
        std::optional<mint> x;
        ll y;
        S() : x{}, y{} {}
        S(ll f) : x{}, y{} {
            if (f == 0)
                x = 0;
            else
                y = f;
        }
    };
    static S op(const S &a, const S &b) {
        S res = S{};
        if (b.x.has_value()) {
            res.x = a.x.value_or(0) + a.y + b.x.value();
            res.y = b.y;
        } else {
            res.x = a.x;
            res.y = a.y + b.y;
        }
        return res;
    }
    static S e() { return S(); }
};

void solve() {
    LL(N, Q);
    VL(A, N);
    vec<AALC0001H::S> init;
    init.reserve(N);
    rep(i, N)
        init.emplace_back(A[i]);
    SegTree<AALC0001H> seg(init);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(i, x);
            seg.set(i - 1, {x});
        } else if (q == 2) {
            LL(l, r, x);
            auto p = seg.prod(l - 1, r);
            ll ans = x;
            if (p.x.has_value()) {
                ans = (ans + p.x.value()).value();
            }
            ans += p.y;
            print(ans);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`SegTree` には、要素の型 `S`、演算 `op`、単位元 `e` をまとめた構造体を渡します。上の $X$ を `std::optional<mint>` の `x` で表し、$0$ を含まないことを値がないことで表しています。$Y$ は `ll` の `y` です。
