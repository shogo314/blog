## 問題の概要

長さ $n$ の数列 $a$ と整数 $k$ が与えられます。連続する部分列 $a_l, \ldots, a_r$ のうち、総和が $k$ で割り切れるものの個数を求める問題です($n \le 10^5$、$k \le 10^9$、$0 \le a_i \le 10^9$)。

## 解法

累積和を $S_0 = 0$、$S_i = a_1 + \cdots + a_i$ とすると、区間 $[l, r]$ の総和は $S_r - S_{l-1}$ です。これが $k$ で割り切れるのは

$$
S_r \equiv S_{l-1} \pmod{k}
$$

のときです。つまり、$0 \le i < j \le n$ で $S_i \bmod k$ と $S_j \bmod k$ が等しい組 $(i, j)$ の個数が答えです。

$j = 0, 1, \ldots, n$ の順に見ていき、それまでに出てきた余りの個数を数えておけば、各 $j$ について「$S_j \bmod k$ と同じ余りの $S_i$ が前に何個あったか」がすぐに分かります。全体で $O(n)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
from collections import Counter

N, K = map(int, input().split())
A = list(map(int, input().split()))
t = 0
C = Counter()
C[0] += 1
ans = 0
for a in A:
    t += a
    t %= K
    ans += C[t]
    C[t] += 1
print(ans)
```

`t` が累積和を $k$ で割った余り、`C` が余りごとの出現回数です。最初に `C[0] += 1` で $S_0 = 0$ の分を数えておき、各要素を足すたびに同じ余りの個数を答えに加えています。

$k$ は最大 $10^9$ なので、配列ではなく `Counter`(辞書)で数えています。
