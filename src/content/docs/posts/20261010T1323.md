## 問題の概要

正の整数 $a, b$ に対して、$a$ の十進表記を $b$ 回つなげた整数を $\mathrm{rep}(a, b)$ とします。たとえば $\mathrm{rep}(31, 4) = 31313131$ です。

長さ $N$ の正整数列 $A$ が与えられるので、

$$
\prod_{1 \le i < j \le N} \mathrm{rep}(A_i, A_j)
$$

を $998244353$ で割った余りを求める問題です。$A_i \le 10^9$ で、$N$ の総和は $2 \times 10^5$ 以下です。

## 解法

### rep を式で表す

$a$ が $k$ 桁のとき、$a$ を $b$ 回つなげることは、$a$ に $1 + 10^k + 10^{2k} + \dots + 10^{(b-1)k}$ を掛けることと同じです。等比数列の和を使うと

$$
\mathrm{rep}(a, b) = a \cdot \frac{10^{kb} - 1}{10^k - 1}
$$

です。以下、$k$ 桁の数を $b$ 回つなげたときに掛かる部分を $f_k(b) = \dfrac{10^{kb} - 1}{10^k - 1}$ と書きます。

### 積を 2 つに分ける

$A_i$ の桁数を $k_i$ とすると、求める積は

$$
\prod_{i < j} A_i \cdot f_{k_i}(A_j) = \left( \prod_{i < j} A_i \right) \left( \prod_{i < j} f_{k_i}(A_j) \right)
$$

と分けられます。

前半では、$A_i$ は自分より後ろの $j$ の個数だけ掛かるので、$\prod_i A_i^{N - i}$ です。

後半は、$j$ ごとにまとめます。$A_i \le 10^9$ なので桁数 $k$ は $1$ から $10$ までしかありません。$i < j$ で桁数が $k$ のものの個数を $c_{j,k}$ とすると、後半は

$$
\prod_j \prod_{k=1}^{10} f_k(A_j)^{c_{j,k}}
$$

です。$c_{j,k}$ は桁数ごとの個数を数えながら $j$ を動かせば求まります。$f_k(A_j)$ は $1$ つの $j$ につき $10$ 通りしかないので、全体で $O(10 N \log A)$ 回程度の計算で済みます。

### $f_k(b)$ を $998244353$ で割った余り

$f_k(b)$ は割り算を含みます。$10^k - 1$ の逆元を使ってもよいのですが、解答コードでは逆元を使わずに計算しています。

$M = 998244353$、$d = 10^k - 1$、$X = 10^{kb} - 1$ とします。$X$ は $d$ で割り切れます。$X$ を $dM$ で割った余りを $r$ とすると、$X = q \cdot dM + r$ と書けて、$r$ も $d$ で割り切れます。両辺を $d$ で割ると

$$
\frac{X}{d} = qM + \frac{r}{d}
$$

なので、$\dfrac{X}{d}$ を $M$ で割った余りは $\dfrac{r}{d}$ を $M$ で割った余りと同じです。つまり、$10^{kb}$ を $dM$ を法として計算し、$1$ を引いてから $d$ で割れば、$f_k(b)$ を $M$ で割った余りが求まります。

## 解答コード

<details>
<summary>Python</summary>

```python
MOD = 998244353
for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    ans = 1
    d = [0] * 11
    for i in range(N):
        ans *= pow(A[i], N - i - 1, MOD)
        ans %= MOD
        d[len(str(A[i]))] += 1
    for i in reversed(range(N)):
        d[len(str(A[i]))] -= 1
        for j in range(1, 11):
            if d[j] == 0:
                continue
            b = 10**j - 1
            x = pow(10, j * A[i], b * MOD)
            x -= 1
            x %= b * MOD
            assert x % b == 0
            x //= b
            ans *= pow(x, d[j], MOD)
            ans %= MOD
    print(ans)
```

最初のループで前半の積を計算し、桁数ごとの個数 `d` を数えます。2 つ目のループでは後ろから見ていき、`d` から自分を引くことで、`d[j]` が「自分より前にある $j$ 桁の数の個数」になるようにしています。
