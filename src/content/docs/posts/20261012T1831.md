## 問題の概要

長さ $N$ の非負整数列 $A$ に対して、次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。

- `1 l r x`:$A_l, \dots, A_r$ のそれぞれに $x$ を足す。
- `2 l r`:$\min(A_l, \dots, A_r)$ を出力する。

## 解法

区間への加算と区間の最小値の取得なので、遅延評価セグメント木を使います。区間 $[l, r]$ の全要素に $x$ を足すと、その区間の最小値もちょうど $x$ 増えます。そのため、各ノードには「担当区間の最小値」だけを持たせ、作用は「$x$ を足す」、作用の合成は「足す値の和」とすればよいです。

どちらの操作も $O(\log N)$ なので、全体の計算量は $O(N + Q \log N)$ です。

## 解答コード

<details>
<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/lazy-segtree.hpp"

void solve() {
    LL(N, Q);
    VL(A, N);
    RAddMinQ<ll> seg(A);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(l, r, x);
            seg.apply(l - 1, r, x);
        } else {
            LL(l, r);
            print(seg.prod(l - 1, r));
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`RAddMinQ<ll>` は区間加算・区間最小値の遅延評価セグメント木です。`apply(l, r, x)` と `prod(l, r)` は 0 始まりの半開区間 $[l, r)$ を対象にします。
