## 問題の概要

英小文字からなる長さ $N$ の文字列 $S$ が与えられます。$S$ が `ai` を部分文字列(連続する部分)として含めば `AI slop`、含まなければ `Human made` と出力する問題です。

テストケースは $T \le 10^5$ 個あり、$N$ の総和は $5 \times 10^5$ 以下です。

## 解法

$S$ に `ai` が含まれるかを調べるだけです。

`a` と `i` がどちらも含まれていても、`a` のすぐ後ろに `i` が来ていなければ条件を満たしません(たとえば `artificialintelligence` は `Human made` です)。隣り合う 2 文字が `a`、`i` の順になっている場所を探します。

Python では `"ai" in S` で、`ai` が部分文字列として含まれるかを判定できます。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    S = input()
    if "ai" in S:
        print("AI slop")
    else:
        print("Human made")
```
