## 問題の概要

長さ $N$ の整数列 $A$ の、長さ $K$ の連続部分列をちょうど 1 回だけ選んで昇順にソートします。その結果 $A$ 全体を昇順にできるかを判定する問題です($1 \le K < N \le 2 \times 10^5$)。

## 解法

$A$ を昇順にソートした列を $S$ とします。区間 $[i, i + K)$ をソートして $A$ 全体が $S$ になるのは

- 区間より前が $S$ と一致している($A_j = S_j$, $j < i$)
- 区間より後ろが $S$ と一致している($A_j = S_j$, $j \ge i + K$)

のときです。このとき、区間の中の値の集まりも $S$ の対応する部分と一致するので、区間をソートすれば $S$ になります。逆に、区間の外は操作で変わらないので、この 2 つは必要です。

そこで

- $L_i$ = 先頭から $i$ 個がすべて $S$ と一致しているか
- $R_i$ = 位置 $i$ 以降がすべて $S$ と一致しているか

を前と後ろから求めておき、$L_i$ かつ $R_{i+K}$ となる $i$ があるかを調べます。計算量はソートの $O(N \log N)$ です。

:::tip[別の見方]
$A_j \ne S_j$ となる位置(ずれている位置)を考えると、上の条件は「ずれている位置がすべて 1 つの長さ $K$ の区間に収まる」ということです。$K < N$ なので、ずれている位置の最初から最後までの長さが $K$ 以下なら Yes になります(ずれがなければもちろん Yes)。下の Uiua のコードはこの考え方で書いています。
:::

## 解答コード

<details>
<summary>Python</summary>

```python
N, K = map(int, input().split())
A = list(map(int, input().split()))
s = sorted(A)
l = [True]
for i in range(N):
    l.append(l[-1] and A[i] == s[i])
r = [True]
for i in reversed(range(N)):
    r.append(r[-1] and A[i] == s[i])
r.reverse()
if any(l[i] and r[i + K] for i in range(N - K + 1)):
    print("Yes")
else:
    print("No")
```
