## 問題の概要

長さ $N$ の整数列 $A$ に対して、次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 10^5$, $-10^9 \le A_i \le 10^9$)。

- `1 i x`:$A_i$ を $x$ に変更する。
- `2 l r`:$(A_l, \dots, A_r)$ から、互いに重ならない空でない連続部分列を $0$ 個以上 $2$ 個以下選ぶ。選んだ部分列の要素の総和の最大値を出力する。

## 解法

連続部分列を 1 個選ぶ場合(最大部分配列問題)は、セグメント木の各ノードに「区間全体の和」「接頭辞の和の最大値」「接尾辞の和の最大値」「連続部分列の和の最大値」を持たせる方法が知られています。これを 2 個まで選べるように広げます。

選ぶ連続部分列の個数の上限 $k$($k = 1, 2$)と、区間の端に接する部分列があるかどうかで、次の 8 つの値を持たせます。いずれも和の最大値です。

| 値 | 左端に接する部分列 | 右端に接する部分列 |
| --- | --- | --- |
| $\mathrm{lr}_k$ | あり | あり |
| $\mathrm{l}_k$ | あり | なくてもよい |
| $\mathrm{r}_k$ | なくてもよい | あり |
| $\mathrm{z}_k$ | なくてもよい | なくてもよい |

$k = 1$ で左右両端に接するのは区間全体なので、$\mathrm{lr}_1$ は区間全体の和です。

隣り合う区間 $X$(左)と $Y$(右)をつなげるときは、境目をまたぐ部分列があるかどうかで場合分けします。またぐ部分列は、$X$ の右端に接する部分列と $Y$ の左端に接する部分列がつながったものです。そのため、個数は $X$ 側と $Y$ 側の合計より 1 少なくなります。たとえば $\mathrm{z}_2$ は次の候補の最大値です。

- 境目をまたがない:$\mathrm{z}_2^X$、$\mathrm{z}_2^Y$、$\mathrm{z}_1^X + \mathrm{z}_1^Y$
- 境目をまたぐ:$\mathrm{r}_2^X + \mathrm{l}_1^Y$、$\mathrm{r}_1^X + \mathrm{l}_2^Y$

ほかの値も同じように、「$X$ 側で左端の条件を満たし、$Y$ 側で右端の条件を満たす」組み合わせを列挙すれば求まります。部分列を $0$ 個選ぶこともできるので、最大値は $0$ との最大をとっておきます。答えは 8 つの値と $0$ の最大値です。

全体の計算量は $O(N + Q \log N)$ です。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

struct AALC0001I {
    struct S {
        ll lr1, l1, r1, z1, lr2, l2, r2, z2;
        S() {
            lr1 = l1 = r1 = z1 = lr2 = l2 = r2 = z2 = 0;
        }
        S(ll a) {
            lr1 = l1 = r1 = z1 = lr2 = l2 = r2 = z2 = a;
        }
        ll ans() const {
            ll res = 0;
            chmax(res, lr1);
            chmax(res, l1);
            chmax(res, r1);
            chmax(res, z1);
            chmax(res, lr2);
            chmax(res, l2);
            chmax(res, r2);
            chmax(res, z2);
            return res;
        }
    };
    static S op(const S &a, const S &b) {
        S res{};
        res.lr1 = a.lr1 + b.lr1;
        chmax(res.l1, a.l1);
        chmax(res.l1, a.lr1 + b.l1);
        chmax(res.r1, b.r1);
        chmax(res.r1, a.r1 + b.lr1);
        chmax(res.z1, a.z1);
        chmax(res.z1, b.z1);
        chmax(res.z1, a.r1 + b.l1);
        chmax(res.lr2, a.l1 + b.r1);
        chmax(res.lr2, a.lr1 + b.lr2);
        chmax(res.lr2, a.lr2 + b.lr1);
        chmax(res.l2, a.l2);
        chmax(res.l2, a.lr1 + b.l2);
        chmax(res.l2, a.lr2 + b.l1);
        chmax(res.l2, a.l1 + b.z1);
        chmax(res.r2, b.r2);
        chmax(res.r2, a.r2 + b.lr1);
        chmax(res.r2, a.r1 + b.lr2);
        chmax(res.r2, a.z1 + b.r1);
        chmax(res.z2, a.z2);
        chmax(res.z2, b.z2);
        chmax(res.z2, a.z1 + b.z1);
        chmax(res.z2, a.r2 + b.l1);
        chmax(res.z2, a.r1 + b.l2);
        return res;
    }
    static S e() { return S(); }
};

void solve() {
    LL(N, Q);
    VL(A, N);
    vec<AALC0001I::S> init;
    init.reserve(N);
    rep(i, N)
        init.emplace_back(A[i]);
    SegTree<AALC0001I> seg(init);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(i, x);
            seg.set(i - 1, {x});
        } else if (q == 2) {
            LL(l, r);
            print(seg.prod(l - 1, r).ans());
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`SegTree` には、要素の型 `S`、演算 `op`、単位元 `e` をまとめた構造体を渡します。`op` では結果を $0$ で初期化してから `chmax` で候補を入れているので、各値は自然に $0$ 以上になります。
