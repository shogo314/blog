## 問題の概要

`D` と `M` からなる長さ $2n - 1$ の文字列 $s$ が与えられます。長さ $n$ 以上の区間で、`M` をちょうど $x$ 個含むものが $n$ 個以上あるような $x$ を 1 つ求める問題です($n \le 10^6$)。そのような $x$ は必ず存在します。

問題文では「$n$ 人の検査員がそれぞれ異なる区間を担当し、全員が同じ個数の `M` を検査する」という設定になっています。

たとえば $n = 3$、$s = $ `MDMDM` のとき、`M` を $2$ 個含む長さ $3$ 以上の区間は $[1, 3], [3, 5], [1, 4], [2, 5]$ の $4$ 個あるので、$x = 2$ が答えです。

## 解法

長さ $n$ 以上の区間はおよそ $\frac{n^2}{2}$ 個あるので、すべて数えることはできません。そこで、条件を満たすと保証できる $x$ を 1 つ見つけます。

**長さ $n$ の区間に含まれる `M` の個数の最大値を $x$ とすると、これが答えになります。**

### $x$ が条件を満たす理由

最大を達成する区間を $[p, p + n - 1]$ とします。区間を 1 文字伸ばしたり縮めたりしても、`M` の個数は $0$ か $1$ しか変わりません。そのため、$x$ 以下の区間から $x$ 以上の区間まで 1 文字ずつ動かせば、途中に必ずちょうど $x$ の区間があります。

これを使って、ちょうど $x$ 個の区間を $n$ 個見つけます。

- **左端 $l < p$ のそれぞれ($p - 1$ 個):** 右端を $l + n - 1$ から $p + n - 1$ まで伸ばしていきます。最初の $[l, l + n - 1]$ は長さ $n$ なので `M` は $x$ 個以下、最後の $[l, p + n - 1]$ は最大の区間を含むので $x$ 個以上です。途中に `M` がちょうど $x$ 個の区間があります。
- **右端 $r \ge p + n - 1$ のそれぞれ($n - p + 1$ 個):** 左端を $p$ から $r - n + 1$ まで縮めていきます。最初の $[p, r]$ は最大の区間を含むので $x$ 個以上、最後の $[r - n + 1, r]$ は長さ $n$ なので $x$ 個以下です。こちらも途中にちょうど $x$ 個の区間があります。

前者の区間は左端が $p$ より前、後者は左端が $p$ 以降なので、すべて異なります。どれも長さは $n$ 以上で、個数は $(p - 1) + (n - p + 1) = n$ です。

:::tip[ポイント]
すべての $x$ について数えるのではなく、「その区間を含めば $x$ 以上」「長さ $n$ なら $x$ 以下」の 2 つが言える極端な値(最大値)を選ぶのがポイントです。あとは 1 ずつしか変わらない性質から、ちょうど $x$ の区間の存在が言えます。
:::

### 計算量

長さ $n$ の区間は $n$ 個あり、スライディングウィンドウで `M` の個数を更新しながら最大値を求めれば $O(n)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
S = input()
ans = t = S[:N].count("M")
for i in range(N - 1):
    t -= S[i] == "M"
    t += S[i + N] == "M"
    ans = max(ans, t)
print(ans)
```

`t` が今の区間に含まれる `M` の個数です。区間を 1 つ右にずらすとき、左端から外れる `S[i]` と右端に入る `S[i + N]` の分だけ `t` を更新しています。

</details>
