## 問題の概要

長さが $3$ 以上で、公差が正の、正整数からなる等差数列を良い数列と呼びます。良い数列のうち、要素の総積が $N$ 以下であるものの個数を求める問題です($1 \le N \le 10^{18}$)。

## 解法

良い数列は、長さ $l$、初項 $a$、公差 $d$ で決まります($l \ge 3$、$a \ge 1$、$d \ge 1$)。総積は

$$
a (a + d) (a + 2d) \cdots (a + (l - 1)d)
$$

です。答えは $10^{12}$ 程度になる(入力例 2)ので 1 つずつ数えることはできませんが、$l$ と $a$ を全探索して、$d$ の個数をまとめて数えれば間に合います。

- **$l$ の範囲**:総積が最小になるのは $a = d = 1$ のときで、その値は $l!$ です。$20! \approx 2.4 \times 10^{18} > 10^{18}$ なので、$l \le 19$ です。
- **$a$ の範囲**:総積は $a^3$ より大きいので、$a < 10^6$ です。
- **$d$ の個数**:$l$ と $a$ を決めると、総積は $d$ について単調増加です。よって総積が $N$ 以下になる $d$ は $1$ 以上のある値 $D$ 以下のすべての整数で、その個数 $D$ は[二分探索](/blog/posts/20261024T1231/)で求められます。総積は $2d^2$ より大きいので、$D < 10^9$ です。

$a$ を大きくしても総積は増えるので、ある $a$ で $D = 0$ になったら、それより大きい $a$ も調べる必要はありません。計算量は、$l = 3$ のときの $10^6$ 個の $a$ のそれぞれで二分探索をするのがいちばん重く、全体で $10^8$ 回程度の計算です。

## 解答コード

<details>
<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/math/saturating.hpp"
#include "shogo-library/utility/binary-search.hpp"

void solve() {
    LL(N);
    ll ans = 0;
    rep(l, 3, 20) {
        rep(a, 1, 1e6) {
            ll ng = 1e9;
            ll ok = binary_search(0, ng, [=](ll x) {
                ll p = a, t = a;
                rep(l - 1) {
                    t += x;
                    p = saturating_mul(p, t);
                    if (p > N)
                        break;
                }
                return p <= N;
            });
            if (ok == 0)
                break;
            ans += ok;
        }
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`binary_search(ok, ng, f)` は、`f(ok)` が真、`f(ng)` が偽であるとして、`f` が真になる側の境界の値を返します。ここでは `f(x)` が「公差 `x` のときの総積が $N$ 以下か」なので、返り値がそのまま $D$ になります。`f(0)` が偽(つまり $a^l > N$)のときも、すべての `x` で偽なので $0$ が返り、$D = 0$ として扱えます。

総積の計算では、`saturating_mul` で掛け算がオーバーフローしたときに `long long` の最大値に丸めています。
