## 問題の概要

ある標準錘の重さを $N$ 個の都市で量った記録があります。$i$ 番目の都市の $1$ ポンドは $U_i$ グレインで、その都市は標準錘を $A_i$ ポンド($1$ ポンド未満は切り捨て)と記録しました。標準錘の実際の重さは、グレインで表すと正の整数です。残った記録がすべて正しくありうるように、除く記録の最小個数を求める問題です($1 \le N \le 200000$、$1 \le U_i \le 10000$、$0 \le A_i \le 100000$)。

## 解法

標準錘の重さを $W$ グレインとすると、記録 $i$ が正しいのは $\lfloor W / U_i \rfloor = A_i$、つまり

$$
U_i A_i \le W < U_i (A_i + 1)
$$

のときです。さらに $W \ge 1$ なので、記録 $i$ が正しくなる $W$ は半開区間 $[\max(U_i A_i, 1), U_i (A_i + 1))$ です。$U_i = 1, A_i = 0$ のときはこの区間は空で、その記録は必ず除くことになります。

$W$ を固定すると、残せる記録は $W$ を含む区間の個数です。よって、$N$ 個の区間が最も多く重なっている点での重なりの数を $c$ とすると、答えは $N - c$ です。

区間の端点は $10^9$ 程度まで大きくなるので、端点を[座標圧縮](/blog/posts/20261012T0121/)してから[いもす法](/blog/posts/20261024T1313/)で各点の重なりの数を求めます。重なりの数が変わるのは区間の左端だけなので、左端と右端の座標だけ見れば十分です。計算量は $O(N \log N)$ です。

$W \ge 1$ の条件を区間の左端に入れておくのが大事です。左端を $U_i A_i$ のままにして、座標 $0$ での重なりの数を最大値の候補から除くだけだと、$A_i = 0$ の記録の区間 $[0, U_i)$ が数えられなくなります。例えば $N = 1$、$(U_1, A_1) = (4, 0)$ では、$W = 1$ なら記録が正しいので答えは $0$ ですが、座標 $0$ を除くと $1$ になってしまいます。

## 解答コード

<details>
<summary>Python</summary>

```python
import bisect

N = int(input())
lr = []
comp = []
for i in range(N):
    u, a = map(int, input().split())
    l = max(u * a, 1)
    lr.append((l, u * (a + 1)))
    comp.append(l)
    comp.append(u * (a + 1))
comp = sorted(set(comp))
imos = [0] * len(comp)
for l, r in lr:
    imos[bisect.bisect_left(comp, l)] += 1
    imos[bisect.bisect_left(comp, r)] -= 1
for i in range(1, len(imos)):
    imos[i] += imos[i - 1]
print(N - max(imos))
```

`comp` が座標圧縮した端点の座標で、`imos[i]` は累積和をとったあと、点 `comp[i]` を含む区間の個数になります。空の区間は、同じ位置に $+1$ と $-1$ が入るので打ち消し合います。
