強連結成分分解について、参考になる記事や資料をまとめました。

強連結成分分解(SCC)は、有向グラフの頂点を「互いに行き来できる頂点どうし」のグループ(強連結成分)に分けることです。各成分を 1 つの頂点に縮約すると、閉路のない有向グラフ(DAG)になるので、その上でトポロジカル順に DP などができるようになります。DFS を 2 回行う Kosaraju 法や、DFS を 1 回行い lowlink を使う Tarjan 法で、$O(N + M)$ で求められます。2-SAT もこれを使って解きます。

成分を並べる順序には注意が必要です。AtCoder Library(ACL)の `scc_graph::scc()` は成分をトポロジカル順(辺の始点側の成分が先)に返しますが、Tarjan 法をそのまま書くと成分は逆トポロジカル順に見つかります。自分で書いたり他のライブラリを使ったりするときは、どちらの順かを確かめてください。また、1 頂点だけの成分は、自己ループがなければ閉路を含みません。DFS を再帰で書くと、頂点数が多いときに再帰が深くなりすぎることがあります。

## まず読むもの

- [強連結成分分解の意味とアルゴリズム](https://manabitimes.jp/math/1250)(高校数学の美しい物語)
  - 定義と、元のグラフで DFS をして帰りがけ順に番号を付け、辺を逆向きにしたグラフで番号の大きい頂点から DFS する手順(Kosaraju 法)を、図と具体例で説明しています。正しさの証明もありますが概略で、途中の補題は省略されています。コードはありません。
- [AtCoder Library Practice Contest G - SCC](https://drken1215.hatenablog.com/entry/2023/05/06/133900)(けんちょんの競プロ精進記録)
  - 強連結成分分解とは何か、縮約すると DAG になる理由を図で説明し、ACL を使うコードと、DFS を 2 回行う自前の C++ 実装(縮約した DAG も作る)を載せています。
- [強連結成分(SCC)](https://hkawabata.github.io/technical-note/note/Algorithm/graph/scc.html)(technical-note)
  - Kosaraju 法の手順を、DFS で番号を付けるところから成分を 1 つずつ取り出すところまで、図で 1 ステップずつ追っています。「上流・下流」のたとえで正しさを直感的に説明していて、厳密な証明やコードはありません。

## 縮約した DAG と 2-SAT

- [競技プログラミングにおける有向グラフに関する問題まとめ](https://blog.hamayanhamayan.com/entry/2017/06/11/124732)(はまやんはまやんはまやん)
  - トポロジカルソート、強連結成分分解、DAG の最小パス被覆、区間に辺を張る方法など、有向グラフの手法と、それを使う問題をまとめています。説明は短く、解説は外部の記事へのリンクが中心です。2017 年の記事です。
- [2-SAT](https://cp-algorithms.com/graph/2SAT.html)(cp-algorithms、英語)
  - 節 $(a \lor b)$ を $\lnot a \Rightarrow b$ と $\lnot b \Rightarrow a$ の 2 本の辺にした含意グラフを作り、$x$ と $\lnot x$ が同じ成分にあるかで判定し、成分のトポロジカル順の番号から割り当てを決める方法を、証明つきで説明しています。C++ の実装もあります。
  - 実装の最後の使用例 `example_usage` にある `vector<bool>(True, False, True)` は C++ として正しくないので、そこはそのまま写さないでください。

## AtCoder Algorithm Lectures

強連結成分分解そのものを扱う講座はまだありません。関連する講座として、次のものがあります。

- [グラフ理論用語集](https://info.atcoder.jp/entry/algorithm_lectures/graph_terms)
  - 5 章で強連結成分と強連結グラフを、9 章で DAG とトポロジカルソートを定義しています。DAG であることは、すべての強連結成分が 1 頂点からなりループを持たないことと同値だ、とも書かれています。
- [トーナメント](https://info.atcoder.jp/entry/algorithm_lectures/tournament)
  - 5 章で、トーナメント(どの 2 頂点の間にもちょうど 1 本の向きつきの辺がある有向グラフ)では強連結成分が一列に並び、強連結成分分解が各頂点の入次数だけから決まることを示しています。

## 実装

- [scc](https://atcoder.github.io/ac-library/production/document_ja/scc.html)(AtCoder Library のドキュメント)
  - `scc_graph` に `add_edge` で辺を追加し、`scc()` で成分ごとの頂点のリストを受け取ります。成分はトポロジカル順に並び、成分の中の頂点の順序は決まっていません。計算量は $O(n + m)$ です。
- [two_sat](https://atcoder.github.io/ac-library/production/document_ja/twosat.html)(AtCoder Library のドキュメント)
  - 節 $(x_i = f) \lor (x_j = g)$ を `add_clause` で追加し、`satisfiable()` で判定、`answer()` で割り当てを受け取ります。内部では強連結成分分解を使っています。
- [Strongly Connected Components (強連結成分分解)](https://ei1333.github.io/library/graph/connected-components/strongly-connected-components.hpp.html)(Luzhiled's Library)
  - Tarjan 法の C++ 実装で、各頂点の成分番号 `comp`(トポロジカル順に振り直してある)、成分ごとの頂点 `group`、縮約した DAG `dag` が得られます。DFS は再帰を使わずに書かれています。

- [Strongly Connected Components](https://usaco.guide/adv/SCC)(USACO Guide)
