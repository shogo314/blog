## 問題の概要

長さ $N$ の非負整数列 $A$ に対して、次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。

- `1 l r x`:$A_l, \dots, A_r$ のそれぞれに $x$ を足す。
- `2 l r k`:$\sum_{i=l}^{r} A_i^k$ を $998244353$ で割った余りを出力する($1 \le k \le 4$)。

## 解法

遅延評価セグメント木の各ノードに、担当区間の $p = 0, 1, \dots, 4$ 乗和 $s_p = \sum A_i^p$ を持たせます($s_0$ は区間の長さです)。2 つの区間の合成は、それぞれの和をとるだけです。

区間の全要素に $x$ を足したときは、二項定理より

$$
\sum (A_i + x)^p = \sum_{q=0}^{p} \binom{p}{q} x^{p-q} \sum A_i^q = \sum_{q=0}^{p} \binom{p}{q} x^{p-q} s_q
$$

となるので、新しい $s_p$ は古い $s_0, \dots, s_p$ から計算できます。足す値の合成は和です。

全体の計算量は $O(N + Q \log N)$ です(定数倍は $k$ の上限 $4$ に応じて大きくなります)。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/lazy-segtree.hpp"
#include "shogo-library/math/modint.hpp"
using mint = modint998244353;

struct AALC0001G {
    struct S {
        ary<mint, 5> dat;
        S() : dat{} {}
        S(mint a) {
            rep(i, 5) dat[i] = a.pow(i);
        }
    };
    using F = mint;
    static S op(const S &a, const S &b) {
        S res;
        rep(i, 5) res.dat[i] = a.dat[i] + b.dat[i];
        return res;
    }
    static S e() { return S(); }
    static S mapping(const F &f, const S &x) {
        S res;
        res.dat[0] = x.dat[0];
        res.dat[1] = x.dat[1] + f * x.dat[0];
        res.dat[2] = x.dat[2] + 2 * f * x.dat[1] + f * f * x.dat[0];
        res.dat[3] = x.dat[3] + 3 * f * x.dat[2] + 3 * f * f * x.dat[1] + f * f * f * x.dat[0];
        res.dat[4] = x.dat[4] + 4 * f * x.dat[3] + 6 * f * f * x.dat[2] + 4 * f * f * f * x.dat[1] + f * f * f * f * x.dat[0];
        return res;
    }
    static F composition(const F &f, const F &g) { return f + g; }
    static F id() { return F{}; }
};

void solve() {
    LL(N, Q);
    VL(A, N);
    vec<AALC0001G::S> init;
    init.reserve(N);
    rep(i, N)
        init.emplace_back(A[i]);
    LazySegTree<AALC0001G> seg(init);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(l, r, x);
            seg.apply(l - 1, r, x);
        } else if (q == 2) {
            LL(l, r, k);
            print(seg.prod(l - 1, r).dat[k]);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`LazySegTree` には、要素の型 `S`・作用の型 `F` と、`op`, `e`, `mapping`, `composition`, `id` をまとめた構造体を渡します(ACL の `lazy_segtree` と同じ構成です)。`mapping` で上の二項展開を $p = 4$ まで書き下しています。
