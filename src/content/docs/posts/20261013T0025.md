## 問題の概要

英小文字からなる文字列 $S$ が与えられるので、末尾が `oj` かどうかを判定する問題です。テストケースは $T$ 個あり、$1 \le T \le 100$、$1 \le |S| \le 100$ です。

## 解法

各テストケースについて、$S$ の末尾が `oj` かどうかをそのまま調べます。

Python なら `str.endswith` が使えます。$|S| = 1$ のときも、`"x".endswith("oj")` は `False` になるので、長さを別に気にする必要はありません。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    if input().endswith("oj"):
        print("Yes")
    else:
        print("No")
```
