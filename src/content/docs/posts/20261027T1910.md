## 問題の概要

$n$ 日間の歩数 $a_1, a_2, \dots, a_n$ と目標の歩数 $k$ が与えられます。歩数が $k$ 以上の日が連続する最大の日数を求める問題です($1 \le n, k \le 10^5$、$0 \le a_i \le 10^5$)。そのような日が 1 日もなければ $0$ を出力します。

## 解法

前から順に見ていき、「今日まで目標を達成した日が何日続いているか」を $t$ として持ちます。$a_i \ge k$ なら $t$ を $1$ 増やし、そうでなければ $t$ を $0$ に戻します。各日の $t$ の最大値が答えです。

## 解答コード

<details>
<summary>Python</summary>

```python
t = 0
ans = 0
N, K = map(int, input().split())
A = list(map(int, input().split()))
for a in A:
    if a >= K:
        t += 1
    else:
        t = 0
    ans = max(ans, t)
print(ans)
```
