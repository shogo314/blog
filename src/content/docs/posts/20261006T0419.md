## 問題の概要

$M$ 粒のぶどうを、人 $1, 2, \ldots, N$ の順に 1 粒ずつ繰り返し配るとき、各人がもらう粒数を求める問題です($N \le 100$、$M \le 10^4$)。

## 解法

$j$ 粒目 ($1 \le j \le M$) をもらうのは、$j \equiv k \pmod N$ となる人 $k$ です。人 $k$ がもらう粒数は、$1$ 以上 $M$ 以下で $N$ で割ると $k$ 余る(人 $N$ なら割り切れる)整数の個数なので

$$
\left\lfloor \frac{M - k + N}{N} \right\rfloor
$$

です。$M$ が小さいので実際に配るシミュレーションでも間に合いますが、式で一発で出せます。

コードでは $i = N - k$ として、$i = N - 1, \ldots, 0$ の順に $\lfloor (M + i) / N \rfloor$ を出力しています。

## 解答コード

<details>
<summary>Python</summary>

```python
N, M = map(int, input().split())
for i in reversed(range(N)):
    print((M + i) // N)
```

</details>
