## 問題の概要

$xy$ 平面上の $N$ 個の点 $(i, A_i)$ を、点 $1, 2, \ldots, N$ の順に線分で結んで折れ線を作ります。この折れ線上(端点も含む)にある点のうち、$y$ 座標が $K$ であるものの個数を求める問題です($2 \le N \le 100$、$A_i \ne A_{i+1}$)。

## 解法

条件を満たす点は、次の 2 種類です。

- $A_i = K$ である点 $i$ そのもの。
- 点 $i$ と点 $i + 1$ を結ぶ線分の内部の点で、$A_i$ と $A_{i+1}$ の一方が $K$ より大きく、もう一方が $K$ より小さいとき。$y$ 座標が $K$ を横切るので、線分の内部にちょうど 1 個あります。

$A_i \ne A_{i+1}$ なので、線分が $y = K$ の上に重なることはありません。

ただし、隣り合う 2 本の線分が共有する端点を 2 回数えないように注意が必要です。そこで、点 $1$ は単独で数え、それ以降は線分ごとに「右端の点と線分の内部」だけを数えます。

点 $i - 1$ と点 $i$ を結ぶ線分を見るとき、

- $A_{i-1} = K$ なら、左端は前の線分(または点 $1$)ですでに数えています。$A_i \ne K$ なので、この線分にはほかに条件を満たす点はありません。
- そうでなければ、$A_i = K$(右端)か、$A_{i-1}$ と $A_i$ が $K$ をはさんでいる(内部)ときに、1 個数えます。

計算量は $O(N)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
N, K = map(int, input().split())
A = list(map(int, input().split()))
ans = 0
if A[0] == K:
    ans += 1
for i in range(1, N):
    if A[i - 1] == K:
        continue
    if A[i] == K or (A[i] > K) != (A[i - 1] > K):
        ans += 1
print(ans)
```

`A[i - 1]` と `A[i]` がどちらも $K$ でないとき、`(A[i] > K) != (A[i - 1] > K)` は、2 点が $y = K$ をはさんでいることを表します。

</details>
