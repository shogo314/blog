## 問題の概要

整数 $N$ が与えられるので、`DOJ beginner contest` の後ろに空白を 1 つと $N$ をつなげた文字列を出力する問題です。テストケースは $T \le 100$ 個です。

## 解法

そのまま出力します。`beginner` と `contest` は小文字です。

Python の `print` は、複数の引数を空白 1 つで区切って出力するので、`print("DOJ beginner contest", N)` で求める形になります。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    print("DOJ beginner contest", int(input()))
```

</details>
