## 問題の概要

正の整数列 $a = (a_1, a_2, \dots, a_N)$ が与えられます。空でない部分列 $b$ に対して、次の操作を何回でも行えます。

- 素数 $p$ を 1 つ選び、$b$ の要素のうち $p$ で割り切れるものをすべて同時に $p$ で割る。

$b$ の要素をすべて同じ値にするとき、その値の最大値を $f(b)$ とします。すべての空でない部分列 $b$ についての $f(b)$ の和を $998244353$ で割った余りを求める問題です。

$a_i \le 2 \times 10^5$ で、$N$ の総和は $5 \times 10^5$ 以下、$\max a$ の総和は $2 \times 10^5$ 以下です。

## 解法

### $f(b)$ の性質

素数 $p$ ごとに考えます。$b$ の各要素の $p$ の指数を見ると、$p$ を選ぶ操作は、正の指数をすべて $1$ ずつ減らし、$0$ の指数はそのままにします。

最後にすべての指数を $e > 0$ でそろえるには、正の指数どうしの差は変わらず、$0$ の指数は増えないので、はじめからすべての指数が $e$ でなければなりません。そうでなければ、すべて $0$ にそろえるしかありません。

よって、$f(b)$ は「$b$ のすべての要素で指数が等しい素数」について $p^e$ を掛けたものです。ここから次のことがいえます。

- $b$ のすべての要素が $c \cdot j$($\gcd(c, j) = 1$)の形で書ける $\iff$ $c$ を割り切るどの素数についても、$b$ のすべての要素の指数が $c$ の指数と等しい $\iff$ $f(b) = c \cdot d$($\gcd(c, d) = 1$)と書ける

### $f(b) = c$ となる部分列の個数

$a$ の要素のうち、$c \cdot j$($\gcd(c, j) = 1$)の形のものの個数を $t_c$ とします。これらだけからなる空でない部分列は $2^{t_c} - 1$ 個あり、上の性質から、これはちょうど $f(b) = c \cdot j$($\gcd(c, j) = 1$)となる部分列全体です。$f(b) = c$ となる部分列の個数を $g_c$ とすると、

$$
g_c = 2^{t_c} - 1 - \sum_{j \ge 2,\ \gcd(c, j) = 1} g_{cj}
$$

です。$c$ の大きい順に計算すれば、右辺の $g_{cj}$ はすでに求まっています。答えは $\sum_c c \cdot g_c$ です。

$M = \max a$ とすると、$c$ ごとに $M / c$ 個の倍数を見るので、全体で $O(M \log M)$ 回の $\gcd$ 計算です。

## 解答コード

<summary>Python</summary>

```python
from math import gcd

MOD = 998244353
for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    M = max(A)
    tmp0 = [0] * (M + 1)
    tmp1 = [0] * (M + 1)
    for a in A:
        tmp0[a] += 1
    ans = 0
    for i in reversed(range(1, M + 1)):
        t = tmp0[i]
        u = 0
        for j in range(2, M // i + 1):
            if gcd(i, j) != 1:
                continue
            t += tmp0[i * j]
            u += tmp1[i * j]
        v = (pow(2, t, MOD) - u - 1) % MOD
        tmp1[i] = v
        ans += i * v
    ans %= MOD
    print(ans)
```

`tmp0[x]` は値 $x$ の要素の個数、`tmp1[c]` は $g_c$ です。`t` が $t_c$、`u` が $\sum g_{cj}$ にあたります。
