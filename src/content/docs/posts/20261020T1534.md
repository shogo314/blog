## 問題の概要

`e` は空文字列、`f(X)` は文字列 $X$ の先頭に `f` をつけたもの、`g(X)` は先頭に `g` をつけたもの、`X+Y` は $X$ と $Y$ の連結を表します。これらを組み合わせた式 $S$ が与えられるので、評価した文字列を求める問題です($1 \le |S| \le 2 \times 10^5$)。

## 解法

式の値は、$S$ に現れる文字 `f` と `g` を、現れる順に並べた文字列です。

式の組み立て方に沿って確かめます。

- `e` は空文字列で、`f` も `g` も含みません。
- `f(X)` の値は `f` に $X$ の値を続けたものです。式の中でも `f` は $X$ の前にあります。`g(X)` も同じです。
- `X+Y` の値は $X$ の値に $Y$ の値を続けたものです。式の中でも $X$ は $Y$ の前にあります。

したがって、$S$ から `f` と `g` だけを取り出せば答えになります。

## 解答コード

<details>
<summary>Python</summary>

```python
print("".join(c for c in input() if c in "fg"))
```

`f` と `g` 以外の文字(`e`、`(`、`)`、`+`)を取り除いています。答えが空文字列のときは、改行だけが出力されます。

</details>
