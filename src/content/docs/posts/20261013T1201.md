## 問題の概要

$0$ 以上 $2^{30}$ 未満の整数からなる長さ $N$ の数列 $A$ に対して、次の 2 種類のクエリを $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。ここで NAND は、2 進法 30 桁で表したときの桁ごとの NAND(両方 $1$ なら $0$、そうでなければ $1$)です。

- `1 p x`:$A_p$ を $x$ に変更する。
- `2 l r`:$B_l = A_l$ とし、$i = l + 1, \ldots, r$ の順に $B_i$ を $B_{i-1}$ と $A_i$ の NAND とする。$B_r$ を出力する。

## 解法

NAND は桁ごとに独立なので、30 桁それぞれについて別々に考えます。ある桁に注目すると、$B_{i-1}$ のその桁 $b$ から $B_i$ のその桁を求める操作は、$A_i$ のその桁で決まる $\{0, 1\}$ 上の写像になります。

- $A_i$ の桁が $1$ のとき:$b \mapsto \lnot b$($0 \mapsto 1$, $1 \mapsto 0$)
- $A_i$ の桁が $0$ のとき:$b \mapsto 1$($0 \mapsto 1$, $1 \mapsto 1$)

クエリ 2 の答えのその桁は、$A_l$ のその桁に、$A_{l+1}, \ldots, A_r$ に対応する写像を順に適用したものです。写像の合成は結合的なので、各桁ごとに写像を要素とするセグメント木を作れば、区間 $[l + 1, r]$ の写像の合成を $O(\log N)$ で求められます。$l = r$ のときは区間が空になり、合成は恒等写像なので $B_l = A_l$ がそのまま答えになります。

クエリ 1 では 30 本のセグメント木それぞれで 1 点更新をします。全体の計算量は、桁数を $W = 30$ として $O(W (N + Q \log N))$ です。

## 解答コード

<summary>C++</summary>

```cpp
#include "shogo-library/algebra/monoid.hpp"
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

void solve() {
    LL(N, Q);
    VL(A, N);
    ary<SegTree<monoid::Mapping<2>>, 30> seg;
    rep(d, 30) {
        vec<monoid::Mapping<2>::S> init;
        init.reserve(N);
        for (ll a : A) {
            if ((a >> d) & 1) {
                init.push_back({1, 0});
            } else {
                init.push_back({1, 1});
            }
        }
        seg[d] = SegTree<monoid::Mapping<2>>(init);
    }
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(p, x);
            p--;
            rep(d, 30) {
                if ((x >> d) & 1) {
                    seg[d].set(p, {1, 0});
                } else {
                    seg[d].set(p, {1, 1});
                }
            }
            A[p] = x;
        } else {
            LL(l, r);
            l--;
            ll ans = 0;
            rep(d, 30) {
                ll t = seg[d].prod(l + 1, r)[(A[l] >> d) & 1];
                ans |= t << d;
            }
            print(ans);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`SegTree` にはモノイドを表す構造体を渡します(1 点更新・区間積のセグメント木で、`prod(l, r)` は半開区間 $[l, r)$ の積です)。`monoid::Mapping<2>` は $\{0, 1\}$ 上の写像の合成のモノイドで、写像 $f$ を `std::array<int, 2>` の $(f(0), f(1))$ で表します。区間の積は左の要素の写像から順に適用した合成なので、`prod(l + 1, r)` に $A_l$ の桁を渡せば $B_r$ の桁が得られます。
