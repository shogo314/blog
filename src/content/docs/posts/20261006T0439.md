## 問題の概要

$i$ 番目のトッピングは価格 $i$、嬉しさ $W_i$ です。価格の総和が $V$ 以下になるように相異なる 3 種類を選ぶとき、嬉しさの総和の最大値を求める問題です($N \le 100$)。

## 解法

$N \le 100$ なので、3 つの組 $i < j < k$ を全部試しても $\binom{100}{3} \approx 1.6 \times 10^5$ 通りで間に合います。価格の総和 $i + j + k$ が $V$ 以下のものについて、嬉しさの総和の最大値を取ります。

コードでは添字を $0$ 始まりにしているので、価格の総和は $i + j + k + 3$ になります。

## 解答コード

<details>
<summary>Python</summary>

```python
from itertools import combinations

N, V = map(int, input().split())
W = list(map(int, input().split()))
ans = 0
for i, j, k in combinations(range(N), r=3):
    if i + j + k + 3 > V:
        continue
    ans = max(ans, W[i] + W[j] + W[k])
print(ans)
```
