## 問題の概要

ボタン式の古い携帯電話で単語 $s$ を入力するのにかかる時間を求める問題です($1 \le |s| \le 10^5$、$s$ は英小文字のみ)。

ボタンには `abc`、`def`、`ghi`、`jkl`、`mno`、`pqrs`、`tuv`、`wxyz` の文字が割り当てられていて、ボタンの中の $j$ 番目の文字を入力するにはそのボタンを $j$ 回押します。1 回押すのに $1$ 秒かかります。また、次の文字が直前の文字と同じボタンにあるときは、区切るために $1$ 秒待つ必要があります。

## 解法

各文字について、それがどのボタンの何番目の文字かを調べ、その番号を足していきます。さらに、直前の文字と同じボタンなら $1$ を足します。

例えば `hello` は、`h` が 2 回、`e` が 2 回、`l` が 3 回、もう一度 `l` が 3 回と待ち時間 1 秒、`o` が 3 回で、合計 $14$ 秒です。

## 解答コード

<details>
<summary>Python</summary>

```python
l = ["abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]

ans = 0
S = input()
d = []
for c in S:
    for i, a in enumerate(l):
        if c in a:
            d.append(i)
for i, c in enumerate(S):
    ans += l[d[i]].index(c) + 1
    if i > 0 and d[i - 1] == d[i]:
        ans += 1
print(ans)
```

`d[i]` は `S[i]` が何番目のボタンにあるかで、`l[d[i]].index(c) + 1` がそのボタンを押す回数です。
