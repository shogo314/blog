## 問題の概要

$0$ と $1$ からなる長さ $N$ の数列 $A$ と、長さ $M$ の数列 $B$ が与えられます。$N$ 行 $M$ 列の配列 $C$ を $C_{i,j} = A_i + B_j$ で定めます。値が $2$ のマスだけを考え、辺を共有するマスどうしをつないだときの連結成分のうち、最大のものの面積を求める問題です。値が $2$ のマスがなければ $0$ を出力します。

$N, M \le 2 \times 10^5$ なので、$C$ を実際に作ることはできません。

## 解法

$C_{i,j} = 2$ となるのは、$A_i = 1$ かつ $B_j = 1$ のときだけです。

$A$ で $1$ が連続している区間を行の区間、$B$ で $1$ が連続している区間を列の区間として、その組み合わせごとに長方形ができます。

- 長方形の中のマスはすべて値が $2$ で、つながっています。
- 隣の長方形との間には、$A_i = 0$ の行か $B_j = 0$ の列があるので、別の長方形とはつながりません。

したがって、連結成分はこの長方形そのものです。最大の面積は、$A$ で $1$ が連続する最大の長さと、$B$ で $1$ が連続する最大の長さの積になります。値が $2$ のマスがない場合も、どちらかが $0$ になるので、積は $0$ で正しく求まります。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N, M = map(int, input().split())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))
    x = 0
    t = 0
    for a in A:
        if a:
            t += 1
        else:
            t = 0
        x = max(x, t)
    y = 0
    t = 0
    for a in B:
        if a:
            t += 1
        else:
            t = 0
        y = max(y, t)
    print(x * y)
```

`x` が $A$ の、`y` が $B$ の、$1$ が連続する最大の長さです。`t` は今見ている位置で終わる $1$ の連続の長さです。
