## 問題の概要

長さ $N$ の非負整数列 $A$ が与えられます。次の条件をすべて満たす長さ $N$ の非負整数列 $B$ の個数を $10^9 + 7$ で割った余りを求める問題です。

- $B_1 = 0$。
- すべての $1 \le i < N$ について $|B_i - B_{i+1}| \le K$。
- $\sum_{i=1}^{N} |A_i - B_i| \le E$。

制約は $2 \le N \le 100$、$0 \le K \le 20$、$0 \le E \le 50$、$0 \le A_i \le 50$ です。

## 解法

$B$ を前から 1 つずつ決めていく DP をします。次の値を決めるのに必要なのは、直前の値 $B_i$ と、それまでの誤差の合計だけです。そこで

$$
\mathrm{dp}_i[e][b] = (B_1, \dots, B_i \text{ のうち、誤差の合計が } e \text{ で } B_i = b \text{ であるものの個数})
$$

とします。$\mathrm{dp}_1$ は $\mathrm{dp}_1[A_1][0] = 1$ だけが $1$ です($A_1 > E$ なら答えは $0$ です)。$\mathrm{dp}_i[e][b]$ から、$|b - b'| \le K$ を満たす各 $b'$ について、$e' = e + |A_{i+1} - b'| \le E$ なら $\mathrm{dp}_{i+1}[e'][b']$ に足します。答えは $\mathrm{dp}_N$ の値の総和です。

$B_i$ のとりうる範囲は有限です。$|A_i - B_i| \le E$ なので、$B_i \le A_i + E \le \max A + E$ です。よって $b$ は $0$ 以上 $M = \max A + E \le 100$ 以下だけを考えれば十分です。

計算量は $O(NEMK)$ で、最大でも $100 \times 51 \times 101 \times 41 \approx 2 \times 10^7$ 回程度です。

## 解答コード

<summary>Python</summary>

```python
MOD = 10**9 + 7
N, K, E = map(int, input().split())
A = list(map(int, input().split()))
if A[0] > E:
    print(0)
    exit(0)
M = max(A) + E
dp = [[0 for i in range(M + 1)] for j in range(E + 1)]
dp[A[0]][0] = 1
for a in A[1:]:
    ndp = [[0 for i in range(M + 1)] for j in range(E + 1)]
    for i in range(E + 1):
        for j in range(M + 1):
            for k in range(j - K, j + K + 1):
                if k not in range(M + 1):
                    continue
                if abs(a - k) + i > E:
                    continue
                ndp[abs(a - k) + i][k] += dp[i][j]
                ndp[abs(a - k) + i][k] %= MOD
    dp = ndp
print(sum(sum(a) % MOD for a in dp) % MOD)
```

`dp[i][j]` が、誤差の合計が `i` で直前の値が `j` である数列の個数です。`k` が次の値 $B_{i+1}$ の候補で、範囲 $[0, M]$ から外れるものと、誤差の合計が $E$ を超えるものを飛ばしています。
