## 問題の概要

長さ $n$ の数列 $a$ と整数 $L, R$ が与えられます。連続する部分列のうち、総和が $L$ 以上 $R$ 以下のものの個数を求める問題です($n \le 10^5$、$-10^9 \le a_i \le 10^9$、$-10^{14} \le L \le R \le 10^{14}$)。$a_i$ は負になることもあります。

## 解法

累積和を $S_0 = 0$、$S_j = a_1 + \cdots + a_j$ とすると、区間 $[i + 1, j]$ の総和は $S_j - S_i$ です。条件 $L \le S_j - S_i \le R$ を $S_i$ について書き直すと

$$
S_j - R \le S_i \le S_j - L
$$

です。したがって、各 $j$ について「$i < j$ で $S_i$ が $[S_j - R, S_j - L]$ に入るものの個数」を足し合わせれば答えになります。

$a_i$ が負になることもあるので $S$ は単調ではなく、しゃくとり法は使えません。そこで $j = 1, 2, \ldots, n$ の順に見ていき、それまでに出てきた $S_i$ を、値ごとの個数として管理します。必要な操作は次の 2 つです。

- $S_j$ を 1 個追加する
- 値が $[S_j - R, S_j - L]$ の範囲にある $S_i$ の個数を数える

$S$ の値は最大 $10^{14}$ 程度と大きいので、$S_0, \ldots, S_n$ を座標圧縮して添字にし、区間和を求めるセグメント木(または BIT)で管理します。値の範囲 $[S_j - R, S_j - L]$ は、圧縮後の添字では二分探索で求まります。全体で $O(n \log n)$ です。

## 解答コード

<details>
<summary>C++(セグメント木)</summary>

```cpp
#include "ou-library/segtree.hpp"
#include "sh-library/base/all"

void solve() {
    LL(N, L, R);
    VL(A, N);
    ll t = 0;
    sl s;
    s.insert(t);
    for (ll a : A) {
        t += a;
        s.insert(t);
    }
    vl v(all(s));
    RSumQ<ll> seg(v.size());
    ll ans = 0;
    t = 0;
    seg.apply(bisect_left(v, t), 1);
    for (ll a : A) {
        t += a;
        ans += seg.prod(bisect_left(v, t - R), bisect_right(v, t - L));
        seg.apply(bisect_left(v, t), 1);
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

前半では累積和の値を `std::set` に入れ、ソート済みで重複のない `v` にしています(座標圧縮)。値 $x$ の添字は `bisect_left(v, x)` です。

後半では `t` が $S_j$ で、`seg.prod(bisect_left(v, t - R), bisect_right(v, t - L))` が「値が $[S_j - R, S_j - L]$ にある $S_i$ の個数」です。数えてから `seg.apply(..., 1)` で $S_j$ を追加するので、$i < j$ のものだけが数えられます。`RSumQ` は区間和のセグメント木です。

<details>
<summary>Python(BIT)</summary>

```python
from bisect import bisect_left, bisect_right
from itertools import accumulate

N, L, R = map(int, input().split())
A = list(map(int, input().split()))
S = [0, *accumulate(A)]
v = sorted(set(S))
M = len(v)
bit = [0] * (M + 1)


def add(i):
    i += 1
    while i <= M:
        bit[i] += 1
        i += i & -i


def count(i):
    res = 0
    while i:
        res += bit[i]
        i -= i & -i
    return res


ans = 0
add(bisect_left(v, 0))
for t in S[1:]:
    ans += count(bisect_right(v, t - L)) - count(bisect_left(v, t - R))
    add(bisect_left(v, t))
print(ans)
```

C++ 版と同じ処理を BIT で書いています。`count(i)` は添字が $i$ 未満の個数なので、2 つの差が範囲内の個数になります。
