## 問題の概要

$1$ 以上 $9$ 以下の整数 $A, B$ が与えられます。$A + B$ の桁数を求める問題です。

## 解法

$A + B$ を文字列にして、その長さを出力します。

$A + B$ は $2$ 以上 $18$ 以下なので、$A + B \ge 10$ なら $2$、そうでなければ $1$ と場合分けしても求まります。

## 解答コード

<details>
<summary>Python</summary>

```python
print(len(str(sum(map(int, input().split())))))
```

</details>
