## 問題の概要

整数 $X$ が与えられます。$1 \le k, m, n \le X$ を満たす整数の組 $(k, m, n)$ のうち、$km - n = k$ を満たすものの個数を求める問題です($2 \le X \le 10^6$)。

## 解法

$km - n = k$ は $n = k(m - 1)$ と変形できます。$n$ は $k$ と $m$ から決まるので、$n$ が $1$ 以上 $X$ 以下になるような $(k, m)$ の組を数えればよいです。

$t = m - 1$ とおくと、条件は $1 \le t \le X - 1$ かつ $kt \le X$ です($kt \ge 1$ は $t \ge 1$ から成り立ちます)。$k$ を固定すると、条件を満たす $t$ は $1$ 以上 $\min(\lfloor X / k \rfloor, X - 1)$ 以下のすべての整数です。これを $k = 1, \dots, X$ について足し合わせれば答えです。

$\lfloor X / k \rfloor$ は割り算で直接求められますが、下のコードでは「$kt \le X$ を満たす最大の $t$」を二分探索で求めています。計算量は $O(X \log X)$ です。

## 解答コード

<details>
<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/utility/binary-search.hpp"

void solve() {
    LL(X);
    ll ans = 0;
    rep(k, 1, X + 1) {
        ans += binary_search(1, X, [=](ll mm) { return k * mm <= X; });
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`mm` が上の $t = m - 1$ です。`binary_search(ok, ng, f)` は、`f(ok)` が真、`f(ng)` が偽であるとして、`f` が真になる側の境界の値を返します。`ng` を $X$ にしているので、返り値は $X$ 未満で $kt \le X$ を満たす最大の $t$、つまり $\min(\lfloor X / k \rfloor, X - 1)$ です。$k \le X$ なので、`f(1)` は常に真です。
