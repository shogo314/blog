## 問題の概要

$N$ 人が左から一列に並んでいて、$i$ 番目の人の身長は $H_i$ です。ダダスは $1$ 番目の人です。

ダダスを含む連続した区間 $[L, R]$ のうち、区間内でダダスの身長がほかの全員より真に高いものの個数を求める問題です。$N$ の総和は $3 \times 10^5$ 以下です。

## 解法

ダダスは $1$ 番目なので、区間は必ず $L = 1$ です。数えるのは、$H_2, \dots, H_R$ がすべて $H_1$ より小さくなるような $R$ の個数です。

左から見ていき、$H_i \ge H_1$ となる最初の $i$ を探します。条件を満たす $R$ は $1, 2, \dots, i - 1$ の $i - 1$ 個です。そのような $i$ がなければ、$R = 1, \dots, N$ のすべてが条件を満たすので、答えは $N$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    H = list(map(int, input().split()))
    for i in range(1, N):
        if H[i] >= H[0]:
            print(i)
            break
    else:
        print(N)
```

コードは 0-indexed なので、`H[i] >= H[0]` となる最初の `i` がそのまま答えの $i - 1$ にあたります。`for` 文の `else` は、`break` せずにループを終えたときに実行されます。
