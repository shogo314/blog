## 問題の概要

$1$ から $N$ までの整数の順列 $P$ が与えられます。$P_1 + Q_1, P_2 + Q_2, \dots, P_N + Q_N$ が広義単調増加になるような順列 $Q$ を 1 つ作る問題です。答えが複数あれば、どれを出力してもかまいません。

テストケースは $T \le 10^5$ 個あり、$N$ の総和は $2 \times 10^5$ 以下です。

## 解法

$Q_i = N + 1 - P_i$ とします。

$P$ が $1$ から $N$ の順列なので、$N + 1 - P_i$ も $1$ から $N$ までを 1 回ずつとり、$Q$ は順列になります。そして、どの $i$ でも $P_i + Q_i = N + 1$ です。和がすべて等しいので、広義単調増加の条件を満たします。

## 解答コード

<details>
<summary>Python</summary>

```python
for _ in range(int(input())):
    N = int(input())
    P = list(map(int, input().split()))
    print(*[N - p + 1 for p in P])
```
