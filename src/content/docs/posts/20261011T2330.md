## 問題の概要

$N$ 個のおかずがあり、$i$ 個目のおいしさは $A_i$、体積は $B_i$ です。体積の合計が $W$ 以下になるようにおかずを選ぶとき、おいしさの合計の最大値を求める問題です。1 つも選ばなくてもかまいません($1 \le N \le 20$、$1 \le W, A_i, B_i \le 10^9$)。

## 解法

$N \le 20$ と小さいので、おかずの選び方 $2^N$ 通りをすべて調べられます。それぞれについて体積の合計とおいしさの合計を求め、体積の合計が $W$ 以下のもののうち、おいしさの合計の最大値が答えです。

選び方は、$0$ 以上 $2^N$ 未満の整数 $i$ で表します。$i$ を 2 進数で書いたとき下から $j$ 桁目が $1$ なら $j$ 個目のおかずを選ぶ、と決めれば、$i$ を $0$ から $2^N - 1$ まで動かすことですべての選び方を 1 回ずつ調べられます。計算量は $O(2^N N)$ です。

$W$ や $B_i$ が大きいので、体積を添字にするナップサック DP は使えません。

## 解答コード

<details>
<summary>Python</summary>

```python
N, W = map(int, input().split())
AB = [tuple(map(int, input().split())) for i in range(N)]
ans = 0
for i in range(1 << N):
    a = 0
    b = 0
    for j in range(N):
        if (i >> j) & 1:
            a += AB[j][0]
            b += AB[j][1]
    if b <= W:
        ans = max(ans, a)
print(ans)
```

`(i >> j) & 1` で、$i$ の下から $j$ 桁目(0 始まり)が $1$ かどうか、つまり $j$ 個目のおかずを選ぶかどうかを調べています。`a` がおいしさの合計、`b` が体積の合計です。`i = 0` は何も選ばない場合にあたり、このとき `a = 0` なので、`ans` の初期値 $0$ と同じです。

</details>
