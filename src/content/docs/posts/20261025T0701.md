## 問題の概要

名前 $s$ が $Q$ 回与えられます。各回について、$s$ にすでに ID が割り当てられていればその ID を、そうでなければまだ使われていない最小の正の整数を $s$ の ID として割り当て、その ID を出力する問題です($1 \le Q \le 2 \times 10^5$、$1 \le |s| \le 10$)。

## 解法

ID は $1, 2, 3, \ldots$ の順に割り当てられるので、新しく割り当てる ID は「それまでに出てきた名前の種類数 $+ 1$」です。

名前から ID への辞書(連想配列)を持ち、名前が辞書になければ、そのときの辞書の大きさ $+ 1$ を ID として登録します。そのあと辞書から ID を引いて出力します。

## 解答コード

<details>
<summary>Python</summary>

```python
d = {}
for _ in range(int(input())):
    S = input()
    if S not in d:
        d[S] = len(d) + 1
    print(d[S])
```
