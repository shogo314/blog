## 問題の概要

$N$ 個の年号の名前 $S_i$ と、その年号が始まった西暦年 $A_i$ が与えられます($A_1 < A_2 < \dots < A_N$)。各年号は始まった年を $1$ 年として数え、次の年号が始まるまで使われます。西暦 $Y$ 年に使われていた年号の名前と、その年号での年数を求める問題です($1 \le N \le 100$、$A_1 \le Y \le 9999$)。

## 解法

西暦 $Y$ 年に使われているのは、$A_i \le Y$ を満たす $i$ のうち最大のものです。$A$ は昇順に並んでいるので、後ろから見ていって最初に $A_i \le Y$ となったものが答えの年号です。$A_1 \le Y$ なので必ず見つかります。

年数は、$A_i$ 年が $1$ 年なので $Y - A_i + 1$ 年です。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
S = []
A = []
for _ in range(N):
    s, a = input().split()
    S.append(s)
    A.append(int(a))
Y = int(input())
for i in reversed(range(N)):
    if Y >= A[i]:
        print(S[i], Y - A[i] + 1)
        break
```
