## 問題の概要

$N$ 種類の微生物があり、$i$ 番の微生物の $x$ 日目の個体数は $A_i + B_i x$ です。$B_i$ を成長係数とよびます。

$x$ 日目に、何種類かの微生物を選びます。ただし、選んだ微生物を次の 2 通りで並べたとき、番号の並びが一致しなければなりません。

- 成長係数の小さい順
- $x$ 日目の個体数の少ない順

どちらも、値が同じなら番号の小さい順に並べます。$K$ 種類以上選べる最も早い日 $x \ge 0$ を求める問題です。存在しなければ `-1` を出力します。

$1 \le K \le N \le 10^5$、$1 \le A_i, B_i \le 10^9$ です。

## 解法

### 固定した日に選べる最大の種類数

微生物を $(B_i, i)$ の昇順に並べておきます。選んだ微生物の並びがこの順で、$(A_i + B_i x, i)$ も昇順になっていれば条件を満たします。

つまり、$(B_i, i)$ の順に並べた列で、$(A_i + B_i x, i)$ の[**最長狭義増加部分列**(LIS)](/blog/posts/20261023T1325/)の長さが、$x$ 日目に選べる最大の種類数です。LIS の長さは $O(N \log N)$ で求まります。

### 日数についての単調性

$x$ 日目に選べる組は、$x + 1$ 日目にも選べます。

$(B_p, p) < (B_q, q)$ の 2 つが $x$ 日目に条件を満たしているとします。1 日たつと、個体数の差 $(A_q + B_q x) - (A_p + B_p x)$ は $B_q - B_p \ge 0$ だけ増えます。$B_p < B_q$ なら差が増えるので順序は保たれ、$B_p = B_q$ なら差が変わらないので順序も変わりません。

よって、選べる最大の種類数は $x$ について広義単調増加です。$K$ 種類以上選べる最小の $x$ を二分探索で求めます。

### 探索の範囲

問題文にあるとおり、答えが存在すれば $10^9$ 以下です。$x = 10^9 + 1$ で $K$ 種類選べなければ `-1` を出力し、選べれば $[0, 10^9 + 1]$ で二分探索します。

全体で $O(N \log N \log \max)$ です。

## 解答コード

<summary>Python</summary>

```python
from operator import itemgetter
from bisect import bisect_left

for _ in range(int(input())):
    N, K = map(int, input().split())
    ABi = [tuple(map(int, input().split())) + (i,) for i in range(N)]
    ABi.sort(key=itemgetter(1))

    def q(x):
        dp = [(2 * 10**18, 10**18)] * (N + 1)
        for a, b, i in ABi:
            dp[bisect_left(dp, (a + b * x, i))] = (a + b * x, i)
        for i in range(N + 1):
            if dp[i][0] >= 2 * 10**18:
                return i
        assert False

    ok = 10**9 + 1
    ng = -1
    if q(ok) < K:
        print(-1)
        continue
    while ok > ng + 1:
        mid = (ok + ng) // 2
        if q(mid) >= K:
            ok = mid
        else:
            ng = mid
    print(ok)
```

`sort` は安定なので、$B_i$ だけをキーにしても、$B_i$ が等しいものは番号順に並びます。`q(x)` は $(A_i + B_i x, i)$ の LIS の長さを返します。`dp[k]` は長さ $k + 1$ の増加部分列の末尾の最小値で、番兵の値が残っていない個数が LIS の長さです。
