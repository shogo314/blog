## 問題の概要

英小文字からなる文字列 $S$ が与えられます。$Q$ 個のクエリで文字列 $T_i$ が与えられるので、$S$ と $T_i$ の両方の部分文字列である空でない文字列のうち、最長のものの長さを答える問題です(なければ $0$)。制約は $1 \le |S| \le 2000$、$1 \le Q \le 2 \times 10^5$、$\sum |T_i| \le 10^6$ です。

## 解法

$T$ の各位置 $j$ について、$T$ の $j$ 文字目で終わる文字列のうち $S$ の部分文字列であるものの最長の長さを $\ell_j$ とします。共通の部分文字列はどれも $T$ のどこかの位置で終わるので、答えは $\ell_j$ の最大値です。

$\ell_j$ は、$S$ の [Suffix Automaton](/blog/posts/20261023T2141/) を使うと、$T$ を前から 1 文字ずつ読みながら求められます。Suffix Automaton は $S$ のすべての部分文字列を受理するオートマトンです。各状態は $S$ の部分文字列の集まりを表し、状態の数は $O(|S|)$ です。

$T$ の $j$ 文字目までを読んだとき、長さ $\ell_j$ の文字列(その位置で終わる、$S$ の部分文字列である最長の文字列)を表す状態 $v$ と $\ell_j$ を持っておきます。次の文字 $c$ を読むときは、次のようにします。

- $v$ から $c$ で遷移できれば、遷移して長さを $1$ 増やす。
- 遷移できなければ、先頭の文字を削って短くする。Suffix Automaton では、これは suffix link をたどることにあたる。遷移できるようになるか初期状態に戻るまでたどってから、遷移を試す。

長さは 1 文字読むごとに高々 $1$ しか増えないので、suffix link をたどる回数の合計は $|T|$ 以下です。よって、1 つのクエリは $O(|T|)$ で処理でき、全体の計算量は $O(|S| + \sum |T_i|)$ です。

## 解答コード

<details>
<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/string/suffix-automaton.hpp"
#include "shogo-library/utility/container_func.hpp"

void solve() {
    LL(Q);
    STR(S);
    SuffixAutomaton sam(S);
    rep(Q) {
        STR(T);
        print(max(sam.match_lengths(T)));
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`SuffixAutomaton` は Suffix Automaton で、既定では英小文字を扱います。`match_lengths(T)` は上の $\ell_j$ を $T$ の各位置について並べた列を返すので、その最大値を出力しています。
