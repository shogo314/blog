## 問題の概要

長さ $10^{18}$ の `0`, `1` からなる文字列 $S$ があり、はじめはすべて `0` です。次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le Q \le 2 \times 10^5$)。

- `1 l r`:$S_l, \dots, S_r$ を反転する。
- `2 l r`:$S_l, \dots, S_r$ に含まれる `1` の個数を出力する。

## 解法

クエリを先読みして座標圧縮します。区間を 0 始まりの半開区間 $[l - 1, r)$ で表し、すべてのクエリの端点 $l - 1$, $r$ を集めてソートし、重複を除いたものを $v_0 < v_1 < \dots < v_{m-1}$ とします。すると、どのクエリの区間も小区間 $[v_{j-1}, v_j)$ をいくつか並べたものになります。また、各小区間の中の文字はつねにすべて同じように反転されます。

そこで、小区間 $[v_{j-1}, v_j)$ を 1 つの要素とする遅延評価セグメント木を作ります。各ノードには担当範囲の `0` の個数と `1` の個数を持たせます。はじめは `0` の個数が小区間の長さ $v_j - v_{j-1}$ で、`1` の個数は $0$ です。反転はこの 2 つを入れ替える作用で、2 回反転すると元に戻るので、作用の合成は XOR です。

全体の計算量は $O(Q \log Q)$ です。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/lazy-segtree.hpp"

struct AALC0001J {
    struct S {
        al<2> cnt;
        S() : cnt{0, 0} {}
        S(ll a, ll b) {
            cnt[0] = a;
            cnt[1] = b;
        }
    };
    using F = ll;
    static S op(const S &a, const S &b) {
        S res;
        rep(i, 2) res.cnt[i] = a.cnt[i] + b.cnt[i];
        return res;
    }
    static S e() { return S(); }
    static S mapping(const F &f, const S &x) {
        S res = x;
        if (f) {
            std::swap(res.cnt[0], res.cnt[1]);
        }
        return res;
    }
    static F composition(const F &f, const F &g) { return f ^ g; }
    static F id() { return F{}; }
};

void solve() {
    LL(Q);
    VAL(qlr, Q, 3);
    vl tmp;
    tmp.reserve(2 * Q);
    for (auto &[q, l, r] : qlr) {
        l--;
        tmp.push_back(l);
        tmp.push_back(r);
    }
    sl s(all(tmp));
    vl v(all(s));
    vec<AALC0001J::S> init;
    init.reserve(v.size() - 1);
    rep(i, 1, v.size()) {
        init.emplace_back(v[i] - v[i - 1], 0);
    }
    LazySegTree<AALC0001J> seg(init);
    for (auto [q, l, r] : qlr) {
        if (q == 1) {
            seg.apply(bisect_left(v, l), bisect_left(v, r), 1);
        } else {
            print(seg.prod(bisect_left(v, l), bisect_left(v, r)).cnt[1]);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`VAL(qlr, Q, 3)` で、クエリを `std::array<ll, 3>` の配列として読み込んでいます。座標圧縮は `std::set` に入れてから `vector` に戻す形で行い、`bisect_left` で端点の番号を求めています。セグメント木の $j$ 番目の要素は小区間 $[v_j, v_{j+1})$ なので、半開区間 $[l - 1, r)$ は要素の番号の範囲 $[\mathrm{bisect\_left}(v, l - 1), \mathrm{bisect\_left}(v, r))$ に対応します。

`LazySegTree` には、要素の型 `S`・作用の型 `F` と、`op`, `e`, `mapping`, `composition`, `id` をまとめた構造体を渡します(ACL の `lazy_segtree` と同じ構成です)。
