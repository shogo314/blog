## 問題の概要

文字列 $S, T$ が与えられます。$Q$ 個のクエリ $(L, R)$ それぞれについて、$S$ の $L$ 文字目から $R$ 文字目までの部分に $T$ が含まれるかを判定する問題です($|S| \le 4 \times 10^5$、$|T| \le 10$、$Q \le 2 \times 10^5$)。

## 解法

$S$ の $L$ 文字目から $R$ 文字目までに $T$ が含まれるのは、$T$ が $S$ の $i$ 文字目から始まって出現するような $i$ が $L \le i \le R - |T| + 1$ の範囲にあるときです。

そこで、前処理として $S$ の各位置から $T$ が始まるかを調べておきます。$|T| \le 10$ なので、各位置で愚直に比べても $O(|S||T|)$ で間に合います。これの累積和をとっておけば、各クエリでは区間 $[L, R - |T| + 1]$ にある開始位置の個数が $O(1)$ で求まり、それが $1$ 以上なら Yes です。

## 解答コード

<details>
<summary>Python</summary>

```python
Q = int(input())
S = input()
T = input()
N, M = len(S), len(T)
acc = [0] * (N + 1)
for i in range(N):
    acc[i + 1] = acc[i] + S.startswith(T, i)
for _ in range(Q):
    L, R = map(int, input().split())
    print("Yes" if L - 1 <= R - M and acc[R - M + 1] > acc[L - 1] else "No")
```

`acc[i]` は、$T$ の出現のうち開始位置(0 始まり)が $i$ 未満のものの個数です。0 始まりで開始位置が $L - 1$ 以上 $R - |T|$ 以下の出現があるかを、`acc[R - M + 1] > acc[L - 1]` で調べています。$R - L + 1 < |T|$ のときは区間が空なので、先に `L - 1 <= R - M` で除いています。

</details>
