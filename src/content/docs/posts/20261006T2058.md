## 問題の概要

頂点 $1, \ldots, N$ の木 $T$ について、頂点 $1$ から始めて「訪問候補の集合 $S$ から番号が最小の頂点を取り出して訪問し、その未訪問の隣接頂点を $S$ に加える」ことを繰り返したときの訪問順を $f(T)$ とします。順列 $Q$ ($Q_1 = 1$) が与えられるので、$f(T) = Q$ となる木 $T$ の個数を $998244353$ で割った余りを求める問題です($N \le 2 \times 10^5$)。

## 解法

以下、添字を $0$ 始まりにして $Q_0 = 1$ とします。

### 各頂点の「親」を数える

$i \ge 1$ について、$Q_i$ を $S$ に加えたのは、$Q_i$ より先に訪問された隣接頂点です。木なので、$Q_i$ に隣接する頂点のうち $Q_i$ より先に訪問されるものはちょうど 1 つで、これを $Q_i$ の親 $Q_k$ ($k < i$) と呼ぶことにします。木は「各 $i \ge 1$ の親の選び方」と 1 対 1 に対応するので、条件を満たす親の選び方を数えればよいです。

$Q_k$ を訪問した時点で $Q_i$ が $S$ に入り、$Q_i$ は $i$ 番目に取り出されるまで $S$ に残ります。その間に取り出される $Q_{k+1}, \ldots, Q_{i-1}$ はそのときの $S$ の最小値なので、すべて $Q_i$ より小さくなければなりません。

そこで、$Q_i$ より前にある $Q_i$ より大きい要素のうち最も後ろのものの位置を $p_i$ とします(なければ $p_i = 0$)。すると親の位置 $k$ の条件は

$$
p_i \le k \le i - 1
$$

で、選び方は $i - p_i$ 通りです($Q_{p_i}$ 自身は大きくても、親として先に訪問されるので構いません)。

逆に、すべての $i$ についてこの範囲で親を選べば、$i$ 番目の時点で $S$ に残っている他の頂点 $Q_m$ ($m > i$) は、親が $i$ より前にあるので条件から $Q_i < Q_m$ となり、$Q_i$ が最小として正しく取り出されます。したがって各 $i$ の選び方は独立で、答えは

$$
\prod_{i=1}^{N-1} (i - p_i)
$$

です。

### $p_i$ を求める

$p_i$ は「直前にある自分より大きい要素の位置」なので、

- 区間最大値のセグメント木で `min_left` を使って二分探索する($O(N \log N)$)
- 単調スタックの要領で、直前の大きい要素へのポインタをたどる(全体で $O(N)$)

のどちらでも求められます。

## 解答コード

`LL`、`VL`、`rep`、`print` などは[自作ライブラリ](https://github.com/shogo314/cpp_include/tree/6c2f83f9d587cc195671a261b121060e479ec580)のマクロ・関数で、`RMaxQ`(区間最大値のセグメント木)と `modint` は同じリポジトリの ou-library のものです。

<details>
<summary>C++(セグメント木)</summary>

```cpp
#include "ou-library/modint.hpp"
#include "ou-library/segtree.hpp"
#include "sh-library/base/all"
using mint = modint998244353;

void solve() {
    LL(N);
    VL(Q, N);
    Q--;
    mint ans = 1;
    RMaxQ<ll> seg(Q);
    rep(i, 1, N) {
        ll j = seg.min_left(i, [&](ll x) { return x <= Q[i]; });
        if (j)
            j--;
        ans *= i - j;
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`min_left(i, x <= Q[i])` で「$Q_l, \ldots, Q_{i-1}$ がすべて $Q_i$ 以下になる最小の $l$」を求め、その 1 つ前が $p_i$ です。

</details>

<details>
<summary>cLay(ポインタをたどる)</summary>

```cpp
#define MD 998244353
ll@N,@Q[N],g[N],p;mint x=1;rep(i,1,N){p=i-1;while(p&&Q[p]<Q[i])p=g[p];g[i]=p;x*=i-p;}wt(x);
```

`g[i]` に $p_i$ を記録しておき、$Q_{i-1}$ から始めて自分より小さい間は `g` をたどることで $p_i$ を求めています。$Q_0 = 1$ は最小なので、より大きい要素がなければ $p = 0$ で止まります。

</details>
