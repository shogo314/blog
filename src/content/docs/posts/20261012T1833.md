## 問題の概要

$0, 1, 2$ からなる長さ $N$ の数列 $A$ に対して、次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。

- `1 i x`:$A_i$ を $x$ に変更する。
- `2 l r`:$(A_l, \dots, A_r)$ の[転倒数](/blog/posts/20261023T1324/)を出力する。

## 解法

セグメント木の各ノードに、担当区間について次の値を持たせます。

- $\mathrm{cnt}_v$:値 $v$($v = 0, 1, 2$)の個数
- $\mathrm{inv}$:区間内の転倒数

隣り合う区間 $X$(左)と $Y$(右)をつなげたときの転倒数は、「$X$ の中の転倒数」「$Y$ の中の転倒数」「$X$ と $Y$ にまたがる転倒数」の和です。またがる転倒は、$X$ の値 $i$ と $Y$ の値 $j$ で $i > j$ となる組なので、その個数は $\sum_{i > j} \mathrm{cnt}^X_i \, \mathrm{cnt}^Y_j$ です。

$$
\mathrm{inv}^{XY} = \mathrm{inv}^X + \mathrm{inv}^Y + \sum_{i > j} \mathrm{cnt}^X_i \, \mathrm{cnt}^Y_j
$$

これで 2 つの区間の情報を $O(1)$ で合成できるので、セグメント木に載せられます。全体の計算量は $O(N + Q \log N)$ です。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

struct AALC0001D {
    struct S {
        al<3> cnt;
        ll inv;
        S() : cnt{}, inv{} {}
        S(ll x) : cnt{}, inv{} {
            assert(0 <= x && x < 3);
            cnt[x] = 1;
        }
    };
    static S op(const S &a, const S &b) {
        S res;
        res.inv = a.inv + b.inv;
        rep(i, 3) {
            res.cnt[i] = a.cnt[i] + b.cnt[i];
            rep(j, i) {
                res.inv += a.cnt[i] * b.cnt[j];
            }
        }
        return res;
    }
    static S e() { return S(); }
};

void solve() {
    LL(N, Q);
    VL(A, N);
    vec<AALC0001D::S> init;
    init.reserve(N);
    for (ll a : A)
        init.push_back(a);
    SegTree<AALC0001D> seg(init);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(i, x);
            seg.set(i - 1, x);
        } else if (q == 2) {
            LL(l, r);
            print(seg.prod(l - 1, r).inv);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`SegTree` には、要素の型 `S`、演算 `op`、単位元 `e` をまとめた構造体を渡します。`al<3>` は `std::array<ll, 3>` です。
