## 問題の概要

頂点 $1, \ldots, N$ が重み $A_i$ の辺で円環状につながり、さらに各頂点 $i$ が中心の頂点 $N+1$ と重み $B_i$ の辺でつながったグラフがあります。$Q$ 個のクエリ $(S, T)$ それぞれについて、頂点 $S$ から頂点 $T$ への最短経路の長さを求める問題です($N, Q \le 2 \times 10^5$)。

## 解法

中心の頂点を $H = N + 1$ とし、$H$ から各頂点への最短距離 $F_v$ をダイクストラ法で求めておきます。

$T = H$ のときは、答えは $F_S$ です。

$T \ne H$ のときは、最短経路が $H$ を通るかどうかで場合分けします。

- **$H$ を通る場合:** $S$ から $H$ へ行き、$H$ から $T$ へ行く経路になるので、長さは $F_S + F_T$ 以上です。逆に、$S \to H$ と $H \to T$ の最短経路をつなげれば長さ $F_S + F_T$ の経路が作れます。なので、この場合の最短は $F_S + F_T$ です。
- **$H$ を通らない場合:** 円環の上だけを通るので、$S$ から $T$ へ時計回りに行くか、反時計回りに行くかの 2 通りです。$A$ の累積和を $G_i = A_1 + \cdots + A_i$ とすると、長さはそれぞれ $G_{T-1} - G_{S-1}$ と $G_N - (G_{T-1} - G_{S-1})$ です。

この 3 つの最小値が答えです。前処理が $O(N \log N)$、各クエリが $O(1)$ です。


[cLay](http://rsujskf.s602.xrea.com/?cLay) で書いています。頂点は 0 始まりで、$0, \ldots, N-1$ が円環、$N$ が中心です。

`C`、`D`、`E` に辺の両端と重みを入れ、`wgraph` の `setEdge` で重み付き無向グラフを作り、`getDist(N, F)` で中心からの最短距離を `F` に求めています。`G` は $A$ の累積和です。

クエリでは `x<?=` (小さい方を代入する cLay の演算子)で 3 つの候補の最小値をとっています。`N-T` が $0$、つまり $T$ が中心のときは `F[S]` を出力します。

```python
import sys
from heapq import heappop, heappush
from itertools import accumulate
input = sys.stdin.readline

N, Q = map(int, input().split())
A = list(map(int, input().split()))
B = list(map(int, input().split()))
graph = [[] for _ in range(N + 1)]
for i in range(N):
    graph[i].append(((i + 1) % N, A[i]))
    graph[(i + 1) % N].append((i, A[i]))
    graph[i].append((N, B[i]))
    graph[N].append((i, B[i]))
F = [None] * (N + 1)
pq = [(0, N)]
while pq:
    d, v = heappop(pq)
    if F[v] is not None:
        continue
    F[v] = d
    for u, w in graph[v]:
        if F[u] is None:
            heappush(pq, (d + w, u))
acc = [0, *accumulate(A)]
ans = []
for _ in range(Q):
    S, T = map(int, input().split())
    S -= 1
    T -= 1
    if T == N:
        ans.append(F[S])
    else:
        ans.append(min(F[S] + F[T], acc[T] - acc[S], acc[S] + acc[N] - acc[T]))
print(*ans, sep="\n")
```

cLay 版と同じ処理です。ダイクストラ法は `heapq` で書いています。
