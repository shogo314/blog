## 問題の概要

$N$ 人の候補者がいて、候補者 $i$ の名前は $S_i$ です(名前はすべて異なります)。$M$ 枚の投票用紙があり、投票用紙 $j$ には文字列 $T_j$ が書かれています。各投票用紙は次のように扱われます。

- $T_j$ と名前が完全に一致する候補者がいれば、その候補者に 1 票入る。
- そうでなく、$T_j$ を 1 文字書き換えると名前が一致する候補者がちょうど 1 人いれば、その候補者に 1 票入る。
- どちらでもなければ無効票になる。

各候補者の得票数を求める問題です($1 \le N, M \le 100$、$1 \le |S_i|, |T_j| \le 10$)。

## 解法

書かれているとおりに調べます。

「$T_j$ を 1 文字書き換えると $S_i$ に一致する」は、$T_j$ と $S_i$ の長さが等しく、異なる文字の位置がちょうど 1 か所であること(ハミング距離が $1$ であること)と同じです。完全に一致する候補者がいないときは、この条件を満たす候補者を数え、ちょうど 1 人ならその人に 1 票を入れます。

計算量は、名前の長さの最大値を $L$ として $O(NML)$ です。

## 解答コード

<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/string/string.hpp"
#include "shogo-library/utility/container_func.hpp"

void solve() {
    LL(N, M);
    VS(S, N);
    VS(T, M);
    vl ans(N);
    for (str t : T) {
        if (contains(S, t)) {
            ans[index(S, t)]++;
            continue;
        }
        vl cand = indices_if(S, [&](str s) { return len(t) == len(s) && hamming_distance(t, s) == 1; });
        if (len(cand) == 1) {
            ans[cand[0]]++;
        }
    }
    for (ll a : ans)
        print(a);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`contains(S, t)` は `S` に `t` が含まれるか、`index(S, t)` はその位置を返します。`indices_if` は条件を満たす要素の位置をすべて集めた列を返し、`hamming_distance` は長さの等しい 2 つの文字列で異なる文字の個数を返します。`hamming_distance` は長さが等しいことを前提にしているので、先に `len(t) == len(s)` を確かめています。
