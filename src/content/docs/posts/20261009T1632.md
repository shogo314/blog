## 問題の概要

長さ $n$ の整数列 $a_1, \dots, a_n$ があります($6 \le n \le 2 \cdot 10^5$、$|a_i| \le 10^4$)。$1 \le x \le n - 4$ に対して、鍵 $x, x + 2, x + 4$ の組を「トライアド $x$」と呼び、その値を $a_x + a_{x+2} - a_{x+4}$ とします。

鍵を共有せず、値が等しい 2 つのトライアドの組(順序は区別しない)の個数を求めてください($n$ の総和 $\le 2 \cdot 10^5$)。

## 解法

$v_x = a_x + a_{x+2} - a_{x+4}$ とおきます。

### 鍵を共有するのはどんなときか

トライアド $x < y$ の鍵は $\{x, x+2, x+4\}$ と $\{y, y+2, y+4\}$ です。$y - x$ が奇数なら偶奇が違うので共有しません。$y - x \ge 6$ なら離れすぎていて共有しません。したがって、**鍵を共有するのは $y - x = 2$ または $y - x = 4$ のときだけ**です。

### 余事象で数える

鍵の共有を気にせずに、値が等しいペアをすべて数えてから、鍵を共有するペアを引きます。

- **値が等しいペアの総数**:$v$ をソートすると、同じ値が連続して並びます。同じ値が $k$ 個あれば、そこから $\binom{k}{2} = \frac{k(k-1)}{2}$ 個のペアが作れます。
- **鍵を共有するペア**:$v_x = v_{x+2}$ となる $x$ の個数と、$v_x = v_{x+4}$ となる $x$ の個数を足したものです。

答えは前者から後者を引いたものです。計算量はソートがあるので $O(n \log n)$ です。

## 補足:辞書で数えるとハックされる

$v_y$ と等しい $v_x$($x < y$)の個数を、`Counter` などの辞書で数えながら左から見ていく方法も考えられます。ただ、Python でこの方法を提出したところ、PyPy でも TLE になりました(テスト 7)。

テスト 7 は、奇数番目の要素がすべて $0$ の入力です。そのため奇数位置の $v_x$ はすべて $0$ になり、辞書のキー $0$ が約 $10^5$ 回検索されます。一方、偶数位置の $v_x$ は、キー $0$ を検索するときにたどる位置をほかのキーで埋め尽くすように作られていると考えられます。Python の整数のハッシュ値は値そのものなので、キーが予測できればこのような入力を作れてしまいます。その結果、検索のたびに長い列をたどることになって TLE します。

対策としては、次のどちらかがあります。

- 起動時に決めた乱数とキーの XOR をとってから辞書に入れる(ハックする側が衝突を狙えなくなる)
- 上の解法のように、ハッシュを使わずにソートで数える

ここでは後者を採用しています。C++ の `std::map` は平衡二分木でハッシュを使わないので、辞書で数える方法でも問題ありません。

## 解答コード

<details>
<summary>Python</summary>

```python
from itertools import groupby

for _ in range(int(input())):
    N = int(input())
    A = list(map(int, input().split()))
    M = N - 4
    v = [A[i] + A[i + 2] - A[i + 4] for i in range(M)]
    ans = 0
    for _, g in groupby(sorted(v)):
        k = len(list(g))
        ans += k * (k - 1) // 2
    for i in range(M):
        if i + 2 < M and v[i] == v[i + 2]:
            ans -= 1
        if i + 4 < M and v[i] == v[i + 4]:
            ans -= 1
    print(ans)
```

`groupby(sorted(v))` で同じ値の並びごとに個数 `k` を数え、$\binom{k}{2}$ を足しています。そのあと、位置の差が $2$ と $4$ で値が等しいものを引いています。

<details>
<summary>C++(std::map で数える)</summary>

```cpp
#include "sh-library/base/all"

void solve() {
    LL(N);
    VL(A, N);
    mll c;
    ll ans = 0;
    deque<ll> d;
    rep(i, N - 4) {
        ll t = A[i] + A[i + 2] - A[i + 4];
        ans += c[t];
        if (d.size() >= 1 && d[d.size() - 1] == t) {
            ans++;
        }
        if (d.size() >= 3 && d[d.size() - 3] == t) {
            ans++;
        }
        while (d.size() >= 4) {
            c[d.front()]++;
            d.pop_front();
        }
        d.push_back(t);
    }
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    LL(T);
    rep(T)
        solve();
}
```

左から順に見て、トライアド $y$ と組になる $x < y$ を数えています。

- $y - x \ge 5$ の分は、`c`(値ごとの個数を持つ `std::map`)で数えます。
- $y - x$ が $1$ と $3$ の分は、直近 4 個の値を持つ `d` で個別に確かめます。

$y - x$ が $2$ と $4$ のペアは鍵を共有するので数えません。
