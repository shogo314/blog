## 問題の概要

長さ $N$ の非負整数列 $A$ に対して、次の 3 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。

- `1 i x`:$A_i$ を $x$ に変更する。
- `2 l t`:$\sum_{i=l}^{r} A_i \ge t$ となる $r$($l \le r \le N$)の最小値を出力する。なければ $N + 1$ を出力する。
- `3 r t`:$\sum_{i=l}^{r} A_i \ge t$ となる $l$($1 \le l \le r$)の最大値を出力する。なければ $0$ を出力する。

## 解法

和の[セグメント木](/blog/posts/20261010T0123/)を使います。$A_i \ge 0$ なので、$l$ を固定すると $\sum_{i=l}^{r} A_i$ は $r$ について単調に増えます。そのため、クエリ 2 は「和が $t$ 未満である間、右に伸ばせるだけ伸ばす」という二分探索で求まります。これはセグメント木上の二分探索(ACL の `max_right` に当たる操作)で $O(\log N)$ で行えます。クエリ 3 も同様に、左に伸ばす二分探索(`min_left`)で求まります。

全体の計算量は $O(N + Q \log N)$ です。

<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

void solve() {
    LL(N, Q);
    VL(A, N);
    RSumQ<ll> seg(A);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(i, x);
            seg.set(i - 1, x);
        } else if (q == 2) {
            LL(l, t);
            print(1 + seg.max_right(l - 1, [t](ll a) { return a < t; }));
        } else {
            LL(r, t);
            print(seg.min_left(r, [t](ll a) { return a < t; }));
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`RSumQ<ll>` は区間和のセグメント木で、`max_right` と `min_left` は ACL と同じ仕様です。

- `max_right(l - 1, f)` は、0 始まりの半開区間 $[l - 1, r')$ の和が $t$ 未満となる最大の $r'$ を返します。0 始まりで $r'$ 番目(1 始まりで $r' + 1$ 番目)の要素を加えたときに初めて $t$ 以上になるので、答えは $r' + 1$ です。$r' = N$ のときは $N + 1$ になり、「存在しない」場合の出力とも一致します。
- `min_left(r, f)` は、半開区間 $[l', r)$ の和が $t$ 未満となる最小の $l'$ を返します。0 始まりで $l' - 1$ 番目(1 始まりで $l'$ 番目)の要素を加えたときに初めて $t$ 以上になるので、答えは $l'$ です。$l' = 0$ のときも、そのまま「存在しない」場合の出力 $0$ になります。
