## 問題の概要

$N$ 個の町があり、はじめは道がありません。2 つの町を結ぶ道を追加して、どの町 $i$ からもすべての町へ $D_i$ 本以下の道で行けるようにします。追加する道の本数の最小値を求める問題です($2 \le N \le 3 \times 10^5$、$1 \le D_i \le N - 1$)。

## 解法

$D_i = 1$ の町の個数を $k$ とします。

### $k = 0$ のとき

すべての町がつながっている必要があるので、道は $N - 1$ 本以上必要です。1 つの町を中心にして、残りの $N - 1$ 個の町とそれぞれ結ぶと、中心からはどの町へも $1$ 本で、ほかの町からはどの町へも $2$ 本以下で行けます。$k = 0$ なのですべての $i$ で $D_i \ge 2$ となり、条件を満たします。よって答えは $N - 1$ です。

### $k \ge 1$ のとき

$D_i = 1$ の町 $i$ は、ほかのすべての町と直接結ばれていなければなりません。よって、$D_i = 1$ の町のどれかを端点に持つ道は、すべて必要です。その本数は、$D_i = 1$ の町と別の町の組の個数で、

$$
(N - 1) + (N - 2) + \dots + (N - k)
$$

です。$D_i = 1$ の町を 1 つずつ見て、まだ数えていない町との組を足していくとこの式になります。

逆に、この道だけで条件を満たします。$D_i = 1$ の町はすべての町と直接結ばれています。それ以外の町は、$D_i = 1$ の町を経由してどの町へも $2$ 本以下で行けて、$D_i \ge 2$ です。よって、これが答えです。

計算量は $O(N)$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
D = list(map(int, input().split()))
ans = 0
k = 0
for d in D:
    if d == 1:
        k += 1
        ans += N - k
if ans == 0:
    ans += N - 1
print(ans)
```

$D_i = 1$ の町が見つかるたびに、それが何個目かを `k` として、$N - k$ を足しています。$k \ge 1$ なら `ans` は $N - 1$ 以上になるので、`ans == 0` となるのは $k = 0$ のときだけです。
