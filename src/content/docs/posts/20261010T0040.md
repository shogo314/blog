## 問題の概要

$x$ 時に寝始めて、$t$ 時間眠ります($0 \le x \le 23$、$1 \le t \le 50$)。起きる時刻(0 時から 23 時のどれか)を求めてください。

## 解法

時計は 24 時間で一周するので、答えは $(x + t) \bmod 24$ です。

$t$ は最大 $50$ で 24 時間を超えることがありますが、$\bmod 24$ をとれば何周しても正しく求まります。たとえば $x = 10, t = 50$ なら $60 \bmod 24 = 12$ です。

## 解答コード

<details>
<summary>Python</summary>

```python
print(sum(map(int, input().split())) % 24)
```
