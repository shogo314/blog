## 問題の概要

$N$ 日間、毎日「配信する」か「休む」かを選びます。$i$ 日目に配信するとファンが $A_i$ 人増え、休むと何も起きません($1 \le A_i \le 10^9$)。

ただし、$B$ 日以上続けて休むことはできず、$C$ 日以上続けて配信することもできません($2 \le B, C \le N + 1$)。増えるファンの人数の最大値を求めてください($N \le 3 \times 10^5$)。

## 解法

配信が続く区間を「配信区間」と呼びます。配信区間の長さは $C - 1$ 以下、休みが続く区間の長さは $B - 1$ 以下でなければなりません。

### 3 日以上続く休みは考えなくてよい

$A_i \ge 1$ なので、配信する日は多いほうが得です。3 日以上続く休みがあれば、その真ん中の 1 日を配信に変えられます。この日の両隣は休みのままなので、長さ 1 の配信区間ができるだけです。$C \ge 2$ なので長さ 1 の配信区間は必ず許され、休みの区間も短くなるだけなので、条件は崩れません。しかもファンは増えます。

したがって、**最適解では休みは 2 日までしか続きません**。$B = 2$ なら連続休みは 1 日まで、$B \ge 3$ なら 2 日まで許されます。以下では、$B \ge 3$ のときは連続休みの長さに上限を設けずに計算します。上限を超える休み方は、真ん中を配信に変えたものより必ず悪いので、最大値は変わりません。

### 「休む日」で DP する

$\mathrm{rest}_i$ を「$i$ 日目に休むときの、$i$ 日目までのファンの増加数の最大値」とします。$i$ 日目に休む直前の状況で場合分けします。

- **前日も休み**:$\mathrm{rest}_{i-1}$。$B \ge 3$ のときだけ選べます。
- **前日まで配信区間**:配信区間が $j$ 日目から $i - 1$ 日目までなら、$j - 1$ 日目は休みです。値は $\mathrm{rest}_{j-1} + (A_j + \dots + A_{i-1})$ で、配信区間の長さの制約から $i - (C - 1) \le j \le i - 1$ です。
- **$i$ 日目が 1 日目**:何もしていないので $0$ です。

1 日目より前の日を「0 日目に休んだ」とみなして $\mathrm{rest}_0 = 0$ とおくと、配信区間が 1 日目から始まる場合も 2 つ目の式で扱えます。ただし、1 日目に休むときに「前日も休み」の場合として扱うと、$B = 2$ では選べなくなってしまいます。そこで 1 日目に休む場合は、$B$ によらず $0$ とします(下の補足も参照)。

最終日に休む場合の答えは $\mathrm{rest}_N$、最終日まで配信する場合の答えは $j$ 日目から $N$ 日目までの配信区間を使った同じ式で求まります。

### スライド最大値で高速化する

累積和 $S_i = A_1 + \dots + A_i$ を使うと、2 つ目の式は

$$
\mathrm{rest}_{j-1} + S_{i-1} - S_{j-1} = (\mathrm{rest}_{j-1} - S_{j-1}) + S_{i-1}
$$

と書けます。$i$ が 1 増えると、$j$ の範囲は 1 つずつ右にずれます。したがって、長さ $C - 1$ の窓の中での $\mathrm{rest}_{j-1} - S_{j-1}$ の最大値が分かればよく、これは deque を使ったスライド最大値で求まります。

計算量は $O(N)$ です。

## 補足:1 日目に休む場合

最初は 1 日目に休む場合も「前日も休み」として扱っていて、WA になりました。たとえば $N = 2, B = 2, C = 2, A = (8, 9)$ では、1 日目に休んで 2 日目に配信する $9$ が正解です。しかし、1 日目の休みを「0 日目からの連続休み」とみなすと、$B = 2$ で禁止されて $8$ になってしまいます。0 日目は実際には休みではないので、1 日目だけは $B$ によらず休めるようにする必要があります。

## 解答コード

<summary>Python</summary>

```python
from collections import deque

N, B, C = map(int, input().split())
A = list(map(int, input().split()))
t = 0
k = 0
d = deque()
e = deque()
for i, a in enumerate(A):
    if d:
        u = e[0] + k
    else:
        u = -(10**18)
    if B > 2 or i == 0:
        u = max(u, t)
    d.append(t - k)
    e.append(t - k)
    while len(e) >= 2 and e[-2] < e[-1]:
        x = e.pop()
        e.pop()
        e.append(x)
    k += a
    while len(d) >= C:
        x = d.popleft()
        if len(e) > 0 and e[0] == x:
            e.popleft()
    t = u
print(max(t, max(d) + k))
```

変数の意味は次のとおりです。

- `t`:前日に休んだときの最大値($\mathrm{rest}_{i-1}$)
- `k`:前日までの累積和($S_{i-1}$)
- `u`:その日に休んだときの最大値($\mathrm{rest}_i$)
- `d`:配信区間の始まりの候補 $j$ について、$\mathrm{rest}_{j-1} - S_{j-1}$ を並べた窓。最大 $C - 1$ 個を持ちます。
- `e`:`d` のうち、後ろにより大きい値がないものだけを残した deque。先頭が窓の中の最大値です。

`d` から要素を捨てるときは、その値が `e` の先頭と等しければ `e` からも捨てます。値しか比べていませんが、別の要素を取り違えることはありません。捨てる要素 $x$ が `e` から消えているなら、$x$ より後に $x$ より大きい値が窓の中にあります。そのため `e` の先頭(窓の最大値)は $x$ より大きく、等しくはなりません。最後の `max(d) + k` は、最終日まで配信する場合の値です。
