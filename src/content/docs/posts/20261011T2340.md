## 問題の概要

$N$ 個のマスが一列に並んでいます。マス $i$ からは、左側の好きなマスへコスト $L_i$ で、右側の好きなマスへコスト $R_i$ で移動できます。$Q$ 個のクエリ $(s, t)$ について、マス $s$ からマス $t$ へ移動するときのコストの合計の最小値を求める問題です($2 \le N \le 3 \times 10^5$、$1 \le Q \le 3 \times 10^5$、$1 \le L_i, R_i \le 10^9$、$s \ne t$)。

## 解法

$s < t$ の場合を考えます($s > t$ の場合は左右を入れ替えるだけです)。

最初の移動で場合分けします。

- **最初に右へ移動する場合**:コストは少なくとも $R_s$ かかります。一方、マス $s$ からマス $t$ へ直接移動すればコスト $R_s$ で着くので、この場合の最小値は $R_s$ です。
- **最初に左へ移動する場合**:まずコスト $L_s$ がかかります。その後マス $t$ に行くには、どこかで右へ移動する必要があります。最初に右へ移動するまでは左にしか動いていないので、そのときにいるマス $j$ は $j < s$ を満たし、コスト $R_j$ がかかります。逆に、マス $s$ からマス $j$ へ移動し、マス $j$ からマス $t$ へ移動すれば、コスト $L_s + R_j$ で着きます。したがって、この場合の最小値は $L_s + \min_{j < s} R_j$ です。

まとめると、答えは

$$
\min\left(R_s,\ L_s + \min_{1 \le j < s} R_j\right)
$$

です($s = 1$ のときは $R_s$)。$s > t$ のときは同様に $\min\left(L_s,\ R_s + \min_{s < j \le N} L_j\right)$ です。

$\min_{j < s} R_j$ は $R$ の先頭からの最小値(累積 min)、$\min_{j > s} L_j$ は $L$ の末尾からの最小値なので、前計算しておけば各クエリに $O(1)$ で答えられます。計算量は $O(N + Q)$ です。[セグメント木](/blog/posts/20261010T0123/)で区間の最小値を求めても、$O((N + Q) \log N)$ で間に合います。

## 解答コード

<details>
<summary>Python</summary>

```python
N, Q = map(int, input().split())
L = [0, 0] + list(map(int, input().split()))
R = [0] + list(map(int, input().split())) + [0]
INF = 1 << 60
pre = [INF] * N
for i in range(1, N):
    pre[i] = min(pre[i - 1], R[i])
suf = [INF] * (N + 2)
for i in range(N, 1, -1):
    suf[i] = min(suf[i + 1], L[i])
for _ in range(Q):
    s, t = map(int, input().split())
    if s < t:
        print(min(R[s], L[s] + pre[s - 1]))
    else:
        print(min(L[s], R[s] + suf[s + 1]))
```

`L[i]` が $L_i$、`R[i]` が $R_i$ になるように、先頭と末尾に $0$ を詰めています。`pre[i]` は $\min(R_1, \dots, R_i)$、`suf[i]` は $\min(L_i, \dots, L_N)$ で、範囲が空のときは `INF` です。$s = 1$ のときは `pre[0]` が `INF` なので、自動的に $R_s$ が答えになります($s = N$ のときも同様です)。

<summary>C++</summary>

```cpp
#include "shogo-library/algebra/monoid.hpp"
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

void solve() {
    LL(N, Q);
    VL(L, N - 1);
    VL(R, N - 1);
    RMinQ<ll> segl(L), segr(R);
    rep(Q) {
        LL(s, t);
        s--, t--;
        ll ans = 1e18;
        if (s < t) {
            chmin(ans, R[s]);
            if (s > 0) {
                chmin(ans, segr.prod(0, s) + L[s - 1]);
            }
        } else {
            chmin(ans, L[s - 1]);
            if (s < N - 1) {
                chmin(ans, segl.prod(s, N - 1) + R[s]);
            }
        }
        print(ans);
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`RMinQ` は区間の最小値を求めるセグメント木で、`prod(l, r)` は半開区間 $[l, r)$ の最小値を返します。コードでは `s` を 0 始まりに直しているので、問題文のマス $s$ に対して `L[s - 1]` が $L_s$、`R[s]` が $R_s$ です。`segr.prod(0, s)` が $\min_{j < s} R_j$、`segl.prod(s, N - 1)` が $\min_{j > s} L_j$ にあたります。
