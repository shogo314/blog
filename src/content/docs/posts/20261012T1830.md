## 問題の概要

長さ $N$ の非負整数列 $A$ に対して、次の 2 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$)。

- `1 i x`:$A_i$ を $x$ に変更する。
- `2 l r`:$\min(A_l, \dots, A_r)$ を出力する。

## 解法

1 点の更新と区間の最小値の取得なので、最小値を演算とするセグメント木をそのまま使えます。どちらの操作も $O(\log N)$ なので、全体の計算量は $O(N + Q \log N)$ です。

## 解答コード

<details>
<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/segtree.hpp"

void solve() {
    LL(N, Q);
    VL(A, N);
    RMinQ<ll> seg(A);
    rep(Q) {
        LL(q);
        if (q == 1) {
            LL(i, x);
            seg.set(i - 1, x);
        } else {
            LL(l, r);
            print(seg.prod(l - 1, r));
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`RMinQ<ll>` は区間の最小値を求めるセグメント木です。`prod(l, r)` は 0 始まりの半開区間 $[l, r)$ を対象にするので、`prod(l - 1, r)` としています。
