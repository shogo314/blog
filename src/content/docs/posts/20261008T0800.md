## 問題の概要

$N$ 個の地点が一列に並び、それぞれの高さはすべて異なります。両隣より低い地点(谷)を 1 つ見つけるインタラクティブ問題です。端の地点では、外側に無限に高い山があるとみなします。

`? i` と質問すると地点 $i$ の高さが返ってきます。質問は $130$ 回までで、$N$ は最大 $10^{18}$ です。

## 解法

二分探索で谷を探します。

### 端を先に調べる

まず端を調べます。

- $h_1 < h_2$ なら、地点 $1$ が谷です。
- $h_{N-1} > h_N$ なら、地点 $N$ が谷です。

どちらでもなければ、$h_1 > h_2$(左端では下り)かつ $h_{N-1} < h_N$(右端では上り)です。

### 「下り」と「上り」の間を狭める

$l$ を「$h_l > h_{l+1}$(下り)」、$r$ を「$h_r < h_{r+1}$(上り)」を満たす位置として、$l = 1$、$r = N - 1$ から始めます。

$l$ と $r$ の真ん中 $m$ で $h_m$ と $h_{m+1}$ を比べ、上りなら $r = m$、下りなら $l = m$ とします。こうすれば、$l$ では下り、$r$ では上り、という状態がずっと保たれます。

$r = l + 1$ になったら、$h_l > h_r$ かつ $h_r < h_{r+1}$ なので、地点 $r$ が谷です。

### 質問回数

$r - l$ は 1 回ごとにほぼ半分になるので、繰り返しは $\lceil \log_2 10^{18} \rceil = 60$ 回以下です。1 回の繰り返しで質問するのは $h_m$ と $h_{m+1}$ の 2 つなので、最初の 4 回と合わせて $4 + 2 \times 60 = 124$ 回以下に収まります。

## 解答コード

```python
d = {}


def q(x):
    if x not in d:
        print("?", x)
        d[x] = int(input())
    return d[x]


N = int(input())
if N == 1:
    print("!", 1)
    exit(0)
if q(1) < q(2):
    print("!", 1)
    exit(0)
if q(N - 1) > q(N):
    print("!", N)
    exit(0)
l = 1
r = N - 1
while l + 1 < r:
    m = (l + r) // 2
    if q(m) < q(m + 1):
        r = m
    else:
        l = m
print("!", r)
```

`q(x)` は地点 $x$ の高さを質問する関数で、同じ地点を 2 回質問しないように結果を `d` に覚えています。

問題文では出力のたびにフラッシュするように書かれていますが、Python の `input()` は読み込む前に標準出力をフラッシュするので、`flush` を書かなくても質問はジャッジに届きます。
