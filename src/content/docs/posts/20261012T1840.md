## 問題の概要

はじめ $N$ 個の要素 $A_1, \dots, A_N$ をもつ整数の多重集合 $S$ に対して、次の 3 種類のクエリを合計 $Q$ 個処理する問題です($1 \le N, Q \le 2 \times 10^5$, $0 \le A_i, x \le 10^9$)。

- `1 x`:$S$ に $x$ を 1 個追加する。
- `2 x`:$S$ から $x$ を 1 個削除する($x$ が含まれることは保証される)。
- `3`:$S$ の要素を昇順に並べた列を $x_1, \dots, x_k$ として、$\sum_{i=1}^{k} i x_i$ を $998244353$ で割った余りを出力する。

## 解法

クエリを先読みして、現れる値を座標圧縮します。値ごとに、その値の要素の「値の和 $u$」と「(順位)×(値)の和 $w$」を管理すると、答えは $w$ の総和です。同じ値の要素どうしは、どの順に並べても $\sum i x_i$ は変わりません。そのため、同じ値の要素の中での順番は自由に決めてよいです。

値 $x$ を追加するとき、$x$ は同じ値の要素の中で先頭に入れることにします。すると、

- $x$ 以上の値の要素(同じ値の要素も含む)は順位が 1 つずつ増えるので、それぞれの値について $w$ が $u$ だけ増えます。
- 追加した要素の順位は「$x$ 未満の要素の個数 $+ 1$」なので、値 $x$ の $u$ に $x$、$w$ に(順位)$\times x$ を足します。

削除は逆で、同じ値の要素の中の先頭を取り除くことにします。$x$ 以上の値の $w$ から $u$ を引き、値 $x$ の $u$ から $x$、$w$ から「$x$ 未満の要素の個数」$\times x$ を引きます。ここでの順位は、全体の順位を 1 つ下げた後の値です。

「$x$ 以上の値すべての $w$ に $c \cdot u$ を足す」は区間への作用です。そのため、値ごとの $(u, w)$ を遅延評価セグメント木で管理します。作用 $c$ は $(u, w) \mapsto (u, w + c u)$ で、合成は和です。$x$ 未満の要素の個数は、値ごとの個数を持つ別のセグメント木で求めます。

全体の計算量は $O((N + Q) \log (N + Q))$ です。

```cpp
#include "shogo-library/base/all"
#include "shogo-library/data_structures/lazy-segtree.hpp"
#include "shogo-library/data_structures/segtree.hpp"
#include "shogo-library/math/modint.hpp"
using mint = modint998244353;

struct AALC0001K {
    struct S {
        mint u, v;
        S() : u{}, v{} {}
    };
    using F = mint;
    static S op(const S &a, const S &b) {
        S res;
        res.u = a.u + b.u;
        res.v = a.v + b.v;
        return res;
    }
    static S e() { return S(); }
    static S mapping(const F &f, const S &x) {
        S res;
        res.u = x.u;
        res.v = x.u * f + x.v;
        return res;
    }
    static F composition(const F &f, const F &g) { return f + g; }
    static F id() { return 0; }
};

void solve() {
    LL(N, Q);
    VL(A, N);
    vl tmp = A;
    val<2> query;
    query.reserve(Q);
    rep(Q) {
        LL(q);
        if (q <= 2) {
            LL(x);
            query.push_back({q, x});
            tmp.push_back(x);
        } else {
            query.push_back({q, 0});
        }
    }
    sl s(all(tmp));
    vl v(all(s));
    RSumQ<ll> seg0(v.size());
    LazySegTree<AALC0001K> seg1(v.size());
    for (ll a : A) {
        ll k = bisect_left(v, a);
        seg1.apply(k, v.size(), 1);
        auto g = seg1.get(k);
        ll f = seg0.prod(0, k) + 1;
        g.u += a;
        g.v += f * a;
        seg1.set(k, g);
        seg0.apply(k, 1);
    }
    for (auto [q, x] : query) {
        if (q == 1) {
            ll k = bisect_left(v, x);
            seg1.apply(k, v.size(), 1);
            auto g = seg1.get(k);
            ll f = seg0.prod(0, k) + 1;
            g.u += x;
            g.v += f * x;
            seg1.set(k, g);
            seg0.apply(k, 1);
        } else if (q == 2) {
            ll k = bisect_left(v, x);
            seg1.apply(k, v.size(), -1);
            auto g = seg1.get(k);
            ll f = seg0.prod(0, k);
            g.u -= x;
            g.v -= f * x;
            seg1.set(k, g);
            seg0.apply(k, -1);
        } else {
            print(seg1.all_prod().v);
        }
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

コードでは $w$ を `v` という名前にしています(座標圧縮した値の配列も `v` ですが、別物です)。`seg0` は値ごとの個数を持つ区間和のセグメント木で、`apply(k, c)` は $k$ 番目の要素に $c$ を足す操作です。`seg1` は値ごとの $(u, w)$ を持つ遅延評価セグメント木で、構造体には要素の型 `S`・作用の型 `F` と、`op`, `e`, `mapping`, `composition`, `id` をまとめています(ACL の `lazy_segtree` と同じ構成です)。初期の $N$ 個の要素も、追加クエリと同じ手順で 1 個ずつ入れています。
