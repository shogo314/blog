## 問題の概要

長さ $N$ の整数列 $A$ が与えられます。$i = 1, 2, \dots, N$ の順に $(A_1, \dots, A_i)$ を末尾に連結して、長さ $\frac{N(N+1)}{2}$ の数列 $B$ を作ります。$Q$ 個の質問 $(L, R)$ について、$B_L + \dots + B_R$ を求める問題です($1 \le N, Q \le 10^5$、$-10^8 \le A_i \le 10^8$)。

## 解法

$B$ の先頭からの和 $f(x) = B_1 + \dots + B_x$ が求められれば、答えは $f(R) - f(L - 1)$ です。

$B$ は、$k$ 番目のかたまりが $(A_1, \dots, A_k)$ であるようなかたまりの連結です。$k$ 番目のかたまりの長さは $k$ なので、はじめの $i$ 個のかたまりの長さの合計は $T_i = \frac{i(i+1)}{2}$ です。また、$A$ の累積和を $P_j = A_1 + \dots + A_j$ とすると、$k$ 番目のかたまりの和は $P_k$ です。

$f(x)$ を求めるには、まず $T_i \le x$ となる最大の $i$ を求めます。$B_1, \dots, B_x$ は、はじめの $i$ 個のかたまりと、$i + 1$ 番目のかたまりの先頭 $x - T_i$ 個からなります。したがって

$$
f(x) = (P_1 + \dots + P_i) + P_{x - T_i}
$$

です。$P$ と、$P$ の累積和を前計算しておけば、$f(x)$ は $i$ を求めるだけで計算できます。$T_i$ は増加列なので、$i$ は二分探索で求められます。

計算量は $O(N + Q \log N)$ です。$|f(x)|$ は最大で $\frac{N(N+1)}{2} \times 10^8 \approx 5 \times 10^{17}$ 程度なので、64 ビット整数に収まります。

## 解答コード

<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/utility/binary-search.hpp"
#include "shogo-library/utility/container_func.hpp"

void solve() {
    LL(N, Q);
    VL(A, N);
    vl tmp = {0};
    vl s0 = {0}, s1 = {0};
    rep(i, N) {
        s0.push_back(s0.back() + A[i]);
        s1.push_back(s1.back() + s0.back());
        tmp.push_back(tmp.back() + i + 1);
    }
    auto q = [&](ll x) {
        ll i = bisect_right(tmp, x) - 1;
        return s1[i] + s0[x - tmp[i]];
    };
    rep(Q) {
        LL(L, R);
        print(q(R) - q(L - 1));
    }
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    solve();
}
```

`tmp[i]` が $T_i$、`s0[j]` が $P_j$、`s1[i]` が $P_1 + \dots + P_i$ です。`bisect_right(tmp, x)` は `tmp` の中で `x` より大きい最初の要素の位置(Python の `bisect.bisect_right` と同じ)を返すので、そこから $1$ を引くと $T_i \le x$ となる最大の $i$ になります。`q(x)` が $f(x)$ です。
