## 問題の概要

$1$ 以上 $N$ 以下の秘密の整数 $x$ を当てるインタラクティブ問題です。

`? l r` と質問すると、$x$ が $l$ 以上 $r$ 以下かどうかが $1$(はい)か $0$(いいえ)で返ってきます。ただし、ジャッジは嘘つきかもしれません。嘘つきの場合は、常に逆の答えを返します。質問は $20$ 回までで、$N \le 10^5$ です。

## 解法

### 嘘つきかどうかを先に調べる

`? 1 N` と質問します。$x$ は必ず $1$ 以上 $N$ 以下なので、本当の答えは「はい」です。したがって、$1$ が返ってくればジャッジは正直者、$0$ が返ってくれば嘘つきだとわかります。

嘘つきなら、これ以降の応答をすべて反転すれば本当の答えになります。

### 二分探索

あとは、ふつうの二分探索で $x$ を求めます。$x$ がありうる範囲を $[l, r]$ として、真ん中 $m$ で区切り、$x$ が $[l, m]$ にあるかを質問します。あれば $r = m$、なければ $l = m + 1$ とします。

範囲の大きさは 1 回ごとに半分(切り上げ)になるので、$\lceil \log_2 10^5 \rceil = 17$ 回で $1$ つに決まります。最初の 1 回と合わせて $18$ 回なので、$20$ 回に収まります。

## 解答コード

<details>
<summary>Python</summary>

```python
N = int(input())
l = 1
r = N
print("?", 1, N, flush=True)
x = (int(input())) ^ 1
while l < r:
    m = (l + r) // 2
    print("?", l, m, flush=True)
    res = int(input())
    if res ^ x:
        r = m
    else:
        l = m + 1
print("!", l, flush=True)
```

変数 `x` は秘密の整数ではなく、ジャッジが嘘つきなら $1$、正直者なら $0$ になるフラグです。`res ^ x` で応答を反転し、本当の答えに直しています。
