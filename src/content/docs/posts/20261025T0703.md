## 問題の概要

$xy$ 平面上に $N$ 個の星 $(X_i, Y_i)$ があります。原点を通り、どの星も通らない直線を 1 本引き、分けられた 2 つの領域のどちらかを選びます。選んだ領域に含まれる星の個数の最大値を求める問題です。

どの 2 個の星も原点と一直線上に並ぶことはありません。$T$ 個のテストケースに答えます($N$ の総和は $2 \times 10^5$ 以下、$|X_i|, |Y_i| \le 10^9$)。

## 解法

### 半平面を偏角の区間で考える

原点を通る直線で分けた一方の領域は、偏角(原点から見た向きの角度)が長さ $\pi$ の開区間 $(\alpha, \alpha + \pi)$ に入る点の集まりです。よって、偏角が長さ $\pi$ の区間に入る星の個数の最大値を求めればよいです。

ある領域 $(\alpha, \alpha + \pi)$ が星を含むとき、含まれる星のうち偏角が最小のものを $\theta$ とします。含まれる星の偏角はどれも $\theta$ 以上 $\alpha + \pi$ 未満で、$\alpha < \theta$ なので、どれも $[\theta, \theta + \pi)$ に入ります。逆に、偏角が $[\theta, \theta + \pi)$ に入る星は、$\alpha$ を $\theta$ より少しだけ小さくした領域でちょうど全部含められます。偏角がちょうど $\theta + \pi$ の星はないので(原点と一直線上に並ばないため)、$\alpha$ を $\theta$ に十分近くすれば余計な星は入りません。

したがって、各星 $i$ について、偏角が $[\theta_i, \theta_i + \pi)$ に入る星を数え、その最大値が答えです。

### 尺取り法

星を偏角の順に並べます。偏角は一周すると元に戻るので、偏角に $2\pi$ を足した写しを後ろにつなげた長さ $2N$ の列を作ります。この列で、各 $l$ $(0 \le l < N)$ について、偏角が $\theta_l + \pi$ 未満である範囲の右端 $r$ を求めると、$r - l$ が $[\theta_l, \theta_l + \pi)$ に入る星の個数です。$l$ が増えると $r$ も減らないので、[尺取り法](/blog/posts/20261025T0709/)で全体 $O(N)$ で求まります。

計算量は、偏角ソートの $O(N \log N)$ です。

偏角は `atan2` などの浮動小数点数で求めると、偏角の近い星の比較で誤差が出るおそれがあります。外積を使って比べると、整数だけで正確に比べられます。座標の絶対値は $10^9$ 以下なので、外積は 64 bit 整数に収まります。

## 解答コード

<summary>C++</summary>

```cpp
#include "shogo-library/base/all"
#include "shogo-library/geometry/angle.hpp"
#include "shogo-library/utility/container_func.hpp"
#include "shogo-library/utility/two-pointers.hpp"

void solve() {
    LL(N);
    vec<Angle<ll>> A(N);
    for (auto &a : A)
        std::cin >> a;
    sort(A);
    rep(i, N) A.push_back(A[i].next_turn());
    auto right = two_pointers(2 * N, [&](ll l, ll r) { return A[r] < A[l].opposite(); });
    ll ans = 0;
    rep(l, N)
        chmax(ans, right[l] - l);
    print(ans);
}

int main() {
    std::cin.tie(nullptr);
    std::ios_base::sync_with_stdio(false);
    LL(T);
    rep(T)
        solve();
}
```

`Angle<ll>` はベクトル $(x, y)$ の偏角を表す型で、周回数 `turn` を持ち、偏角 $2\pi \cdot \mathrm{turn} + [0, 2\pi)$ として外積で比べます。`next_turn()` は偏角に $2\pi$ を足したもの、`opposite()` は $\pi$ を足したもの(逆向きのベクトル)です。

`sort(A)` で偏角の順に並べ、`next_turn()` で $2\pi$ を足した写しを後ろにつなげます。`two_pointers(n, can_add)` は、各 `l` について、区間 `[l, r)` に `r` を加えてよい(`can_add(l, r)` が真)間だけ `r` を伸ばし、伸ばし終えた `r` を並べた列を返します。ここでは「`A[r]` の偏角が `A[l]` の偏角 $+ \pi$ 未満」を条件にしています。
